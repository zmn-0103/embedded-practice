## 内容口径与限制

难度按题目任务复杂度统一为基础228、进阶141、综合50，界面显示易/中/难，与个人自评完全独立。单个错误不会自动更改题目难度。答案采用核心结论、必要解释、适用条件；判断和选择结果放在答案区。

I2C第二层原100题无答案，本次已逐题补充参考答案、来源与收发时序。STM32函数题限定F103RCT6和SPL V3.5.0；I2C接收依AN2824与适用ES0340。原048标准模式/快模式条件混淆已修正，原053明确清ADDR前关闭ACK。外部器件分别给定W25Q16JV/24LC256条件，完整器件后缀、实物接线、芯片修订及板上波形仍需核实。

这些是供个人测试的候选答案，已经AI逐题整理与静态核对，**用户技术审阅和硬件验证尚未完成**。原GPIO板卡接线改成明确题设，不把原笔记描述认定为已核验实物；没有具体待审驱动的题目只给审查方法，不虚构缺陷。技术核对范围、运行证据及首次失败见[本批说明](../../../docs/V0.0.0题库整理与验收.md)。

程序版本与题库版本分开：以后只调整题目时，可保持身份并单独更新完整专题，无需重新安装程序。导入前先通过程序导出完整备份；已经开始的练习继续保留原队列与原答案版本，新内容用于下一轮。
