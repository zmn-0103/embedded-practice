# 嵌入式刷题本

供个人使用的 Windows 离线嵌入式问答练习工具。题目与参考答案在程序外用 Markdown 维护，程序负责导入、选题、作答、自评和复盘，把一次练习与后续整理连在一起。

核心流程：**选择题目 → 输入答案或自行思考 → 揭晓参考答案 → 自评“不会 / 不熟 / 掌握” → 整理笔记与复习安排。** 程序不会自动判分。

## 当前状态

当前版本为 **V0.0.3**，目标平台为 **Windows x64**，处于本地试用阶段。仓库提供 [23 专题、382 题的 V0.0.3 题库](question-banks/releases/v003-20261030/README.md)，覆盖 GPIO、时钟、中断、UART、定时器、DMA、ADC、SPI、I2C、CAN，以及部分存储器和 C 语言知识。通用原理与具体芯片寄存器机制分别组织；题目不要求背诵某个库的 API。

现有单元测试和定向桌面自动化覆盖部分关键流程，实际范围与未验项目见[验收记录](docs/验收记录.md)。题目技术内容、硬件、安装器及完整人工体验仍有待审阅或验收，不能把试用状态理解为全部完成。

## 可以做什么

| 任务 | 当前能力 |
| --- | --- |
| 找到要练的题 | 按板块、专题、关键词、难度、题库标签、个人标签、自评、收藏和最近练习情况组合筛选 |
| 安排一轮练习 | 顺序或随机练习；保存、编辑动态方案；跨页勾选题目并保存有序固定题单；按专题配额预览组卷 |
| 连续作答 | 自动保存草稿、继续原固定队列、查看本轮清单、跳题、自评、从结果页再练；可选口述倒计时 |
| 整理个人积累 | 独立个人笔记、个人标签、明确安排与完成复习待办、人工关联易混或前置知识 |
| 回看与复盘 | 当前版本学习统计、单题历史、按轮次复盘、两次作答对照、积累检索、Markdown 复习材料导出 |
| 管理本地资料 | Markdown 完整专题导入预览与更新、内容版本差异、分类归属、本地主题、完整备份与确认恢复 |
| 跟踪学习安排 | 每日目标、关联固定题单的备考目标、活动日历；目标进度与当前版本掌握情况分别展示 |

具体操作见[使用说明](docs/使用说明.md)。版本更新、旧程序清理和历史检查集中在[产品入口与交付沿革](docs/history/产品入口与交付沿革.md)，首页只描述当前能力。

## 从源码快速启动

已验证的开发环境为 Windows 11 x64、Node.js **24.19.0**、npm **11.17.0**；Node 版本范围为 `>=24.19.0 <25`。进入仓库根目录后执行：

```powershell
npm ci
npm run dev
```

首次安装开发依赖需要联网下载 Electron 等组件，并重建 SQLite 原生模块；完成后核心练习功能可离线使用。安装失败时请按[开发说明](docs/开发说明.md#安装开发与预览)检查环境与原生模块，不跳过安装步骤。

新建的开发数据默认是空库，不会自动导入仓库题库。在“题库”中选择 `question-banks/releases/v003-20261030/topics/` 下的 23 份 `.md` 文件，核对预览后确认导入；说明文件与来源映射不作为题库导入。新专题默认未分类，可再按推荐板块设置归属。开发数据默认位于 `%APPDATA%/embedded-practice-dev/`，与正式桌面数据分开。

本仓库没有在此提供公开安装包或下载地址。本机现有完整程序的绝对路径、构建标识和兼容限制仅记录在[当前交付说明](docs/当前试用版本交付说明.md)，不能作为其他电脑的下载链接。

## 使用边界与数据

- 单机、单人、离线使用；没有账号、云同步、在线题库市场、遥测或自动更新。参考资料仅在主动点击后交给系统浏览器。
- 题目在程序外编辑；程序检查格式、身份与关联关系，参考答案的技术正确性仍需人工审阅。
- 没有自动判分、AI 追问、代码执行或自动复习调度；难度与个人掌握程度分别记录。
- Markdown 是维护来源，SQLite 保存已导入内容和个人记录。更新时保持 `topic_id + question_id`，完整专题中缺少的旧题会归档。
- 程序文件与数据分离。正式桌面数据默认位于 `%APPDATA%/embedded-practice/`；移动程序目录不会转移学习记录。使用程序内的完整备份与恢复迁移数据，恢复前核对摘要。
