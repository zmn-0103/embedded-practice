# 板块入口与难度标识

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

## 日常使用

程序默认进入“学习总览”，从“知识板块”入口进入板块列表。有可继续练习时可沿原固定队列继续；需要选择模式、难度、收藏等条件时进入“开始练习”。选用方案只填条件，明确开始才建轮。

板块页展示全部题库、未分类、15个基础板块及本机自定义分类。7个拓展方向默认收起；已有活动题的拓展方向始终显示。搜索板块会同时检索全部规划的板块名/专题名及本机实际专题，不受拓展开关限制。展开“查看专题与范围”即可看已导入专题、建设规划和收题边界。

板块题数只统计本机当前分类中的活动题，不使用参考软件或仓库候选题数。归档题数单独提供入口，不混入活动题数。点击“查看题库”会进入原题库，并明确设置分类范围、活动/归档状态，清空专题、页码和附加筛选，以使卡片题数与列表一致。之后仍可使用原有搜索、标签、难度、收藏、自评与分类导航。普通导航切回题库继续保留原阅读位置与已应用条件；再次点击板块才重新设置范围。

## 空板块与现有分类

空库也能浏览22份规划，无须制造占位题。0题卡片显示“待补题”，活动题入口禁用，仍可展开规划；卡片不直接开始练习，原开始页也继续禁止创建空轮。

规划与本机同名分类合并成一张卡片，使用该分类的真实ID和当前归属。同名英文部分沿用既有大小写语义；规划键不是数据库ID。原自定义分类、未分类及归档题都有入口。分类改名后保留原身份，按新的本机名称显示；原规划名恢复为待补题，不自动重建分类。

程序不会自动导入题库或写入22个分类，也不凭专题ID、文件名或标签猜测归属。新专题仍默认未分类。要使用某个规划板块，可在“题库 → 管理分类”创建同名分类，再将已导入专题归入其中；已有不同分类也可以继续使用。专题重导入保留归属。

## 易、中、难与原始难度

| 题库/存储值 | 界面显示 | 初始编写口径 |
| --- | --- | --- |
| 基础 | 易（基础） | 一个主要概念，给定条件下直接辨认或简单推导 |
| 进阶 | 中（进阶） | 需要计算、步骤分析、边界条件或异常分析 |
| 综合 | 难（综合） | 同时连接多个模块或多步骤推理，给出取舍与依据 |
| 未分级/未填写 | 未分级 | 尚未作出难度判断，不能自动当作易 |

题目列表、详情与练习均显示难度标识；筛选、方案摘要和原轮条件使用相同用语。难度是题库编辑者的任务复杂度约定，不是自动判分或个人掌握度。“综合”保留原文，提示旧内容采用的分档口径。

Markdown仍写 `难度：基础`、`难度：进阶` 或 `难度：综合`；不同时添加一套“易中难”知识标签。缺省规则与解析格式保持，旧题的未分级状态不自动改为基础。原题目、专题、版本、方案条件及旧轮难度快照不改写，技术审阅状态也不改变。

## 实现边界

板块规划继续来自[单一清单](../question-banks/catalog/板块规划.json)。渲染层以原 `listQuestions` 导航快照汇总计数，点击后复用同一分类筛选契约；不新增IPC、数据表、迁移、网络请求或持久化导航规则。

范围/题数读取失败会明确提示并允许重试，不把上次数字当作当前值；旧筛选的晚到响应不能覆盖新的板块范围。分类调整只影响当前导航，不重抽原练习队列或改写草稿、历史、题目版本和原分类名称快照。原方案失效引用仍保留并阻止应用。

需求原文保存在[计划书第十四节](../计划书.md#十四2026-10-24-板块入口接入追加)。原分类与方案契约分别见[分类树](分类树行为与验收.md#本批契约)、[练习方案](练习方案行为与验收.md#当前行为)，数据边界见[数据保护契约](数据保护与桌面边界.md)。
