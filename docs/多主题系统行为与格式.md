# 本地多主题系统：使用、格式与兼容性

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

## 安装、预览和应用

在“设置与数据”点击“安装本地主题…”，选择 `.ep-theme.json` 文件。程序校验后显示主题名称、作者、版本、许可和局部预览；点击“确认安装主题”才写入本机数据库。安装不会自动改变当前外观。

安装后在主题卡片中选择主题，独立选择明暗模式与 15～22px 字号，点击“保存并应用”。预览覆盖导航、阅读区、代码、输入框、按钮、错误提示及辅助信息，只影响预览区域。保存失败时保留原外观与待保存选择；结果尚未确认时重试原操作。

主题完整配置保存在数据库中，安装后可删除下载文件。内置主题有松间绿、晴空蓝、暖沙金、暮山紫和 **Claude 风格**。Claude 风格是非官方视觉预设，无官方品牌素材或专有字体。

主界面“外观”菜单可以明确点击“应用所选主题”，练习期间同样可用。切换只改变样式和受控布局，原练习组件、草稿、固定队列、揭晓状态，以及题库筛选、分页和选中项保留。

## 更新、卸载和默认设置

- 相同 ID、更高版本的包显示旧版本 → 新版本，点击“确认更新主题”后更新已安装配置。当前窗口保留已应用的外观快照，点击“保存并应用”启用新配置；重开会读取已安装的最新配置。
- 相同 ID、相同版本、规范化内容相同，作为已安装主题安全核对；JSON 空白与字段顺序不构成配置变化。同版本不同配置拒绝覆盖，不支持降级。
- `builtin.` 前缀保留给内置主题，外部包不能覆盖；内置主题不能卸载。
- 外部主题在管理区卸载，确认默认留在应用中。卸载当前主题会在同一数据库事务中切换到松间绿；失败时两项一起回滚，重复卸载可安全核对。
- “恢复默认外观”恢复松间绿、跟随系统、17px、导航展开及辅助面板显示；已安装主题和学习数据保留。

预检凭据有效期 10 分钟，确认安装使用同一份已读取配置，不重新读取源文件。过期、重新选择、页面重新加载或窗口关闭后，需要重新预检。写入失败及响应丢失都有明确提示，界面保留原请求供重试；不会通过新 ID 重复创建同一主题。

## 受控布局

当前工作台统一使用六入口侧栏、页面工具栏与响应式阅读布局，五套内置主题及外部主题继续决定配色、受控字体、圆角和密度。主题格式中的classic/study布局标识保留兼容，统一页面框架由应用提供。

宽度不足时导航转为紧凑入口，辅助信息可隐藏，偏好仍保存和备份。工作台的题库窄窗使用“返回题目列表”切回原范围；练习窄窗按题干、我的答案、揭晓、参考和自评顺序排列。正文保持可读，代码内部横向滚动，操作区留在文档流中。练习中六个页面入口可见但禁用，使用“保存并返回”离开。外观入口仍可使用，不承担练习导航，也不重建会话或草稿。

全新的布局能力需要升级应用。本格式不支持自由拖拽、任意面板结构、命令面板或主题自定义快捷键。

## 制作主题包

第一版使用单个 UTF-8 JSON 文件，扩展名 `.ep-theme.json`，不使用 ZIP。单包最多 **256 KiB**，最多安装 **100** 个外部主题。可从两个完整示例复制修改：

- [纸页墨色](../themes/examples/paper-ink.ep-theme.json)：纸页与墨色、衬线字体、紧凑间距。
- [电路夜航](../themes/examples/circuit-blue.ep-theme.json)：蓝色、宽松间距与圆角风格。

两个示例配置采用 CC0-1.0，仅适用于这两个配置文件，不改变应用许可。

所有以下字段必填，任何层级的未知字段都拒绝。不接受 JavaScript、HTML、任意 CSS、图片、字体文件、外部资源地址或本地资源路径；元数据按纯文本显示，不作为代码或资源加载。

| 字段 | 类型与范围 |
|---|---|
| `formatVersion` | 固定数字 `1` |
| `id` | 1～64 字符，以小写英文字母开头，由小写字母、数字、点或连字符分隔段组成，例如 `local.paper-ink`；不能使用 `builtin.` 前缀 |
| `name` | 1～60 字符名称 |
| `version` | `主版本.次版本.修订号`，每段为 0～999999 的十进制整数，无多余前导零；例如 `1.0.0`、`1.1.0`，不支持预发布后缀 |
| `author` | 1～100 字符作者 |
| `description` | 1～300 字符简述 |
| `license` | 1～200 字符许可说明 |
| `light`、`dark` | 两套完整颜色对象，字段见下表 |
| `presentation` | 字体、圆角、密度、布局的受控对象，字段见下表 |

文本元数据不能包含换行或控制字符。颜色必须是六位十六进制 `#RRGGBB`，不接收颜色名称、透明度、函数或 URL。浅深色分别配置，不自动反转。

| 颜色字段 | 用途 |
|---|---|
| `background`、`surface`、`sidebar` | 应用背景、内容表面、导航表面 |
| `text`、`muted` | 主要与次要文字 |
| `line` | 分隔线及边框 |
| `accent`、`accentSoft`、`accentInk` | 强调/主要按钮、浅强调背景、按钮文字 |
| `codeBackground`、`codeKeyword`、`codeValue` | 代码背景、关键字、值/字符串 |
| `error`、`errorSoft` | 错误文字与错误背景 |
| `focus`、`success` | 焦点与成功状态令牌 |

| 呈现字段 | 可选值 |
|---|---|
| `font` | `system`：本机微软雅黑/Segoe UI/系统无衬线回退；`serif`：Georgia/微软雅黑/系统衬线回退。代码仍使用本机等宽字体 |
| `radius` | `square`：2px；`soft`：8px；`rounded`：16px，作用于支持主题参数的面板 |
| `density` | `compact`：16px；`comfortable`：24px，作用于支持主题参数的间距 |
| `layout` | `classic` 或 `study` |

用户字号始终优先于主题风格。请分别检查正文、按钮文字、代码、焦点和错误提示的颜色对比；颜色格式合法不代表配色一定易读。尤其不能默认浅陶土色适合白色小字。内置 Claude 浅色主按钮采用经检查的深陶土 `#A84D35`。

更改自己的主题时保留 ID，提升版本后重新导入；创建不同主题时使用不同 ID。显示名称可以相同，身份以 ID 为准。

## 存储、迁移和恢复

主题配置、选择和布局偏好与学习数据保存在同一数据库。旧 palette 保留兼容，当前主题选择以 theme_id 为准；支持的旧结构均按数据保护契约先保护备份再事务迁移，失败停止，不重建空库。

完整备份包含外部主题完整配置、当前主题、明暗、字号、两项布局偏好以及原有学习数据。恢复摘要显示这些信息。旧备份先在副本中迁移和校验，源文件保持；损坏主题配置、缺失当前主题或坏备份不得覆盖现有数据。

正常库中当前主题缺失或单个配置损坏时，明确提示并临时使用松间绿，数据库中的原选择保留供修复。数据库本身读取失败会显示错误，不返回空主题目录或默认成功。

不同程序支持的结构范围以当前交付说明为准；旧程序不能打开已升级到更高结构的数据。需要试用不同版本时使用独立数据目录，不让旧程序读取新版正式库。
