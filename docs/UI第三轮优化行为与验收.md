## 四项实现

| 项目 | 实现与验收点 |
| --- | --- |
| 分类列单层滚动 | 分类标题、搜索和全部分类入口保留在顶部；分类树占剩余空间独立滚动。父列/details/导航不再叠加滚动条。中窄窗仍保留列表→详情→返回流程，不改题目列表和详情的独立滚动。展开大量分类、搜索及17/22px下检查滚动容器数量与第20题定位。 |
| 长答案就近返回 | 保留顶部“保存并返回”，常驻底栏增加次级“保存后返回”，共同调用原onHome保存流程，失败不离开、不丢输入。底栏继续按实际高度留白，顶部/中部/末尾均检查入口和最后一行不被遮挡。 |
| 板块首屏 | 仅在板块页将继续练习卡压成专题/进度横条，原创建条件默认收起且可展开；标题/本机题数/管理入口合并，搜索、拓展、有题筛选及规则说明同工具区。新增“仅显示有题板块”只改变展示，默认关闭，不写分类归属或改变队列。短摘要后仍可展开完整原文，卡片同排伸展且操作对齐。目标为1440×900、17px、有活动轮时首排不超过450px并完整看到两排。 |
| 窄窗与列表密度 | 唯一“查看参考答案”移入常驻主要操作区，继续沿原reveal事务与防重复保护，未揭晓不挂载答案/历史。窄窗只减少间距，输入默认200px、最小180px，正文仍17/22px实测。列表以完整题名和组合元信息两层展示；专题明确时仅视觉隐藏重复来源名，保留完整可访问名称及题号分隔符；全部专题时仍显示来源，详情保留完整信息。短行目标72～88px，长标题自然增高，不做行数截断。 |

设置真实页签、未应用外观保留、宽窗折叠偏好/窄窗无假按钮、学习记录前三条、13专题导入确认和完整快照风险说明均保留原回归。新按钮不增加保存接口或第二套状态；“内容更新待复习”仍仅为浏览条件，不进入选题。
