# V0.0.0 个人测试版使用与反馈

程序：V0.0.0测试版，构建 **20261024.4-v000**；题库：**bank-20261024.1-full433**；数据库结构：**9**。题目难度是题目属性，个人“不会/不熟/掌握”是学习记录，两者独立。

## 启动与导入

1. 打开[交付目录](../release/V0.0.0-personal-20261024.4/)，进入`win-unpacked`，双击`embedded-practice.exe`。保留整个目录，搬移时整体复制；不需要单独安装Node。
2. 核对页脚`V0.0.0 测试版 · 构建 20261024.4-v000`。本版保留应用身份与原数据位置，已有结构9学习数据继续识别，旧结构按既有保护迁移流程处理，数据库不随产品版本号归零。
3. 已有学习数据时，先到“设置与数据 → 导出完整备份”，选数据文件夹外的位置保存。不要用文件管理器复制正在运行的数据库作为备份。
4. 进入“题库 → 导入题库”。交付目录的`题库`文件夹只放13份可导入专题，可以一次多选全部；题目与答案都在各自文件中。仓库维护入口见[完整题库](../question-banks/releases/v000-20261024/README.md)，跨目录选择不方便时可分专题/板块导入，每份仍需保持完整快照。
5. 核对预览后确认。全新库应新增419；恰好已有原GPIO78、UART30和通用10题且没有自行改题时，本批预期新增301、内容更新108、不变10；再次导入同文件应不变419。个人库有其他内容或改动时，以实际预览为准，不用本示例数字覆盖判断。
6. 新专题默认未分类；用题库中的“分类管理”按交付目录的专题归属表创建板块并保存归属。重复导入已有专题保留原分类；文件名/文件夹不会自动建立本机分类。

本批题数：STM32 313、通信协议63、MCU与外设原理17、存储与文件系统22、C语言4，共419。GPIO原专题和题号按用户选择保留；UART原30题的专题身份不变，当前同专题已扩为68题。

## 练习、退出与恢复

从板块进入专题，或在“开始练习”选择条件。已有练习点“继续练习”，会读取原固定队列和原内容版本；若要使用刚更新的答案，明确结束旧轮后开始新轮。方案只填入条件，不替换旧轮。

输入后留意“已保存”。正常退出会提交尚未到自动保存时间的草稿；强制结束不能保证尚未提交的按键恢复。若保存失败，保留输入并使用“重试保存/重试原操作”，先处理保存问题。

定期从程序导出完整备份。恢复前选择备份预览，确认题数和内容；恢复会替换**全部当前数据**并重启，程序先保护当前数据。不要把其他测试库或初始题库数据库恢复到已有个人学习库上。旧结构8及更早的程序不能打开结构9数据。
