# 第三批：个人笔记、轮次复盘、作答对照与Markdown导出

2026-10-27，用户询问未完成目标并要求有目标就继续。本批实现第三批，保留前两批源码/旧交付，继续离线与独立数据。本批构建20261027.5-study-assets、产品0.0.2、结构13；后续内容差异和方案排序另批推进。

## 个人笔记

每题按稳定身份独立保存纯文本（包括粘贴代码），与轮次作答/题库版本分开，跨轮/重导入/归档保留。上限1MiB，停止输入500ms自动保存；离开题目/正常退出/导出/恢复前等待确认。失败保留输入，阻止丢失修改的切换；响应未知按原文本和原修订重试，过期编辑拒绝覆盖，明确重新读取会先确认放弃未保存内容。

练习中揭晓前不挂载/请求笔记，揭晓后仍需主动打开；新题/新轮默认折叠。题库详情可主动打开。笔记不作为Markdown执行，完整备份恢复包含内容/修订/时间，重导入不写笔记表。

## 按轮复盘与作答对照

学习记录新增按轮入口，只列已结束/已完成轮，按时间倒序20条分页，可按所含专题找轮次。摘要展示本轮原范围/条件/模式/来源及真实数量；选择轮次后只读分页元数据，主动展开单题才读取当时题干/已保存作答/已揭晓答案。排队但未作答的题也保留本轮位置，显示“尚未揭晓”“无文字作答”等已知状态，不据此推断是否曾进入，不补造历史。

同题历史可主动选两次不同轮/位置（跨页可保留两个选择），确认对照才加载两次原记录。并列显示当时作答/自评/时间和内容版本，版本不同时明确提示并分别保留题干。只描述自评变化，不生成系统正确率或客观能力评分。所有复盘/对照查询只读，不揭晓当前轮或解除更新标记。

## Markdown材料导出

固定题单或已结束轮可手动导出。确认页明确范围、题数、版本规则及内容选项：仅题目；题目＋参考答案；题目＋自己的作答＋当前个人笔记。默认仅题目，选答案/个人内容是独立明确动作，导出不改变揭晓/自评/复习标记。

题单按当前有效版本/身份顺序导出，归档/失效拒绝整批并提示处理，不静默补题；题单个人模式仅取该当前版本最近一次已结束轮保存的实际记录，无记录明确留空。轮次导出沿当时固定版本/顺序，个人模式用本轮作答。笔记均为导出时已保存的当前笔记，明确不是当时笔记快照。未保存内容先保存，失败不导出。

每次最多500题，正文累计50MiB、图片累计100MiB，超限拒绝不截断。Markdown和独立同目录资源文件夹一起保留；只复制已入库且属于该版本的图片，不读源文件/网络。以新资源文件夹和暂存Markdown写入，文件失败不留下半份成功报告，旧目标文件在最终替换前保持；资源路径由主进程生成，拒绝写进应用数据目录。保存位置只来自系统对话框，渲染层不传任意路径或内容。

## 验证和边界

结构13新增个人笔记表，旧库一致性保护备份后事务迁移，原轮/题单/条件/队列保持；坏笔记与关联拒绝恢复。逐文件两轮复查记在代码复查记录，原始失败和运行检查分开保存，所有自动化使用新临时数据目录。独立试用不更换个人桌面、不自动导入或迁移个人库，不自动提交/推送。安装器、系统DPI/IME、多屏/长期/硬件和VMware原边界保持。
