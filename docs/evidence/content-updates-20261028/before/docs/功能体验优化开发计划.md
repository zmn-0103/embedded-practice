## 本批实施范围

先落地用户最后推荐的第一批：本轮再练、不会＋不熟联合筛选、方案重命名/修改/另存。现有实际匹配题数复用。固定题单、题目清单、笔记、轮次复盘/对照、Markdown导出及版本差异按下列后续批次推进；置顶和最近使用排序另批补充。

- 再练仅从指定已结束轮次的固定队列和本轮自评取题。分别支持不会、不会＋不熟、仍未揭晓的跳过题、已揭晓未自评题及全部原题；可选原顺序或重新随机。未揭晓且未跳过的题只在“全部原题”中包含，不冒充跳过或未自评。
- 再练沿用来源轮保存的题目、答案、标题和属性版本，包括其后更新或归档的题。开始前明确版本规则、范围及题数，不补入当前题库的其他题；新轮草稿/揭晓/自评均为空。新旧轮相互独立，沿原请求回执和事务保护防止重复建轮。
- 联合筛选基于当前内容版本对应的最近自评，不纳入已过期自评；题库列表、匹配数、方案和建轮一致。
- 方案可只改名，也可用当前配置更新所选方案，另存使用新身份。更新核对原名称和完整条件，拒绝过期编辑和同名覆盖；结果未知时按原操作重试。选用/编辑不自动建轮，不改变活动练习。
- 数据库升级到结构11，保存再练来源，并为新增持久化筛选语义划清旧程序兼容边界。旧库升级前一致性备份、事务迁移；备份恢复包括来源与方案。所有测试使用独立临时目录。
- 复用现有工作台、主题变量与受限IPC，不新增依赖。逐文件Bug轮和可维护性轮见代码复查记录；实际结果单独写入验收记录。本批不更新个人桌面或正式学习库。

## 用户优化方向与后续批次

目标是“选题更自由、练习更顺手、复盘能接着行动”，重点为减少重复操作、自由选题、知道哪些内容需要复习、留下自己的积累；保留现有搜索、收藏、自评、历史、方案和断点续练作为基础。

1. 练后行动：仅再练本轮不会、不会＋不熟；跳过/未自评分别选择；原题重练可用原顺序或重新随机。新记录不覆盖旧作答，更新/归档时明确版本政策。
2. 勾选组卷与固定题单：支持跨专题选择明确题目身份。动态方案存条件，固定题单存身份；遇到归档或失效提示处理，不静默凑数。
3. 个人笔记：文字、代码粘贴、自动保存、导出；跨轮保留、导入不覆盖、揭晓前隐藏，纳入完整备份恢复。作答记录独立于笔记。
4. 方案补强：重命名、修改、另存、常用置顶、最近使用排序、实际匹配题数、联合自评。填入不建轮，修改不改变活动轮。
5. 本轮清单：显示位置、未揭晓、已揭晓未自评、三种自评和曾跳过；跳转前保存，失败留原题；查看不揭晓或改变队列。收藏与本轮跳过分开。
6. 轮次复盘与两次作答对照：按轮查看范围、题目、作答、结果；主动选同题两次记录，题目版本不同则提示；只描述自评变化，不生成客观能力评分。
7. 内容更新复习：题干和参考答案新旧差异、从更新题中选一批练习、保留旧轮快照。只看差异不标记已复习，答案差异须明确查看才展示，同步练习规则。
8. 本地Markdown导出：选定题单或轮次，可选仅题目、题目＋参考答案、题目＋本人作答＋个人笔记；导出前说明范围和包含内容，可用于Obsidian、打印或面试准备。

| 批次 | 内容 | 收益 |
|---|---|---|
| 第一批 | 本轮再练、联合筛选、方案编辑另存 | 接着复习并减少重复配置 |
| 第二批 | 勾选组卷、固定题单、本轮清单 | 准确控制题目与回看 |
| 第三批 | 笔记、轮次复盘、作答对照、Markdown导出 | 沉淀个人理解与复习资料 |
| 第四批 | 内容差异、更新题集中复习 | 有序学习持续更新的题库 |

每日目标、打卡、计时、模拟考试为后续候选；自动判分、智能推荐、到期复习另定义产品规则。本批不以图表数量替代上述实际流程，也不增加在线依赖。A/B/C/D图仅有用户文字描述，本批延续现有设计，不宣称重新查看参考原图。
