# 项目模块职责

本页从原AGENTS.md“模块职责”迁入，保留原职责与限制。表中的代码路径均相对仓库根目录；修改涉及的模块前，结合实际源码核对职责和调用关系。

| 位置 | 职责与限制 |
|---|---|
| `src/main/ipc/` | 请求路由、主进程输入校验、调用来源校验和错误转换 |
| `src/main/services/library/` | Markdown 解析协调、导入预览、确认、版本比较、查询与归档 |
| `src/main/services/practice/` | 选题、固定队列、草稿、揭晓、自评、会话导航与恢复 |
| `src/main/services/resources/` | 图片类型与路径校验、资源入库、受控读取 |
| `src/main/services/backup/` | 一致性备份、恢复预览、保护性备份、替换与失败回退 |
| `src/main/database/` | 数据库连接、迁移、事务和持久化；事务边界服务于完整业务操作 |
| [category-repository.ts](../src/main/database/repositories/category-repository.ts) | 本机板块创建、改名、移除与专题归属；分类变化更新题库修订号，业务边界见[分类树契约](分类树行为与验收.md#本批契约) |
| [practice-plan-repository.ts](../src/main/database/repositories/practice-plan-repository.ts) | 方案定义的读取、保存、删除及原 ID/条件重试；不保存练习队列或递增题库修订号，见[练习方案契约](练习方案行为与验收.md#最小范围) |
| `src/main/workers/` | 批量解析、资源处理等后台工作，避免阻塞窗口响应 |
| `src/preload/` | 只暴露白名单桌面能力，不提供任意文件、SQL 或 IPC 入口 |
| `src/renderer/src/` | 展示、输入与交互状态；不直接访问文件系统、数据库或 Node.js |
| `src/shared/contracts/` | 共享 TypeScript 类型、校验契约与错误结构，不引入主进程专用能力 |
| [主题契约](../src/shared/contracts/themes.ts)与[内置注册](../src/shared/themes.ts) | 严格主题格式、版本比较与受控变量解析；内置和外部主题通过同一渲染路径生效 |
| [theme-repository.ts](../src/main/database/repositories/theme-repository.ts) | 外部配置完整入库、哈希/身份校验、安装更新幂等、容量限制及卸载当前主题的事务回退；不触及学习表 |
| [useAppearance.ts](../src/renderer/src/useAppearance.ts) | 显示/目录读取、已应用快照、保存与焦点恢复、缺失主题提示；只更新根变量/布局属性，不重建业务组件 |
| [ThemeManager.tsx](../src/renderer/src/components/ThemeManager.tsx)与[ThemePreview.tsx](../src/renderer/src/components/ThemePreview.tsx) | 安装更新卸载交互与独立预览；通过受限桥接工作，不接收任意CSS或文件读取能力 |
| `tests/` | 单元、数据库集成、组件、Electron 流程及独立测试样本 |
| `question-banks/` | 真实初始题库、试用选集、原始题答与逐题来源映射，以及模板、显式示例和配图；保持稳定 ID 与审阅状态，不自动导入，也不作为运行数据库位置，见[题库与导入契约](题库与导入契约.md) |

纯解析、变更比较、队列生成等逻辑尽量与 I/O 分离。沿用现有模块边界，不为填满目录创建空实现或无价值转发层。

板块入口由[BoardEntrance.tsx](../src/renderer/src/components/BoardEntrance.tsx)只读展示本机导航，[board-catalog.ts](../src/renderer/src/board-catalog.ts)将规划与真实同名分类合并并汇总计数；规划键不作数据库ID。入口只跳转既有题库范围，不建立分类/题目或练习轮。难度用[DifficultyBadge.tsx](../src/renderer/src/components/DifficultyBadge.tsx)统一展示，底层字段和旧轮快照保持。

分类表单入口为 [CategoryManager.tsx](../src/renderer/src/components/CategoryManager.tsx)。方案由 [usePracticePlans.ts](../src/renderer/src/usePracticePlans.ts) 管理异步状态与重试，[PracticePlans.tsx](../src/renderer/src/components/PracticePlans.tsx) 负责表单展示；均沿受限桥接调用主进程，界面不直接读写数据库。

2026-10-27追加：[PracticeRepeat.tsx](../src/renderer/src/components/PracticeRepeat.tsx)只展示结果页再练范围/题数/版本政策，交由PracticeWorkspace沿原start/run与回执创建新轮。[practice-repository.ts](../src/main/database/repositories/practice-repository.ts)仅从指定已结束轮的practice_items复制原题目版本与属性，保存来源；原队列/作答不改。方案仓库另支持带原条件核对的update；QuestionFilters的联合自评沿公共question-selection谓词，界面不维护第二套选题逻辑。结构11与备份校验同步支持来源列。

## 学习工作台（20261025.3-workbench-e）

[App.tsx](../src/renderer/src/App.tsx)提供六入口、统一侧栏与轻工具栏，保留跨页保存、关闭及数据操作守卫。[LearningOverview.tsx](../src/renderer/src/components/LearningOverview.tsx)复用原PracticeWorkspace活动轮上下文和learning.read；只展示真实摘要、填入题库条件或调用原继续方法，不维护另一份练习会话。

[LibraryBrowser.tsx](../src/renderer/src/components/LibraryBrowser.tsx)管理题库宽窗三栏及窄窗列表/详情切换，保留原Portal、请求代次、过滤、分页与阅读节点；分类管理在三栏上方使用全宽原表单。[PracticePane.tsx](../src/renderer/src/components/PracticePane.tsx)负责题干/作答/揭晓布局，原控制器仍负责保存和推进；[PracticeFavorite.tsx](../src/renderer/src/components/PracticeFavorite.tsx)只调用原收藏能力并参与保存/关闭守卫。参考答案和练习历史在揭晓后才挂载。

[workbench-shell.css](../src/renderer/src/styles/workbench-shell.css)与[workbench-pages.css](../src/renderer/src/styles/workbench-pages.css)复用受控主题变量和字号，提供统一布局；主题JSON不获得任意CSS或面板能力。[ListRequest](../src/shared/contracts/library-desktop.ts)新增可选contentUpdatedOnly，只在[library-reader.ts](../src/main/database/repositories/library-reader.ts)的题库列表/计数中应用固定绑定条件，不进入QuestionFilters、练习方案、会话快照或公共选题SQL。详见[行为与验收](UI学习工作台行为与验收.md)。


## 第二批选题与清单（20261027.4-practice-control）

[question-set-repository.ts](../src/main/database/repositories/question-set-repository.ts)负责题单定义/CAS更新/元数据预览和事务上限，定义不改变题库修订号或学习记录。[question-sets.ts](../src/shared/contracts/question-sets.ts)定义严格身份、预览与组卷请求；沿原library IPC和服务生命周期。question-set-schema.ts只增加题单两表和会话来源列，备份校验同步检查定义与关联。

LibraryBrowser持有同次打开的临时勾选；[QuestionSets.tsx](../src/renderer/src/components/QuestionSets.tsx)与[useQuestionSets.ts](../src/renderer/src/useQuestionSets.ts)管理定义、原操作重试和载入；[SelectedPractice.tsx](../src/renderer/src/components/SelectedPractice.tsx)在开始练习页单独预览并确认，主进程再次核对全部当前版本。PracticeWorkspace仍沿原建轮/替换守卫，无第二套会话管理。

[PracticeOutline.tsx](../src/renderer/src/components/PracticeOutline.tsx)延迟读取50题元数据，交由原practice-controller执行保存后jump。主进程practice-repository只读取队列元数据，跳转复用原草稿/事务/回执。App关闭检查对未确认学习写入使用同步引用，设置和恢复保持原生命周期。

## 第三批个人积累与复盘导出（20261027.5-study-assets）

study.ts定义六个受限接口；note-schema/note-repository负责稳定身份笔记及期望修订/原命令幂等，round-reader只读结束轮摘要/分页元数据/明确单题快照，material-reader在同一读取事务准备明确题单/轮次材料。export-markdown只转换受控Markdown和图片绑定，write-material只负责已准备内容在系统所选位置原子发布；主进程library IPC沿原任务取消/恢复暂停/关闭生命周期，不允许渲染层传路径、SQL或材料正文。

note-controller负责500ms自动保存/冲突/未知结果原操作重试；note-saves协调跨题/跨页/关闭/导出前保存，并仅同步已加载且无本地改动的同题编辑器。PersonalNote复用题库/揭晓后练习/轮次详情；新轮揭晓前不挂载。RoundReview/RoundDetail提供结束轮查询，AnswerComparison在主动选两条确认后才加载，MaterialExport复用同一导出入口。App保留原保存/数据操作守卫，恢复自身忙态与等待中的笔记分开处理。
