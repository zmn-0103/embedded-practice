# 练习、保存与统计契约

本页从原AGENTS.md同名章节迁入，保留既有练习、保存和统计约定。需求基线见[计划书](../计划书.md)。涉及分类范围、专题归属、会话分类快照或分类统计时，另读[分类树契约](分类树行为与验收.md#本批契约)；涉及方案保存、条件填入与失效引用时，另读[练习方案契约](练习方案行为与验收.md#最小范围)。这些数据的迁移、备份与恢复同时遵守[数据保护契约](数据保护与桌面边界.md)，实际检查结果见[验收记录](验收记录.md)。

- 每轮保存固定、不重复的题目队列与对应内容版本；重启保持队列和位置，导入更新不得中途替换本轮内容。
- 每题首次进入隐藏参考答案，揭晓前答案正文不得挂载到页面正文或无障碍阅读树。新一轮不自动展示上次答案、历史作答或揭晓状态。
- 允许空输入揭晓；搜索默认不展示参考答案片段。
- 自评只在揭晓后可用；揭晓、未评价、跳过、自评及收藏的含义分别处理，不显示未经定义的“系统正确率”。
- 同一轮同一题修改自评更新原记录，不重复累计次数；新一轮产生新历史。自评保存与推进位置必须同一事务完成，处理重复点击和重试。
- 输入停止 500ms 后保存草稿；切题、揭晓、返回首页和正常退出前提交待保存内容。使用递增修订号拒绝过期请求覆盖新内容。
- 明确展示保存中、已保存和保存失败；失败时保留输入，阻止依赖该次保存的切题并允许重试，不宣称未提交按键可在强制结束后恢复。
- 最多保留一个可继续的活动会话；无匹配题目时不创建空会话。收藏与掌握程度独立。

## 2026-10-27 本轮再练与联合筛选

- “不会＋不熟”是当前内容版本的最近自评联合，仍与其他选题范围取交集；不纳入旧版本自评，不表示系统正确率。列表、匹配数、保存方案与新轮选题共用SQL谓词。
- 结果页可明确选择本轮不会、本轮不会＋不熟、仍未揭晓的跳过题、已揭晓未自评题或全部原题。已揭晓且曾跳过的题按其当前本轮揭晓/自评状态处理，未进入且未跳过的题不冒充跳过或未自评。
- 再练来源必须为明确已结束/已完成轮次，只从其固定队列和本轮记录取题；与整个题库的最近自评筛选分开，不补入来源外题目。
- 第一版再练明确沿用来源轮的题目、答案、标题及属性快照，包括其后更新或归档项；开始前说明这一政策、范围和实际题数。新一轮可按原顺序或重新随机，首次创建后固定。
- 新轮使用新身份，草稿、揭晓、自评和跳过重新开始；原轮全部记录保留。来源身份与选择范围持久化并纳入完整备份，继续练习时仍说明沿用来源快照。
- 再练沿用原建轮事务/回执/活动轮替换守卫；来源错误、0题或写失败不得结束原活动轮。响应未知时锁定选择、按原请求重试，不重复建轮。
- 旧版本作答只影响对应历史；已有当前版本自评时，旧版本再练不能把其覆盖为过期状态。未练习新内容也不凭旧内容再练解除更新标记。
