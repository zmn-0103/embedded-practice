# 项目概况

本页记录项目定位和技术背景。内容从原AGENTS.md迁入，实际依赖版本以package.json与package-lock.json为准；当前交付和阶段状态分别查阅[交付说明](当前试用版本交付说明.md)、[开发记录](开发记录.md)与[验收记录](验收记录.md)。

- 本项目是 Windows 离线桌面软件，暂定名称“嵌入式刷题本”，内部标识 `embedded-practice`，默认发布验证环境为 Windows 11 x64。

- 当前采用 Electron + React + TypeScript + electron-vite，SQLite + better-sqlite3；已有 Vitest 与 Playwright，React Testing Library 按组件测试需要再接入，打包采用 electron-builder。实际版本以 `package.json` 与 `package-lock.json` 为准。

- 名称中的“嵌入式”描述题库领域，本程序本身不使用 MCU、RTOS 或固件构建流程。涉及题库中的嵌入式知识时，另外核实适用条件与技术来源。
