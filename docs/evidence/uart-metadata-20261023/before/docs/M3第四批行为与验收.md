# M3 第四批：学习记录总览

日期：2026-10-21。接续单题历史与更新标记，本批只完成学习记录总览及收藏/历史入口。主题/字号、完整备份恢复及 M4/M5 不在本批内，数据库保持结构 4，无新依赖。

## 行为口径

- 首页增加“练习与题库”“学习记录”两个页面入口。练习期间入口隐藏，离开练习沿用原保存握手；切到记录页不卸载练习控制器或丢弃已准备的导入预览，返回可继续原轮。
- 总览默认统计全部专题的活动题目，可选专题或归档题目；按稳定题目身份去重，只统计当前内容版本，不把历史轮次次数当作题数。
- “已揭晓题数”只计入当前版本真实作答行的揭晓；“已自评题数”和三种分布采用对应当前版本的最新题目自评状态。同轮改评不重复计数，新轮仍按题去重。只有旧自评状态而无真实作答的兼容数据只计入自评，不补造揭晓或历史。
- 收藏独立统计，更新待复习复用既有版本口径。只排队、草稿或跳过不计入揭晓或自评，不显示系统正确率。
- 下方复用题库浏览，固定到相同专题/活动或归档范围，默认只看收藏；可搜索、筛选或取消只看收藏，主动展开单题历史。列表过滤不改变上方范围总览。
- 查询为只读事务，不包含作答/答案正文，不写统计缓存。失败显示错误和重试，不伪造零；切换范围时旧响应不能覆盖新范围，收藏后重读总览与列表。

## 验证要求

严格契约/可信 IPC；真实 SQLite 的空库、当前版本、重复轮次、同轮改评、未评价/跳过、旧状态兼容、更新/归档恢复及只读；真实 Electron 的范围/收藏/历史、失败重试、晚到响应、导入预览保留和正常关闭/重开。全套原 452 项单元与每种形态 75 项桌面场景保留，逐文件先 Bug 后可维护性复查，实际失败/结果另写验收记录。
