# M4 第三批：数据位置与诊断入口

日期：2026-10-22。用户授权继续开发，补齐计划书第 3.1 节“设置与数据”中的数据位置。

## 范围

显示本次运行实际配置的数据目录、保护性备份目录、诊断日志目录与日志文件位置，提供三个固定文件夹打开按钮。读取不创建目录、不连接数据库；打开时仅可在主进程选择固定目录，必要时建立空的 backups/logs 目录，不读取或执行任意文件。数据库不可用时仍能看到位置与诊断入口；启动失败提示给出具体日志位置。

保留 M4 已有备份恢复、保存与关闭流程，目录操作参与恢复/关闭暂停，失效来源或晚到操作不能打开文件夹。结构保持 6，依赖/锁文件及原练习草稿控制器保持。只用独立临时数据测试，系统文件管理器自动化使用明确替身，不能代签原生 Explorer 人工体验。M5 正式题库/新 NSIS/安装升级/完整离线与性能不在本批。

## 验收目标

- 设置页显示实际路径（含中文/空格），读取/打开后原题库、图片、草稿、队列、历史、自评、收藏和设置不变。
- 系统打开失败、目录不可用、非法输入与不可信来源均明确拒绝且可重试；无任意路径/文件/SQL 能力。
- 只读位置不造默认成功；数据库不可用仍能查位置；新操作/退出/恢复期间的并发及晚到响应受控。
- 既有 533 单元及两种运行形态各 142 桌面场景保留；逐文件两轮复查，实际检查及未验边界另记。

## 已实现行为

“设置与数据”新增“数据位置与诊断”面板，显示当前实际数据目录、保护性备份目录、诊断目录与日志文件。三个按钮分别请求系统打开对应文件夹；没有记录时日志文件可尚未生成。保护目录与用户在导出框另选的文件位置明确区分。长路径在面板内换行，暗色和 22px 字号下的窄窗口仍能看到三个按钮。

主进程只接受 `data | backups | logs`，校验可信窗口、主 frame、页面地址及参数；预加载不暴露任意文件/目录/SQL 入口。读取无文件系统与数据库副作用，打开只允许三个固定目录，子目录按需非递归建立。非目录、junction、路径变化和系统打开错误明确失败，可重试。系统返回内容不直接写入界面或日志。

目录操作参与既有关闭和恢复生命周期：重复打开返回忙碌，正常关闭注销接口并等待在途操作；恢复暂停并排空操作后才开始保护性备份。导航、来源变化、关闭后的异步任务不能晚到打开目录。界面显示“已请求打开”，不将系统调用成功表述成 Explorer 窗口已经人工验收。数据库不可用时仍显示实际位置；无法建立窗口的启动错误提示增加实际数据/日志路径，生产错误没有被屏蔽。

## Windows 路径缺陷及限定修复

本批隔离实测复现已有目录实际叫 `Logs`，配置路径为 `logs` 时被字符串比较误拒。同类检查还确认 `Backups` 下保护性备份/内部文件选择、`Backup-Staging` 暂存也有相同问题。原始失败 API 结果保留于 [位置探针](evidence/m4c/windows-case-first.json)和[备份探针](evidence/m4c/backup-case-first.json)。

修复使用平台相对路径关系判断是否仍为同一位置，系统接收规范化后的真实目录。现有文件、junction、硬链接、运行库/伴随文件和事务/哈希保护保持。新增真实 Windows 目录回归验证打开、导出、内部预览、保护性备份、恢复和独立进程重开；复制来源是已经一致性导出并校验的文件，不是正在写入的数据库主文件。
