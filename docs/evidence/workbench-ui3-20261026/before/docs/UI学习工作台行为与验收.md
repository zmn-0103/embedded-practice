## 页面与边界

| 页面 | 最终实现约定 |
|---|---|
| 学习总览 | 默认入口，复用PracticeWorkspace原活动轮/继续方法；位置与已揭晓/已自评分别表达。范围统计复用learning.read，快捷只向题库填入条件，不启动/替换会话。空库提供导入/模板入口，读取失败明确重试。 |
| 知识板块 | 保留全部/未分类、自定义、15基础和7拓展规划；题数/归属来自本机。空板块可看规划，不自动创建分类或空轮。 |
| 题库 | 宽窗分类导航/列表/详情三栏；较窄时显示可返回的独立阅读区，返回保留过滤/分页/选中/已展开内容及同一阅读节点。导入和分类管理可达，加载/失败不冒充当前结果。 |
| 开始练习 | 原完整条件与方案，宽窗左右配置/方案，窄窗顺序排列。10/20/50/全部及顺序/随机原契约保持；方案只填条件、不自动执行，失效引用不扩大范围。 |
| 练习 | 宽窗题干与输入/参考双栏，窄窗题干→我的答案→揭晓→参考→自评。揭晓前参考正文、摘要和历史作答不挂载，自评不可用；允许空输入。动作区文档流，保留500ms草稿及保存/推进/返回/关闭守卫。 |
| 学习记录 | 原范围/当前版本去重统计与收藏/历史；三条进度仅表达现有主观自评分布，没有系统正确率。下方筛选不改变上方范围，旧版本历史按原内容保存。 |
| 设置与数据 | 外观主题/备份恢复/数据位置三分区就地定位，局部预览与保存应用分离；保留五内置/外部安装更新卸载、完整备份及真实路径。恢复保护与回退复用主线修复。 |

六入口固定顺序为学习总览、知识板块、开始练习、题库、学习记录、设置与数据。侧栏折叠、字号/主题切换不重建练习或题库组件。练习中六个跨页入口继续受禁用及事件守卫，明确“保存并返回”。顶部只显示页面位置/离线/外观与受控辅助开关，搜索仍在题库/板块各自原范围内，不新增重复搜索结果。

## 与既有实现的差异

计划将“内容更新待复习”列为已有筛选，但当前源码只有标记和计数。为完成该入口，本批只增加严格ListRequest可选布尔contentUpdatedOnly和原题库只读列表中的固定绑定谓词，计数/分页共用；与原标记相同，按当前内容版本sequence>1且当前版未练习判断。标签候选仍按分类/专题/归档及revision，不受新筛选缩窄。

这个标志不进入QuestionFilters、练习方案、会话快照或公共选题SQL；原建轮/继续语义、数据库结构和题库身份均保持。不进行数据库层重构。

全局工作台框架由应用UI提供，继续使用既有主题颜色、字号、字体、密度与外观偏好，保留主题JSON兼容性和受控变量。原classic/study属性保留兼容，新统一导航/阅读框架不靠主题开放任意CSS或面板。默认不把用户切换为蓝色；蓝色演示使用独立临时目录中的晴空蓝。

原历史检查允许在未揭晓练习时主动回看历史，本计划明确要求未揭晓时历史作答也不进入正文或无障碍树；本批历史入口在揭晓后才挂载。题库浏览历史仍独立主动展开，不计作练习揭晓。原历史数据与请求取消、分页、版本、只读断言继续验证，按新揭晓边界调整交互准备步骤。
