# M0 启动与存储

## 当前实现

启动路径：主进程选择独立数据目录 → 申请单实例锁 → 打开 SQLite → 记录启动 → 建立白名单 IPC → 加载受限页面 → 界面读取状态。

| 文件 | 职责 |
|---|---|
| `src/main/index.ts` | 生命周期、数据目录、启动协调、诊断与关闭 |
| `src/main/window.ts` | 本地页面、开发回环地址与窗口边界 |
| `src/main/database/startup-store.ts` | 等待数据库初始化/升级，执行启动记录事务与关闭 |
| `src/main/database/open-database.ts` | 数据库身份、当前结构 3 初始化与受控 v1/v2 升级 |
| `src/main/ipc/application.ts` | 调用来源、无参数请求和返回值校验 |
| `src/preload/index.ts` | M0 状态、M1 固定题库方法，M2 增加固定练习/关闭方法与代码复制 |
| `src/shared/contracts/application.ts` | 共享类型与 Zod 数据契约 |
| `src/renderer/src/App.tsx` | 本地状态/重试，组合导入/分页内容检查与 M2 练习窗口 |

M1 第四批补充题库预览/提交服务及数据表，见[预览与提交](M1预览与提交.md)。第五批增加固定题库桥接、导入与分页查看，见[窗口与受控内容](M1窗口与受控内容.md)。

M2 第一批增加[顺序练习服务](M2顺序练习与保存.md)和结构 3，第二批接入[练习窗口与保存协调](M2练习窗口与保存.md)。收藏交互与完整备份恢复仍待后续阶段。

## 数据库

- 文件：用户数据目录下的 `practice.sqlite3`。
- `application_id`：`0x45505231`；M0 的 `user_version` 为 1，M1 第四批为 2，M2 第一批起为 3。
- `app_startup` 保留，仅用于 M0 验证，不进入学习统计；M1 新表见上方说明。

| 字段 | 约束与含义 |
|---|---|
| `id` | 主键且只能为 1 |
| `launch_count` | 正整数，每次主进程启动加 1 |
| `last_started_at` | 最近一次启动的 UTC ISO 时间 |

创建初始表与设置数据库标识在事务中执行；启动计数更新与结果 Schema 校验在另一个事务中执行。读取状态不写入数据。连接使用 WAL、FULL 同步和外键约束。

只有无标识、结构版本为零且没有用户对象的空库可以初始化。已知 v1/v2 库经过 SQLite 一致性备份并校验后迁移到当前结构 3；备份失败停止，DDL 失败回滚。非空未知库、其他不支持版本继续报错，不自动重建空库。通用迁移管理和完整备份恢复仍待 M4。

## 桥接接口

调用：`window.desktop.getAppStatus()`，不接受参数。

成功返回应用版本、启动次数与最近启动时间；失败返回错误码和中文说明。界面不获得文件路径、SQL、任意 IPC、原始 Electron 对象或错误堆栈。

主进程同时检查所属窗口、主 Frame、Frame 存活状态、完整页面 URL、参数数量与返回值；预加载再次校验响应。

## 桌面边界

- 上下文隔离、渲染沙箱开启，Node.js 集成关闭。
- 生产加载应用内文件，CSP 禁止内联脚本、外部连接、表单提交与对象嵌入。
- 开发只加载回环 HTTP 地址；仅开发模式为 React 热更新开放必要的内联引导与回环 WebSocket。
- 新窗口、跨地址导航、WebView 和权限请求默认拒绝。
- 开发数据与正式数据默认隔离；自动化仍显式传入独立临时目录。

第五批图片资源读取、外链打开与文件导入均通过对应受限接口实现，未增加任意文件或页面访问能力；生产 CSP 仅 img-src 增加固定图片协议。
