# M3 单题历史与更新标记

日期：2026-10-21。行为基线见[第三批说明](../M3第三批行为与验收.md)，实际结果见[本批证据](../evidence/m3c/README.md)。本批数据库保持结构 4，不新增表、索引或迁移。

## 按需读取历史

`QuestionHistory` 用于题库详情与练习页。默认只显示“查看本题历史”按钮；列表组件未挂载，不请求或渲染旧作答/答案。展开后调用 `desktop.history.list`，点开一次记录才调用 `getEntry`。练习页传入本轮 ID 作为排除条件；题库可检查活动轮已经保存的记录。

两个白名单方法在预加载校验响应，经 `registerLibraryIpc` 校验可信主 Frame、严格请求及结果，再调用现有题库连接上的 `history-reader.ts`。无题目/无记录返回 NOT_FOUND；真实空历史返回总数 0，读取失败返回错误而不伪造为空。关闭时历史 handler 与原题库 handler 一并清理。没有新增 SQL/路径能力或文件入口。

历史身份为稳定题目 ID 加会话/位置。读 SQL 同时核对专题、题号、队列题目与内容版本归属；相同题号的其他专题不能混入。只纳入 `draft_revision > 0`、已揭晓或曾跳过的作答行，单纯排队没有历史；清空后的已保存修订仍是实际记录。旧状态表中只有自评、没有作答行的记录不补造历史。

列表与计数/当前版本同一只读事务，每页 20 条并收敛超出范围的页码；按会话开始时间倒序、会话插入次序倒序和位置稳定排序。列表只取当时标题/专题、版本序号与是否当前版本、模式、会话状态及保存/揭晓/自评/跳过摘要，不取作答、题干或答案全文。摘要 `hasDraft` 使用字节长度，避免含 NUL 的有效文本被误认为空。

单条详情另读实际草稿及固定版本题干/定义/图片绑定，只有已揭晓记录才取参考答案；响应 Schema 也限制答案与揭晓时间必须对应。旧图片沿用当时版本 ID 和入库资源哈希，经原受控资源协议读取，来源移动与新图片替换不会替换旧内容。作答用 React 纯文本 pre 展示，不作为 Markdown/HTML 执行；题干与答案沿用受控 Markdown、高亮和图片组件。

同轮自评修改更新原 `practice_items` 行，历史只显示当前保存值；新轮产生新行。展示明确区分“已保存草稿未揭晓”“跳过未揭晓”“揭晓未自评”和三种自评。曾跳过后再揭晓的条目以当前揭晓/自评展示，同时保留“曾跳过”时间，不把它算成另一次作答或系统正确率。

## 异步响应与阅读状态

历史展开状态按专题/题号/排除轮建立组件 key；改变题目时同步重置，避免旧内容短暂出现在新题。单条详情再按会话/位置 key 隔离。关闭、翻页或卸载时清理 Effect，拒绝旧响应；请求失败可按原页面/记录重读。

练习阅读区原 key 包含轮次、位置与版本；切题或新轮重新关闭历史，同题自动保存/揭晓保持历史展开。列表/详情的 Effect 只依赖标量身份、页码和重试序号，父级保存状态变化不会重新加载历史或夺取焦点。历史查询本身不调用草稿、导航、揭晓、自评或收藏写入。

## 内容更新待复习

`library-reader.ts` 在列表与详情共用的字段查询中派生 `contentUpdated`：最新版本序号大于 1，并且当前版本尚无练习揭晓/有效自评。它复用现有 `practicedSql` 的版本口径，不新增可漂移的状态列。

- 首次导入不标记。题干、答案、引用定义或图片字节变化产生新版本后，未练习新版时标记；从未揭晓过的题也会在更新后标记。
- 标题、难度、标签、顺序与专题名称只改变元数据，不产生新标记；原有未消除的标记继续保留。
- 排队、跳过、读取题库答案、回看历史不消除标记。旧活动轮揭晓旧版本也不消除新版标记。
- 练习中揭晓最新版后即可消除，允许空作答或不自评；当前掌握程度仍只采用对应当前版本的自评。兼容旧状态仅在已有有效当前版本自评时认定已练习，不据此补造历史作答。
- 题库列表和详情显示相同标记。练习后返回首页时题库重新挂载读取最新状态；收藏刷新仍使用原失效通知/过期响应保护。

## 验证与边界

契约与 IPC 单元检查覆盖严格输入/输出、列表不泄露正文、未揭晓不返回答案及诊断脱敏。真实练习服务生成不同状态/轮次的记录，独立比较分页顺序、完整保存原文、同轮改评、跨专题拒绝、空结果及全库业务行在只读查询前后不变。

Electron 场景检查默认零历史请求、DOM/无障碍树隐藏、主动展开、自动保存的实际数据/滚动/焦点保持、晚到列表与详情、真实表名/坏 JSON 故障及重试、旧图片解码尺寸、来源移动/归档恢复/独立重开、元数据与图像更新标记。只有失败注入/响应时序/文件选择边界受测试控制，数据库写入与内容渲染实际执行。它们不代表随机统计、全量性能、完整系统 DPI 或人工体验验收。
