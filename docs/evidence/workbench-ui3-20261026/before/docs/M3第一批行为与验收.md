# M3 第一批：筛选、搜索与收藏

日期：2026-10-21。计划书 M2 第 445～449 行的五项关键软件条件已通过实际 Electron 窗口、SQLite 和失败路径验证，已确认交互缺陷修复通过；开发构建及解包 EXE 各 49 项证据见 M2 第四批。按计划进入 M3，未完成的系统 DPI、完整输入法/剪贴板人工体验及正式题库审阅继续保留，不宣称人工总验收通过。

## 输入与行为

- 题库和开始练习分别提供搜索及组合筛选：专题、精确标签、难度、当前自评状态、只看收藏。
- 搜索对标题、题干 Markdown 和标签作字面子串匹配，英文大小写不敏感；不搜索答案，不返回答案摘要，百分号、下划线和引号没有 SQL 通配/执行含义。搜索最多 256 个字符，首尾空白忽略。
- 多个筛选条件取交集。未练习指当前内容版本既没有揭晓记录，也没有有效自评；排入队列、空草稿和跳过不自动算已练习。兼容旧版本仅保留有效自评的状态。已揭晓但无自评单独显示，不自动归入“不会”。
- 最新掌握状态仅采用对应当前内容版本的自评。更新后的旧自评仍保留，不能用于新版掌握筛选。
- 收藏采用稳定题目身份，接口设置明确布尔目标而非切换；重复设置、响应未确认后的同目标重试保持幂等。收藏不改变自评、版本、导入预览基线或已有活动队列；归档、恢复和重启保留。
- 开始练习使用同一组筛选语义，在原事务内固定队列。无匹配不创建空会话，明确替换时无匹配也不结束原轮。继续练习使用原队列，不重新应用当前筛选。
- 保存失败或响应未确认时不提前显示成功；保留原显示和明确重试方向。请求乱序/组件卸载不得写入另一题的展示状态。

## 修改与验证范围

数据库结构保持 3，沿用现有收藏列、自评与练习表，不修改迁移和旧回执格式。新增筛选字段可省略，旧请求仍按原默认行为执行；不为旧请求自动插入新字段改变回执哈希。

筛选边界为 `src/shared/contracts/question-filters.ts`；主进程 `question-selection.ts` 只拼接固定 SQL，用户值使用绑定参数。题库计数/分页与练习建轮共用条件和稳定排序，读取列表不会返回题干/答案全文。当前版本自评通过 `last_rated_version_id` 判断，已练习状态查实际揭晓记录或有效自评。

收藏写入由 `favorite-repository.ts` 的单语句 UPSERT 完成，只更新 `favorite`；经固定 `library:set-favorite` 通道、可信主 Frame 和严格输入/输出契约。界面先确认结果再更新状态，双击后续 click 与长按重复键被拦截。收藏成功通知首页刷新匹配数，普通题目详情无需重挂载；收藏筛选中取消收藏则重新读取并收敛分页。题库与首页使用同一个 `QuestionFilterFields` 展示组件，各自保持筛选状态；题库点击应用，首页随条件刷新数量。

逐文件完成 Bug 与可维护性两轮复查。契约用单元验证；实际 SQLite 的组合筛选、字面搜索、旧/新版本、收藏写入与重启、固定队列、无匹配替换和故障恢复用 Electron/数据库场景验证。开发和重新生成的 Windows 解包程序分别完整回归，保留 M2 回归；测试仅使用显式独立临时目录。

本批不实现随机模式、单题历史、内容更新待复习展示或主题/字号设置；这些仍为后续 M3 工作。人工验收项单列，不生成新 NSIS，不提交、推送或发布。

## 2026-10-21 复查修复

再次复查确认旧收藏成功响应可能在较新操作之后返回，导致数据库和详情正确而列表错误。本轮按用户要求只修复，不继续扩展功能。详情现在只发送“收藏已保存”的失效信号；父级以当前筛选重新读取最新列表，旧响应不再直接提供列表收藏值。列表读请求沿用过期响应保护，仍匹配的当前详情保留；收藏页取消后题目从当前页移除，才清理选择。详见[修复证据](evidence/m3-fixes/README.md)。

原解包回归还曾出现一次精确坐标漂移，首行仍命中输入框，不能认定遮挡复发。修复任务保留这次失败及独立复测记录，并为原用例增加实际缩放、窗口/屏幕倍率、视口/DPR、滚动事件和输入前后截图，保留精确坐标、焦点及持久化断言；首次偏移根因仍待确认，不以新增诊断或复测通过冒充已解决。
