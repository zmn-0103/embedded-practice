# 方案E第二轮UI优化：行为与验收

2026-10-26后续四项调整见[第三轮UI行为与验收](UI第三轮优化行为与验收.md)。下文保留第二轮r5当时的实现与检查；第三轮已继续调整分类滚动、底部返回/揭晓入口、板块顶部和列表密度。

用户完整要求见[优化目标原文](UI第二轮优化目标.md)。本批基于工作区已存在的方案E实现继续，改前296文件与原始要求保存于[evidence/workbench-ui2-20261026](evidence/workbench-ui2-20261026/)。原第一轮方案E、已交付程序和失败证据保留。

产品0.0.1，构建20261026.1-workbench-e-ui2，数据库结构10。除备份文件编号比较改用精确整数外，原IPC、数据库结构、草稿控制器、题库内容与依赖不变；所有运行明确使用独立临时目录。

| 用户目标 | 本批行为 |
| --- | --- |
| 1. 题库视口与滚动 | 宽窗顶部筛选和结果数、分类/列表/详情三栏；列表与详情各自纵向滚动，代码横向滚动仍在代码块内。选题定位新详情标题，列表位置保留。分页水平布局，题目按钮独立样式；窄窗返回恢复列表滚动、页码、选中、筛选和同一阅读节点。 |
| 2. 精简练习页 | 专题/难度/标签只在题头显示一次；当前位置、揭晓、自评各自表达。保存并返回在顶部继续原保存流程；宽窗双栏，窄窗依原顺序阅读，输入默认200px且可调整，未揭晓占位缩短。 |
| 3. 自评与保存失败 | 不会/不熟/掌握等尺寸独立分组，暂不评价为次要推进；上一题/结束独立。本轮底部固定操作区按ResizeObserver测得高度预留空间，错误与重试直接出现在操作区。保留输入、防重复、失败阻止推进与离开。 |
| 4. 窄窗导航 | 1199px及以下固定图标栏并隐藏不可展开按钮，保留简洁应用标识、名称和悬停提示。宽窗导航偏好保持，缩放本身不写偏好；练习中页面入口仍受保存守卫约束。 |
| 5. 设置分区 | 外观/备份恢复/数据位置为真正页签，支持方向键/Home/End。三个面板保持挂载，切区保留尚未应用的主题、明暗和字号。主题保存区稳定在分区底部；备份先显示文件/时间/结构/学习摘要，再展示恢复动作，原保护链保持。 |
| 6. 首页与知识板块 | 欢迎区只保留标题和一句说明。空库主要动作导入、次要模板；已有题库提供配置，活动轮突出继续。进度条统一主题轨道和填充；全部/未分类是顶部快捷入口，其余按基础/拓展/本机自定义分组，真实题数、待补题和规划展开保留。 |
| 7. 学习记录 | 紧凑范围栏、五项真实计数、三项自评与明确分母/未自评数；详细口径移至帮助。下方默认搜索/收藏，其他条件在高级筛选；默认只看收藏仍保留，无收藏时提示取消勾选。列表筛选不改变范围统计，单题历史仍主动展开。 |
| 8. 练习配置与方案 | 依选题范围→筛选条件→方式/题数→匹配/本轮数量→开始组织。收起筛选后仍有完整摘要；方案默认展开紧凑区，选用明确为填入条件，空态只保留保存入口。名称、唯一性、100份上限与失效引用保护沿用。 |
| 9. 导入与分类管理 | 题库仅留紧凑工具入口。独立导入工作区展示三阶段、六类实际变更和受控滚动表，完整快照/遗漏归档说明持续可见，关闭预览先调用原discard，预览中切页再返回仍保留原状态。分类独立侧面板先展示现有归属，再按操作展开单个表单；当前→目标明确，移除仍先确认且保留题目和记录。 |
| 10. 视觉与证据 | 保留五内置/外部主题变量及15～22px正文设置。减少重复标题和边框，保持按钮权重；新增真正的视口、滚动、占位和失败重试几何检查，同时运行原业务回归。 |

“内容更新待复习”继续仅用于题库浏览，不进入练习筛选、方案或固定队列。练习未揭晓时答案和历史均不挂载；完整备份、保存/关闭守卫和恢复前保护不以UI优化为由改变。

实际执行结果、首轮失败与后续修正分别记录在[验收记录](验收记录.md)和[本批证据](evidence/workbench-ui2-20261026/README.md)。每个修改文件的Bug轮及可维护性轮见[代码复查记录](代码复查记录.md)。自动化与截图不代替用户主观体验、全部系统DPI/IME、安装器、长期性能或硬件验收；既有VMware跳过保持。

收尾数据保护补充：本机实测Windows文件编号超过Number安全整数，两个不同编号可能舍入相同，造成独立备份误判为运行库别名。只对两处lstat/stat采用bigint，真实同编号硬链接仍拒绝；新增场景先在旧r4复现失败，再在修复版验证。原248/249中的一次拒绝未保留当时精确编号，不能追溯宣称该单次失败的原因已确定。
