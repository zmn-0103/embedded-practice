# M2 第二批：顺序练习窗口与保存

日期：2026-10-20。接续第一批已验证的结构 3 和练习事务。本批两个结果：从窗口完成顺序练习；实现可靠保存与长内容工具。不增加 M3 搜索/随机/收藏/历史查询或主题字号设置。

## 输入与可观察行为

- 首页可选专题及 10/20/50/全部，默认 20；无题不建空轮。有活动轮时提供继续，以及明确结束旧轮并开始新轮。新轮不带入旧草稿、揭晓或自评。
- 练习页展示进度、题干、多行纯文本输入，允许空输入揭晓。揭晓前参考答案不挂载正文或无障碍树，揭晓后才有自评与暂不评价；跳过独立处理，上一题保留本轮状态，末题显示完成摘要。
- 输入停止 500ms 后保存；切题、揭晓、自评、结束、返回首页、正常关闭前立即提交。后台保存期间仍可输入，以递增修订处理迟到结果；操作和关闭期间冻结输入，避免保存快照与实际文本分离。
- 显示待保存、保存中、已保存、保存失败，失败保留输入并阻止依赖该次保存的操作。请求响应不明时保留原 UUID 与内容供重试，已确认提交但读取失败只重读，不能多推进。
- 复查修复：练习状态操作激活后，按钮至少保护 500ms，并拦截鼠标多击及长按重复键，防止前一请求很快完成后连续跨题；保护结束后可以继续明确操作，输入与正常关闭保存不额外等待该保护。
- 正常关闭使用主进程发起、带随机标识的保存握手；确认成功后才清理服务与关窗。失败/超时保持窗口，只有用户在系统提示中明确放弃未保存内容时允许退出。强制结束或渲染进程丢失仅保证已确认保存内容。
- 固定白名单 IPC/响应校验，复用主窗口/主 Frame/完整 URL 来源规则；关闭回执只接受本次标识，不接受题目路径、SQL 或任意通道。
- 代码高亮输出为受控 AST 文本/span，未知语言或较大代码块保留纯文本，不执行内容；代码复制仅通过限长白名单能力，失败有提示。图片可在受控对话框放大并关闭，仍只使用已入库版本/哈希；自动保存不关闭已经打开的对话框，不重置缩放。
- 常用练习操作固定在可见区域，代码/表格允许横向滚动，保持现有明暗配色。默认离线，无外部脚本、样式或字体依赖。
- 数据库保持结构 3，复用既有事务；来源题库和原始计划书保持。所有运行测试使用独立临时目录，不连接默认学习库。

## 验收

1. 单元验证白名单/握手标识、500ms 保存、在途编辑/旧结果、失败保留、重复操作及同请求重试。
2. 真 Electron 窗口完成输入与纯思考、揭晓隐藏、自评/暂不评价/跳过/返回、最后一题完成、新轮默认、活动轮继续。
3. 注入实际 SQLite 写入失败，验证页面文本保留、阻止切题、重试成功；正常返回/关闭与独立进程重开核对。
4. 验证关闭期间有未保存输入、失败/重试/超时或不匹配回执，不能静默丢弃；明确区分正常关闭和强制结束。
5. 真实窗口检查代码 token/复制调用、脚本纯文本、图片放大/关闭、明暗及长内容操作位置。
6. 开发构建与 Windows 解包 EXE 分别运行全部场景；不把测试替换的系统提示/剪贴板能力当作人工系统验收，不制作新 NSIS。
7. 复查新增：50/100/250ms 双击跳过与上一题、100ms Enter/Space 重复激活和持续按住 Enter，只移动一题；只读核对实际位置、修订、跳过标记与回执数。自动保存期间图片保持打开与 150% 缩放，仍可主动关闭、恢复焦点和重新打开。
