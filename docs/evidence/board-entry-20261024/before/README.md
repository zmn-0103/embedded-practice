# 嵌入式刷题本

供个人使用的 Windows 离线刷题程序，内部标识为 `embedded-practice`。题目与参考答案在程序外通过 Markdown 维护，程序负责导入、练习和保存学习记录。

核心流程：导入题库 → 选择分类、专题或筛选条件 → 阅读题目 → 输入答案或自行思考 → 揭晓参考答案 → 自评 → 下一题。

## 使用入口

打开[练习方案试用版](release/practice-plans-20261024/win-unpacked/embedded-practice.exe)，**必须保留整个 `win-unpacked` 目录**。旧结构 8 及更早的程序不能打开结构 9 数据；版本、数据保护与兼容说明以[当前交付说明](docs/当前试用版本交付说明.md)为准。

日常操作见[使用说明](docs/使用说明.md)。新一轮内容试用可使用[五专题10道通用基础小样](question-banks/general/README.md)，来源盘点和用户审阅表见[本批说明](docs/通用基础样题与试用.md)。程序不会自动导入仓库题库，正式题库与答案仍需用户审阅；来源与待办见[GPIO 题库说明](question-banks/README.md)、[UART 试用选集](question-banks/trials/README.md)及[UART 技术核对](docs/UART30题来源与技术核对.md)。

## 开发与数据

使用 npm 和仓库锁文件，环境与操作步骤见[开发说明](docs/开发说明.md)。运行或测试前须核对目标构建、数据库结构和独立临时数据目录；解包检查显式指定目标程序，默认旧目录不能作为当前入口。

正式数据默认位于 `%APPDATA%/embedded-practice/`，开发运行默认使用 `%APPDATA%/embedded-practice-dev/`。自动化使用新建独立临时目录；数据库、个人备份和学习数据不进入 Git。题库来源文件由用户维护，程序不得修改；完整要求见[数据保护契约](docs/数据保护与桌面边界.md)和[题库与导入契约](docs/题库与导入契约.md)。
