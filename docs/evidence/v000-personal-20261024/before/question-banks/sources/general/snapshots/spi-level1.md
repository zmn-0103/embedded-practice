# 第二部分：答案与解析

## A. 单项选择题答案

1. **B**。SCK 是同步串行时钟，由 SPI 主机提供。
2. **A**。MOSI 是主机输出、从机输入的数据线。
3. **A**。Mode 0 为 CPOL=0、CPHA=0。
4. **C**。SPI 全双工模式下发送和接收同时进行，因此接收数据也需要及时处理。
5. **B**。`SPI_Init()` 根据初始化结构体配置 SPI 参数。
6. **A**。`SPI_Cmd()` 用于使能或关闭 SPI 外设。
7. **C**。TXE 表示发送缓冲区可写。
8. **A**。RXNE 表示接收数据可读。
9. **D**。`0x9F` 是常见 JEDEC ID 读取命令。
10. **A**。`0x03` 是常见普通读取命令。
11. **B**。`0x06` 是常见写使能命令。
12. **C**。SPI 主机必须继续产生 SCK，Flash 才能移出数据。
13. **B**。普通读取命令后发送 24 位地址，再提供时钟接收数据；地址格式要按实际 Flash 数据手册核对。
14. **B**。写使能是后续编程/擦除操作的必要条件之一。
15. **B**。页内偏移 `0xF0` 为十进制 240，256−240=16 字节。
16. **B**。跨页编程可能在当前页内回绕，应将数据拆分为符合页边界的事务。
17. **B**。MCU SPI 传输状态与 Flash 内部操作状态属于不同层次。
18. **A**。超时可避免等待循环无限运行。

## B. 简答题参考答案

**19.**
- SCK：同步串行时钟。
- MOSI：主机向从机发送数据。
- MISO：从机向主机返回数据。
- CS：选择目标从设备并界定命令事务，常见 Flash 为低电平有效。

**20.**
- `RCC_APB2PeriphClockCmd()`：使能/关闭相应 APB2 外设时钟。
- `GPIO_Init()`：按结构体配置 GPIO 引脚。
- `SPI_Init()`：按结构体配置 SPI 工作参数。
- `SPI_Cmd()`：使能/关闭 SPI 外设。
- `SPI_I2S_GetFlagStatus()`：读取指定 SPI/I2S 状态标志。
- `SPI_I2S_SendData()`：向 SPI 发送数据寄存器写入数据。
- `SPI_I2S_ReceiveData()`：读取接收数据寄存器中的数据。

**21.** 等待 TXE → 发送一个字节 → 等待 RXNE → 读取接收字节 → 检查错误与超时。最后一个数据帧结束以及 CS 的处理要符合具体事务和芯片手册要求。

**22.** CS 拉低 → 发送 `0x9F` → 继续发送占位字节并接收 ID 字节 → 等待最后一帧结束 → CS 拉高 → 对照实际 Flash 型号数据手册确认 ID。

**23.** 确认测试地址安全、地址和长度有效 → 等待 Flash 就绪 → 写使能 → 可检查 WEL → 发送页编程命令 `0x02`、地址和数据 → 等 SPI 最后一帧结束 → 结束 CS 事务 → 轮询 Flash 内部 BUSY → 回读并比较。

**24.** `SPI_SR.BSY` 反映 MCU SPI 外设的串行传输状态；Flash 的 BUSY/WIP 反映其内部编程/擦除状态。SPI 传输可以已经结束，而 Flash 内部操作仍在进行。

**25.** 选择可安全覆盖的测试区域并确认擦除需求 → 读取并打印原值 → 必要时擦除所在扇区 → 写使能 → 写入新值 → 等待 Flash 内部操作完成 → 读取同一地址 → 打印读回值 → 比较期望值与实际值 → 打印 PASS/FAIL。擦除前必须确认不会破坏重要数据。

**26.** 可检查：供电与接线、CS 时序、SPI 模式、SCK 分频、GPIO 模式、标准外设库初始化参数、TXE/RXNE 处理、接收数据是否被及时读取、写使能/WEL、Flash BUSY、地址字节顺序、页边界、写保护、目标地址是否先擦除、Flash 完整型号及数据手册限制。
