`snapshots/` 保留复制时原始字节，包括原始frontmatter、Obsidian导航和历史状态，不做链接或格式修复，也不作为程序导入文件。日后原笔记变更时，新建一批快照并说明来源，不用新原文覆盖本批依据。

本批实际运行只在程序项目的独立临时库进行，未导入个人学习库；题库文件夹和清单不意味着程序已自动建立分类、导入题目或取得用户技术审阅。
