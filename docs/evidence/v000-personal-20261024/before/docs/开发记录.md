#### 验收记录要求

- 记录状态、环境、实际执行内容与结果；没有执行的项目标为“未验证”。
- 将静态检查、自动化、开发启动、安装包人工检查、离线检查与性能实测分开。
- 有实际产物时记录版本、数据集和证据位置，不记录完整用户答案或敏感信息。
- 大体积测试产物默认不进入 Git；交付时明确安装包是否签名、是否实际运行及是否发布。
