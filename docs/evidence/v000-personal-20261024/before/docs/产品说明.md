## 产品目标

“嵌入式刷题本”面向个人、单机、单用户，提供 Windows 离线练习。Markdown 是题目维护来源，应用数据库保存导入副本与学习记录。完整需求以[计划书](../计划书.md)为准。

目标流程：导入题库 → 筛选专题 → 思考或输入答案 → 揭晓参考答案 → 自评 → 下一题。

## 当前可用内容：导入、筛选收藏、练习与单题历史

- 打开桌面窗口默认进入板块，可浏览规划、当前分类和实际题数，另可进入开始练习、题库、学习记录、设置与数据；未导入时不自动添加样例。
- 通过系统文件框选择一个或多个 Markdown，预览新增、内容更新、信息变更、不变、归档和恢复数量，确认后整批入库。
- 支持准备取消、错误定位、放弃预览和导出原始题库模板。
- 每页 20 题，按专题查看活动或归档题目；选择后展示代码、表格、列表和入库图片。
- 按标题、题干或标签搜索，并将专题、完整标签、难度、当前版本自评和只看收藏组合筛选；搜索不查答案或返回答案片段。
- 题库详情可收藏/取消收藏，失败可按相同目标重试；收藏独立于自评，更新、归档恢复和重开后保留。
- 题库详情与练习页可主动展开单题历史，先列每页 20 条摘要，再查看某次保存作答、当时题干及已揭晓参考答案；新题/新轮默认收起，同题保存保持展开。
- 更新内容或图片后，题库列表/详情显示“内容更新待复习”；练习揭晓最新版后消除，查看题库答案/历史、跳过或揭晓旧轮版本不消除。
- “学习记录”按专题与活动/归档范围展示当前版本的已揭晓题数、已自评题数、三种自评分布、收藏和待复习数量；多轮按题去重，下方默认只看收藏，可调整筛选并主动查看单题历史。
- 参考答案点击后才读取和展示，切题后重新隐藏；当前用于检查导入内容。
- 首页可选顺序／随机、专题、组合筛选与 10/20/50/全部题数，默认顺序、20 题；随机从完整匹配集取样且本轮不重复，实际顺序在开始时保存。可继续活动轮或明确结束旧轮后新建，无匹配不建立空轮或结束旧轮；继续及重开始终使用原模式、队列与内容版本。
- 会话保存创建时规范化的筛选条件，活动轮可只读回看；旧轮缺失时明确未知，首页下一轮的条件不改写原条件，继续不重新选题。
- 练习可输入或纯思考，揭晓前答案不进入页面；揭晓后自评或暂不评价，未揭晓可跳过，上一题可修改本轮记录。
- 草稿停止输入 500ms 后保存，切题、揭晓、自评、返回首页和正常关闭前刷新；状态/失败可见，失败保留输入并允许重试。
- 练习操作区随长内容保持可见，代码高亮/原文复制、图片模态放大、输入区折叠可用；完成页分别展示本轮数量。
- 切题后回到题首并聚焦标题，完成/结束结果同样有明确阅读入口；同题保存和揭晓不抢阅读位置或输入焦点。
- 默认跟随系统明暗、松间绿配色和 17px；可独立选择四种配色、明色/暗色/跟随系统及 15～22px 字号，局部预览后明确保存，全局应用并重开保留，失败保留选择可重试。
- 在“设置与数据”导出已保存的完整数据备份，选择备份校验并显示摘要；确认后先保存待保存内容、创建保护性备份，再恢复所见副本并重启。保护失败停止，替换失败回退，启动先处理未完成的恢复事务。
- 数据位置显示本次运行的数据、保护备份和诊断日志位置，三个固定按钮请求系统打开文件夹；数据库不可用时错误页仍提供位置和日志入口，打开失败可重试。
- 通过受限接口检查真实本地数据库，并显示就绪或错误状态。
- 每次进程启动记录一次启动次数和时间；只读状态、界面重载不增加次数。
- 数据读取失败时保留数据库，显示中文说明并提供重新检查按钮。
- 单实例运行；正常退出先确认输入保存，失败默认返回窗口，明确放弃后才退出；随后取消准备、等待工作线程停止并关闭数据库。
- 提供已验证的完整 Windows x64 解包程序；`release/m5-20261022/` 中另有结构6对应的未签名 NSIS 候选，已生成/拆检但未完成安装验收。`release/` 根目录同名安装器是旧M0，两者均为0.1.0，需按路径及哈希区分，详见[交付说明](当前试用版本交付说明.md)。

## 需要持续保持的体验契约

- 允许输入答案，也允许只思考后直接揭晓。
- 揭晓前答案不进入页面正文或无障碍阅读树。
- 自评为“不会、不熟、掌握”，只在揭晓后可用；跳过与未评价不自动记为不会。
- 收藏与掌握程度独立，统计区分已揭晓、已自评及自评分布。
- 总览只统计所选范围的当前版本并按题去重；只有旧版自评状态而无真实作答的兼容数据不补造揭晓或历史，不能将多轮作答次数当成题数。
- 内容更新保留历史与收藏，活动会话使用开始时的内容版本。
- 保存失败保留当前输入，并阻止依赖本次保存的切题。
- 样例和测试数据不自动进入正式题库，程序不修改来源文件。

答案按需读取/隐藏和来源独立已在内容检查与练习页验证；练习页面可以保存并继续顺序或随机活动轮。单题历史读取实际作答行，不计入仅排队无操作的题，也不补造只有旧自评状态的数据。历史只读，不改变当前作答、自评或待复习标记；方法见[使用说明](使用说明.md)，实现与证据见[第三批说明](M3第三批行为与验收.md)。强制结束仅恢复已确认保存状态，不承诺恢复尚未提交的按键。
