## 使用独立验收数据

使用当前完整 `release/win-unpacked/`。`release/`根目录同名 NSIS 是旧M0，不能用它验收当前练习功能；`release/m5-20261022/`另有结构6未签名候选，安装验收未完成。路径与哈希见[当前交付说明](当前试用版本交付说明.md)。以下命令在仓库根目录的 PowerShell 执行，启动的是可见的交互窗口，数据存入新建临时目录；不指向正式或默认开发学习库，不清理已有数据。

```powershell
$m2ManualProgram = Join-Path (Get-Location) 'release/win-unpacked/embedded-practice.exe'
if (-not (Test-Path -LiteralPath $m2ManualProgram -PathType Leaf)) {
    throw '请先生成当前 Windows 解包程序。'
}
$m2ManualDirectory = Join-Path ([System.IO.Path]::GetTempPath()) ('embedded-practice-manual-m2-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $m2ManualDirectory | Out-Null
$m2PreviousDirectory = [Environment]::GetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', 'Process')
try {
    [Environment]::SetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', $m2ManualDirectory, 'Process')
    Start-Process -FilePath $m2ManualProgram
} finally {
    [Environment]::SetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', $m2PreviousDirectory, 'Process')
}
Write-Output "本次独立验收数据：$m2ManualDirectory"
```

测试关闭重开时，在同一 PowerShell 会话重新执行 `try/finally` 段，复用 `$m2ManualDirectory`，不要重新生成目录。保留这一路径和实际截图作为证据；清单中的启动命令是供人工执行的步骤，不表示本次已经完成这些人工操作。

导入已明确审阅的测试专题，至少包含多行文字、C 代码、表格、长题干/长答案与有效 PNG/JPEG/WebP。仓库格式示例明确为示例，不能据此认定正式题库已审阅；自建两像素小图也不能代替真实大图阅读体验。
