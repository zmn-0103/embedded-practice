# M3 第五批：显示设置与四个页面入口

日期：2026-10-21。接续学习记录总览，完成 M3 剩余的显示设置和四入口分离，不开展 M4 完整备份恢复或 M5 发布验收。

## 行为

- 显示设置默认跟随系统主题、17px；可明确选择跟随系统/明色/暗色，正文字号整数 15～22px。点击保存后生效并持久化，重开保留；保存失败保留选择并允许按明确目标重试，不静默重置为默认值。
- 设置只通过严格白名单读取/保存，存入 SQLite，不能传入任意文件/SQL。新结构 5 增加单行显示设置表；v1/v2/v3/v4 均先一致性备份并校验，再事务迁移。失败停止或回滚，保留旧库；旧版本程序不能打开新库。
- 主要入口拆分为开始练习、题库、学习记录、设置与数据。练习控制器持续挂载；练习中沿用原离开前保存，导航隐藏。题库导入面板跨页保留预览；题目/答案阅读按原按需规则。设置与数据仅提供已实现的显示设置，明确完整备份恢复待 M4。
- 保存设置是明确完整目标，不产生递增业务记录；失败或响应丢失可安全重试相同目标。页面不开放显示设置以外的持久化能力。正常关闭等待已发送的设置保存，并沿用练习保存协调。
- 手动主题优先于系统变化，跟随系统时响应明暗变化；所有阅读区采用保存字号，未知/损坏设置显示错误并可重读，不能冒充成功默认设置。
