# 脚本目录补充约束

继承[根规则](../AGENTS.md)。操作方式见[开发说明](../docs/开发说明.md#运行与测试前的目标核对)，程序来源见[交付说明](../docs/当前试用版本交付说明.md)，数据边界见[数据保护契约](../docs/数据保护与桌面边界.md)。

- 运行脚本前检查其目标参数、环境变量和默认值；应用脚本显式指定支持的 EXE 目标及新建临时数据目录，记录预期/实际构建、结构和数据路径，不依赖封存旧程序的默认路径。
- 新检查、打包与报告使用新的独立输出目录；既有目录先核对用途，不覆盖旧包、首次失败、报告或清单。脚本修改时为缺失或不明确的目标提供明确错误，不静默改用其他版本。
- 清理只限本脚本创建且可确认归属的临时目录。递归删除或移动前核对解析后的绝对路径、父目录和边界，不从任意外部输入拼接清理目标。
- 不隐式读取、迁移、恢复或写入个人学习库；恢复检查只操作本批临时库及其保护备份，不将正式数据作为调试样本。
