## 日常使用

1. 在“题库”导入完整Markdown专题，核对预览后确认；新专题出现在未分类。格式、模板、配图规则见[使用说明](使用说明.md)、[格式说明](MarkdownV1题库格式.md)与[专题模板](../question-banks/templates/README.md)。
2. 展开“管理分类”，添加例如“STM32”的板块；选择明确专题和目标板块，点击“保存专题归属”。程序不会自动导入仓库文件或猜测归属。分类由本机生成ID，[内容分类规范](题库分类与标签规范.md)里的stm32只是内容约定。
3. 分类树中先展开板块，再选专题；直接选板块可看其全部题目。“查找专题”只检索导航，点击分类/专题才应用范围。原搜索、完整标签、难度、自评、收藏和归档继续取交集。
4. 开始练习和学习记录中展开“按分类选择专题”选择同样范围。快捷条件保留分类；下方学习记录清空筛选仍保留上方固定范围。学习统计按当前版本/题目去重，测试自评不代表个人学习成绩。
5. 分类改名/移动/移除不改变已有固定练习队列，“本轮创建条件”保留当时分类名称。移除默认取消，确认后专题保留为未分类，题答、版本、收藏和历史不删除。已有专题重导入保持归属。
6. 分类保存失败时保留输入，可按同一目标重试；正常关闭等待已发起保存。分类变更会使旧导入预览失效，需重新预览。所选分类已移除或专题已移出时明确显示空范围，请重新选择，程序不自动扩大到全部题目。

显示设置仍提供四配色、跟随系统/明色/暗色与15～22px字号，先局部预览，明确保存后全局应用。练习前隐藏答案；输入停止500ms保存草稿，失败保留输入并阻止依赖操作。返回首页/切题/正常关闭先保存，强制终止只保证已确认状态。

30题均待用户技术审阅，[来源与技术核对](UART30题来源与技术核对.md)列明6题条件/步骤待办和1题工具链依据不足，AI核对和元数据入库不等于答案/硬件通过。审阅及真实体验填写[反馈表](M5题目审阅与试用反馈.md)。GPIO78题原文保持；108题仓库对照不代表个人库已导入。

默认解包/安装数据位于 `%APPDATA%\embedded-practice`，开发数据位于 `%APPDATA%\embedded-practice-dev`；实际路径以“设置与数据→数据位置与诊断”为准。自动化只用显式新建临时目录，本批没有操作个人学习库。实际业务库为practice.sqlite3，保护备份在backups，日志在logs/application.log。

首次打开旧库时，支持结构1～7先生成并校验一致性保护备份，再事务升级到8。v7追加分类表、专题归属和会话分类快照；旧专题未分类，旧轮此前没有分类限制，原filters-null仍未知。原业务和显示设置保持；备份/迁移失败停止，不重建空库。**旧结构7/6程序及旧安装器不能打开结构8。** 回退程序前保留完整数据与备份，不用旧程序覆盖新库。

使用“设置与数据”的完整导出备份，覆盖题库/旧版本/图片、记录、草稿、固定队列、原筛选/分类快照、当前分类/归属和显示设置。恢复先预览摘要再明确确认；保护性备份失败停止，替换失败回退，成功重启。不要复制正在写入的数据库冒充完整备份，不要手动覆盖运行库。

需要隔离试用时，按[开发说明](开发说明.md)或既有验收脚本显式传入新建的EMBEDDED_PRACTICE_TEST_DATA_DIR。直接双击使用默认正式目录；先正常关闭已有实例，再选择所需数据目录。生成性能样本不要导入个人库。
