# M1 第五批：导入窗口与受控内容读取

日期：2026-10-20。接续第四批内部服务，本批完成文件选择、预览/确认/结果窗口、分页题库与导入内容检查、受控图片及正常退出协调，不实现 M2 作答、自评和会话。

## 行为

- 文件只能经主进程系统选择框选择一个或多个 Markdown；窗口没有任意路径/SQL/IPC 入口。
- 准备显示忙碌与取消入口；预览展示分专题新增/更新/元数据/不变/归档/恢复与期限，确认原快照。取消、页面重载、渲染退出与关闭释放未确认快照；同一时间只允许一个文件选择/准备操作。
- 明确显示确认成功或错误及文件/行列定位；失败不声称提交成功，支持按错误提示重试或重新预览。重复确认沿用上一批幂等契约。
- 列表每页固定 20 题，提供专题与活动/归档查看；只加载标题等元数据。选择题目才读取对应固定版本的题干；参考答案点击展开后再读取和挂载，切题后重新隐藏。此页是导入内容检查，不是练习会话。
- Markdown 使用受控组件与 GFM 展示代码、表格和列表，不执行原始 HTML。引用定义由标准序列化器提供，外链仅显式点击已验证 HTTP/HTTPS 地址后由系统浏览器打开。
- 图片 URL 由版本 ID 与已入库资源哈希生成；主进程校验版本关联并返回 PNG/JPEG/WebP BLOB，拒绝来源路径/远程 URL/任意哈希读取。页面处理解码失败，不把头部校验当作完整解码保证。
- 导出模板使用仓库原模板随构建内嵌，经系统保存框写入，不能让窗口指定任意位置。模板仍明确为占位内容。
- 正常退出先停用 IPC、取消选择/准备并等待工作线程关闭，再关闭连接。提交事务仍为同步执行，开始后不提供中途取消。强制结束的边界保持上一批约定。
- 数据库仍为结构 2；所有测试显式临时目录，不写默认正式/开发库。依赖通过 npm 固定并更新锁文件，不更改 Electron/SQLite 组合。

## 验收

1. 共享请求/响应校验、调用窗口/Frame/URL、非法参数及令牌、外链和资源路径拒绝。
2. 真 Electron 经固定预加载 API 与原生选择框调用路径完成导入，校验取消、错误、预览放弃、重复确认、重载失效、关闭收尾。
3. 通过窗口实际读取题干/代码/表格与三种图片，答案展开前不存在于正文与无障碍树；移动来源后独立进程重开仍可显示。
4. 验证归档列表、分页、元数据更新与恢复；保留上一批事务/迁移和原有桌面保护回归。
5. 对开发构建与 Windows 解包 EXE 分别执行；截取真实 Electron 明暗界面并检查，不用浏览器截图代替桌面。
6. 原生对话框自动化可在测试主进程替换其返回值，但不得添加生产测试入口；明确这不等于人工完成原生对话框交互或新 NSIS 安装验收。

逐文件先 Bug 检查、再优化检查并记录；运行结果、失败修正和未验证项另记验收记录。
