## 开始试用

在“设置与数据 → 显示设置”选择配色卡、明暗模式与 15～22px 正文字号。右侧为局部预览，**点击“保存显示设置”才应用到全部页面并持久化**；失败时保留选择，可按原目标重试。宽窗口使用左侧导航，小窗口使用横向导航；练习期间仍通过“返回首页”先保存再离开。复制代码成功的对勾在 2.5 秒后消失，复制错误会继续显示。

先阅读[使用说明](使用说明.md)，在“题库”中选择 Markdown，核对预览后确认导入；在“开始练习”中选择专题、模式、题数和筛选条件。首次进入一题时答案隐藏，可以输入答案，也可以空输入思考后揭晓、自评。停止输入 500ms 后自动保存，切题、返回和正常退出会提交待保存内容；出现失败时保留窗口中的输入并重试，等到“已保存”再做后续判断。

同次打开程序内，返回题库会保留筛选、页码、选中题、展开答案和阅读位置；返回时仍按原条件核对当前数据，不再匹配的详情移除，导入更新会重新检查内容。标签可输入片段搜索候选，再点击或用上下键/Enter选择完整标签。首页“练不会/练不熟/练收藏”先替换筛选，保留专题、模式和题数；按“开始”才创建或明确替换新轮，继续始终使用原队列。浏览位置没有新增跨重启保存，个人学习记录继续正常持久化。

建议先使用已有 [UART 30 题试用选集](../question-banks/trials/README.md)，逐题审阅与体验，不继续扩充正式题量。来源与入库哈希对应已检查，**技术答案和主观学习体验仍需用户确认**，填写[题目审阅与试用反馈](M5题目审阅与试用反馈.md)。验收中的自评是测试输入，不是个人学习成绩。

题库在程序外维护。每个专题文件是完整快照，更新时保留 `topic_id + question_id`；缺题会归档，恢复相同 ID 保留历史。配图置于 Markdown 同级 `assets` 目录，支持 PNG/JPEG/WebP；导入后使用入库副本，不依赖来源文件。具体格式、模板与示例见[格式说明](MarkdownV1题库格式.md)、[专题模板](../question-banks/templates/README.md)和[格式示例](../question-banks/examples/README.md)。

若只想验收程序，可以在仓库根目录的 PowerShell 新建独立数据目录后启动；下例不会访问正式或默认开发学习库。每次完整执行会新建一个目录，需要继续同一轮时保留原目录并复用它。

```powershell
$m5TrialProgram = Join-Path (Get-Location) 'release/findability-20261023-r2/win-unpacked/embedded-practice.exe'
if (-not (Test-Path -LiteralPath $m5TrialProgram -PathType Leaf)) { throw '缺少完整解包程序。' }
$m5TrialDirectory = Join-Path ([IO.Path]::GetTempPath()) ('embedded-practice-trial-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $m5TrialDirectory -ErrorAction Stop | Out-Null
$m5TrialPrevious = [Environment]::GetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', 'Process')
try {
    [Environment]::SetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', $m5TrialDirectory, 'Process')
    Start-Process -FilePath $m5TrialProgram -WindowStyle Normal
} finally {
    [Environment]::SetEnvironmentVariable('EMBEDDED_PRACTICE_TEST_DATA_DIR', $m5TrialPrevious, 'Process')
}
Write-Output "本次独立试用数据：$m5TrialDirectory"
```

直接双击程序时使用默认正式数据位置；不要把压力样本和本批生成的体验样本导入个人学习库。已打开一个实例时应先正常关闭，再以所需目录启动。

## 数据位置与保护

默认解包/安装程序数据位于 `%APPDATA%\embedded-practice`，默认开发运行位于 `%APPDATA%\embedded-practice-dev`。程序和数据目录分开；实际路径以“设置与数据 → 数据位置与诊断”显示为准，显式验收目录会显示本次临时位置。业务库为 `practice.sqlite3`，保护性备份位于实际数据目录的 `backups`，日志位于 `logs`，错误定位可查看 `logs/application.log`。

使用“设置与数据”中的完整导出备份。备份覆盖已保存的题库、内容版本、图片、记录、草稿、固定队列、筛选快照和显示设置。恢复先选择文件、查看摘要再明确确认；程序先保存并创建当前数据的保护性备份，失败即停止，替换失败按事务回退，成功后自动重启。不要复制正在写入的数据库冒充完整备份，不要手动覆盖运行库。

当前程序支持结构 1～6 先生成并校验保护备份再迁移到 7；结构 6 仅追加配色，旧明暗、字号及业务数据保持；失败不自动创建空库。**M5 旧界面（结构 6）、旧候选 NSIS 和旧 M0 都不能打开结构 7。** 回退程序前先保留完整数据和备份，不用旧程序尝试覆盖新库。
