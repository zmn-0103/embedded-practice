## 执行方式

从 2026-10-19 开始，按用户要求逐个文件编写，不批量生成应用代码。每个代码文件完成后依次进行：

1. Bug 检查：接口、类型、正常与异常路径、资源释放、数据与桌面边界。
2. 优化检查：职责、可读性、命名、依赖和复杂度；仅做有明确收益的调整。

两轮完成后才开始下一个代码文件；文件后续发生实质修改时重新复查。配置文件同样检查，自动生成的锁文件由包管理器维护。

本文件记录静态复查结论；类型检查、自动化、启动、打包和安装验证另见[验收记录](验收记录.md)。
