# 题库导入、练习与学习记录

当前版本可导入题库，搜索、组合筛选和收藏题目，完成顺序或随机练习，继续已保存的活动轮，查看学习记录总览，并主动查看单题历史及更新待复习标记。宽窗口左侧、小窗口上方可切换“开始练习”“题库”“学习记录”“设置与数据”；练习期间通过原“返回首页”先保存再离开。完整备份、确认恢复及数据位置入口已接通。实际可用范围以[产品说明](产品说明.md)和[验收记录](验收记录.md)为准。

## 启动当前版本

当前Windows解包程序位于仓库 `release/findability-20261023-r2/win-unpacked/embedded-practice.exe`，页脚为 `v0.1.0 · 构建 20261023.3-findability`。保留整个 `win-unpacked` 文件夹后启动其中的EXE。`release/findability-20261023/` 是首轮失败的.2候选，仅保留追溯；`release/ui-20261023/` 为上一UI版；结构6旧M5程序/NSIS与旧M0均不能打开当前库。独立试用方式、兼容与已验/未验范围见[交付说明](当前试用版本交付说明.md)，状态为可试用、部分验收未完成。

本地数据与程序文件分开保存，正式/解包程序默认使用 `%APPDATA%/embedded-practice/`，开发运行默认使用 `%APPDATA%/embedded-practice-dev/`。程序不会自动把仓库里的题库或测试样本导入个人数据。

新 UI 程序使用数据库结构 7，v1～v6 旧库会先生成并校验保护性备份，再升级；v6 只追加配色，保留原明暗、字号和全部学习数据，备份失败时停止。封存的结构 6 程序/候选安装器和旧 M0 均不能打开结构 7，请使用完整的新 UI 程序目录。升级前备份位于数据目录的 `backups`，完整备份与恢复界面在“设置与数据”提供。

## 准备题库

先进入顶部“题库”页，可点击“导出题库模板”，选择位置保存后，在程序外填写。模板含占位正文；请替换成完整题目与参考答案，再人工核对内容。也可阅读[格式说明](MarkdownV1题库格式.md)、[仓库模板](../question-banks/templates/README.md)和[配图示例](../question-banks/examples/README.md)。

每个 Markdown 文件代表一个专题的完整快照，稳定身份为 `topic_id + question_id`。更新时保持原 ID；文件改名无需改 ID。配图放在 Markdown 同级的 `assets` 目录，仅支持 PNG/JPEG/WebP。原始 HTML、远程图片、绝对图片路径、SVG 和脚本会被拒绝。

仓库提供[78 道 GPIO 初始题库](../question-banks/STM32F103RCT6-GPIO阶段自测题.md)，需用户审阅技术内容后决定是否导入。格式通过不等于参考答案技术正确。

## 预览与确认

1. 进入“题库”页，点击“导入题库”，在系统文件框选择一个或多个 `.md` 文件。
2. 等待检查；准备期间可取消。文件错误会显示文件名、行列和原因，请在程序外修正后重试。
3. 核对预览的专题与六类数量：新增、内容更新、信息变更、不变、归档和恢复。特别检查“归档”：它表示该专题原有题目未出现在此次完整快照中。
4. 点击“确认导入”，看到“导入完成”后在下方题库查看；不准备提交时点击“放弃本次预览”。

预览默认保留 15 分钟。确认提交已暂存的内容；预览后改动来源文件不会悄悄替换本次提交。要导入刚改的内容，请放弃并重新选择。页面重载、关闭和重新选择也会使旧预览失效。

如果确认响应失败，请按界面提示重试同一次确认或重新预览；不能仅凭失败提示判断题库一定没有入库。重复确认依照原回执处理，相同内容重新导入不会重复增加题目。

## 查看与后续更新

题库每页 20 题，可按专题切换，用“查看归档题目”检查已归档内容。点击题目查看题干、代码、表格和图片；点击“展开参考答案”后才显示答案，切换题目会重新隐藏。此处用于内容检查；需要保存作答和自评时，从首页开始练习。

在程序外修改 Markdown 后，重新执行预览和确认。仅标题、难度、标签或顺序变化计为信息变更；题干、答案、引用定义或图片内容变化生成新版本。缺题归档，相同 ID 再出现会恢复。程序不修改来源文件，已入库内容和图片可以在来源移走后继续读取。

参考资料仅在点击后交给系统浏览器打开，需要联网的网页由浏览器处理。图片若显示“无法解码或读取”，请在来源中替换有效图片后重新导入；头部校验无法排除全部像素损坏。

## 搜索、筛选与收藏

题库的搜索框匹配题目标题、题干和标签，点击“筛选题库”应用；专题和归档切换会立即应用。搜索不查参考答案，也不展示答案片段。英文大小写不敏感，百分号、下划线和引号按普通字符匹配；最多输入 256 个字符。

专题、标签、难度、自评状态和“只看收藏”可一起使用，结果必须同时满足所有条件。标签可输入片段搜索本地候选，再点击或用上下键/Enter选择完整标签，例如 `ARM Cortex`；Escape收起候选，“清除”取消标签条件，也能直接填写完整标签。候选覆盖当前专题及活动/归档范围的全部标签，不受当前页码、搜索或收藏条件缩窄；超过50项时提示继续输入。已选条件摘要表示当前填写值，列表在点击“筛选题库”后应用。点击“清空题库筛选”恢复全部活动题目。

同一次打开程序内，切去其他入口再返回题库，保留填写与已应用筛选、专题/归档、页码、选中题、已展开答案和阅读位置。返回时会重读当前范围；题目不再匹配会移除，导入更新、主动筛选和重试重新核对详情。离页后旧答案移出当前页面正文，不出现在新轮中。此浏览位置没有新增跨重启持久化。

点击题目后的“收藏本题”或“取消收藏”保存收藏状态。收藏和自评分开：收藏不会改变掌握程度、历史或当前练习队列，更新、归档、恢复与重开程序会保留收藏。保存失败或结果未确认时保留原显示，可按原按钮重试相同设置。

自评筛选只采用当前内容版本的自评。题干或答案等内容更新后，旧版自评仍保存，但不会算作新版掌握程度。“未练习”指当前版本未揭晓且无有效自评；排入队列或跳过仍可属于未练习，揭晓未评价不会自动算作“不会”。题库详情会显示当前自评或揭晓未自评状态。

题目内容或图片更新后，如果新版尚未练习，题目列表及详情会显示“内容更新待复习”。练习中揭晓最新版后标记消除，允许空作答或暂不自评。只改标题、难度、标签和顺序不产生新标记；原有标记继续保留。查看题库答案、历史或继续旧轮揭晓旧版本不会消除新版标记，跳过也不会。

## 学习记录总览

点击顶部“学习记录”，选择专题及活动/归档范围。上方分别显示范围内题数、已揭晓题数、已自评题数、收藏题数、内容更新待复习题数，以及“不会 / 不熟 / 掌握”的题数分布，不显示系统正确率。

这些数量按题去重，只看当前内容版本。多轮练同一道题不会重复增加题数；同轮改评会更新分布。保存草稿、跳过或在题库查看答案不计入已揭晓。揭晓未评价可计入已揭晓，不自动归为“不会”。内容更新后旧版揭晓和自评不计入新版，旧记录仍可主动查看；仅元数据变化不重置统计。旧数据若只有有效当前版本自评而没有真实作答，只计入自评，不补造揭晓记录，因此这类数据的已自评题数可能大于已揭晓题数。

下方默认只看收藏，范围与上方专题/活动或归档选择相同。可取消“只看收藏”、搜索或调整其他筛选，选择题目后主动展开历史。下方筛选不改变上方总览范围；清空下方筛选也保留所选专题和活动/归档范围。收藏保存后总览会重读，读取失败显示错误，可分别重试总览或题目列表。

切到记录页不会丢弃尚待确认的导入预览，返回“题库”后仍可确认或放弃；它也不会结束活动轮。记录页正常关闭程序后，可重新打开并继续原轮已保存内容。

## 查看单题历史

在题库详情或练习页点击“查看本题历史”。默认不读取或展示旧作答和答案；打开后每页显示 20 条摘要，再点击某条的“展开本次记录”查看当时保存的作答、题目和已揭晓参考答案。历史显示当时的标题/专题、内容版本、顺序或随机、轮次状态与揭晓/自评时间；“旧版本”说明这条记录对应的内容已被更新。

从未揭晓的记录可查看已保存作答与题干，不展示参考答案。未填写答案的揭晓仍会保留记录；纯粹排入队列但没有操作的题不计入历史。旧版本只有自评状态却没有实际作答的数据不会被补造为历史。作答按纯文本展示，代码和换行保留；历史图片使用当时已入库的内容。

同一轮修改自评更新同一条记录，新轮产生新记录。归档后可在“查看归档题目”中选择该题继续查看历史；相同 ID 恢复后记录保留。练习页仅列出其他轮次的历史，本轮已保存内容仍在当前作答区；切题或开始新轮会重新收起历史，同题自动保存和揭晓会保持展开状态。回看历史不改变当前轮的位置、揭晓、自评、收藏或待复习状态。读取失败可点击对应重试按钮。

## 开始与继续练习

有活动轮时，首页先展示原轮专题、当前题目与位置，点击“继续练习”回到原队列。下方“练不会”“练不熟”“练收藏”快捷条件会替换其他筛选，保留专题、模式和题数，先显示匹配数量；点击开始按钮才创建或明确替换新轮。“全部题目”取消其他筛选。这里“不会”和“不熟”是两个独立入口，没有新增联合自评条件。

1. 首页选择“练习模式”“练习专题”和“本轮题数”，默认为顺序、全部专题、20 题；也可选随机及 10、50 或全部。展开“筛选练习题目”可设置搜索、完整标签、难度、自评状态与只看收藏，页面显示匹配题数。不足所选数量时使用全部匹配活动题目，归档题不进入新轮；无匹配时不能新建空轮。
2. 点击“开始练习”。顺序模式按专题与文件顺序；随机模式从全部匹配题目中取样，本轮不重复。实际顺序和题目内容版本在开始时保存，导入更新不会中途替换本轮内容。
3. 在“我的答案”中输入文字或代码，也可只思考；点击“查看参考答案”揭晓。未揭晓前没有自评按钮。
4. 揭晓后选择“不会 / 不熟 / 掌握”，或“暂不评价，下一题”；未揭晓题可“跳过本题”。跳过、揭晓未评价不会自动算作“不会”。“上一题”可返回本轮题目，修改自评会更新本轮记录。
5. 最后一题推进后显示本轮摘要，不显示系统正确率。“结束本轮”会保存并结束；“返回首页”保留活动轮，之后点击“继续练习”回到原位置。

有活动轮时，“结束本轮并开始新练习”会结束原轮并按当前模式/筛选/数量建立新轮。无匹配不会结束原轮；“继续练习”保留原模式、队列与版本，不重新应用首页选择，即使当前筛选无结果或已取消其中题目的收藏也能继续。随机轮重开后顺序不变，不再次洗牌；不同轮允许出现相同题目或顺序。新轮默认空输入、隐藏答案和历史，需要时再主动展开查看。

有活动轮时，可展开“本轮创建条件”回看原专题、搜索、标签、难度、自评状态和只看收藏条件。它保存的是创建时经过校验的条件，与首页为下一轮编辑的条件独立；继续仍使用原固定队列，收藏或题库更新不会改写原条件。旧版本创建的会话没有保存条件时，明确显示“原条件未知”，不会从当前题目反推。实现与修复范围见[会话筛选快照修复](M3会话筛选快照修复.md)。

开始请求结果未确认时，页面显示“重试开始本轮”，模式、专题、题数和筛选暂时锁定。点击重试核对原请求，不会另建随机轮。

练习操作后，按钮会短暂禁用至少半秒，避免双击或快速重复按键连续跨题。等按钮恢复后再进行下一次操作；持续按住 Enter 或空格不会自动连跳，需松开后重新按下。

切到下一题或上一题后会回到题首，题目标题接收键盘焦点，便于接着阅读或按 Tab 继续操作；完成/结束时显示并聚焦结果标题。同一题自动保存和揭晓不会主动重置阅读位置或抢走输入焦点。

使用 Tab 进入“我的答案”时，如果输入文字会被底部操作区遮住，页面会将输入框移到可见位置。已可读的输入位置和后续自动保存保持，不需要先用鼠标滚动寻找输入行。

## 保存、失败与退出

输入停止 500ms 后自动保存，操作区显示“待保存 / 保存中 / 已保存 / 保存失败”。切题、揭晓、自评、结束、返回首页和正常关窗前会立即提交最新输入，提交期间暂时锁定操作。草稿上限为 1MiB UTF-8，中文通常占多个字节；超限会报错，保留输入供缩短，不截断正文。

保存失败时输入仍在页面，相关切题不会执行；可修正问题后点击“重试保存”。如果页面显示操作结果尚未确认，使用“重试原操作”核实同一次请求，避免重复推进。此期间输入锁定，先完成核实；持续报数据库不可用时保留窗口中的输入并查看诊断日志，不凭一次报错判断事务未提交。

关闭窗口会先刷新草稿。无法确认保存时，系统提示默认选择“返回窗口”，可保留输入并重试；只有明确点击“放弃未保存内容并退出”才放弃尚未确认的文本。关闭程序重开后，可从首页继续已保存的活动轮。强制结束或进程崩溃只保证已确认保存的状态，未提交的按键没有恢复承诺。

## 长题干与参考答案

代码块可点击“复制代码”，保留代码原文；单次复制上限为 1,048,576 个字符，失败会显示提示。C、C++、ARM/Thumb（语言标记 `arm` 或 `armasm`）等代码支持高亮；未知语言或较大代码块仍完整显示纯文本。高亮不代表代码已经编译或验证。

点击图片可打开预览，在 100%～300% 间放大，按 Escape 或“关闭图片”返回；自动保存不会关闭预览或重置放大比例，小图放大不会增加细节。代码与表格可横向滚动，练习操作区随长内容保持可见。“我的答案”可点击标题折叠，默认跟随系统明暗，可在“设置与数据”修改主题和字号。

## 显示设置

进入“设置与数据”，选择“松间绿 / 晴空蓝 / 暖沙金 / 暮山紫”配色卡，独立选择“跟随系统 / 明色 / 暗色”和 15～22px 正文字号。右侧局部预览显示当前选择；点击“保存显示设置”后才全局应用并持久化，重开保留。正文、代码、表格和作答框使用所选字号，辅助提示/标题保留各自层级。手动明暗不随系统变化；跟随系统会自动响应。配色卡支持 Tab 和方向键选择；复制代码成功的对勾在 2.5s 后消失，复制失败提示保留。

保存过程中暂时不能切页或再次保存。失败时原已确认显示和本次选择保留，可修正问题后“重试保存显示设置”；结果尚未确认也按原目标重试。初次读取失败可“重试读取显示设置”，不会自动重置已保存值。正常关闭等待已发送的设置保存；失败选择返回窗口后可以重试，强制终止不保证尚未提交的选择。

## 遇到问题

格式错误按文件/行列修正；预览过期或失效则重新预览。数据库异常时保留原数据，查看数据目录 `logs/application.log` 并按具体错误处理，不通过删除数据库绕过错误。正常退出在保存协调后等待准备线程停止。

## 查看数据位置与诊断日志

“设置与数据”中的“数据位置”显示本次程序使用的数据文件夹、保护备份文件夹、日志文件夹和诊断日志文件位置。点击相应“打开…文件夹”可请求系统文件管理器打开固定位置；尚未使用过的备份或日志目录会在打开时建立为空目录，读取位置本身不会建立目录或数据库。

这里的备份目录用于迁移前和恢复前的保护备份；通过“导出完整备份”保存的文件以你当时选择的位置为准。诊断日志名为 `application.log`，发生诊断时才写入；仅打开日志文件夹不表示已经有日志文件。完整备份仍使用程序内的导出功能。

打开失败会显示错误，可以检查路径或权限后重试。打开处理中，显示保存、备份和切页暂时停用；正常关闭与恢复会等待已发起操作结算。数据位置读取失败可以重试，不会用猜测路径代替；数据库不可用时，错误页仍提供此面板。若程序连窗口都无法打开，启动错误提示会给出具体数据与日志位置。

Windows 中已有的 `Logs`、`Backups` 等同位置大小写变体可以正常使用；不是文件夹、子目录链接或实际位置改变时仍会拒绝。位置查看和文件夹打开不迁移或修改题库、草稿与设置，范围见[M4 第三批](M4第三批行为与验收.md)。

## 完整备份与恢复

在“设置与数据”点击“导出完整备份”，选择运行数据目录以外的保存位置。程序会将已经保存的题库、历史内容版本、图片、作答与自评、收藏、活动练习队列、创建条件和显示设置导出到一个 `.sqlite3` 文件，完成校验后提示成功。中文和含空格的路径可用。显示选项尚未保存时，先点击“保存显示设置”；练习中先通过“返回首页”完成保存，再前往设置导出。

备份文件独立于原 Markdown 和图片目录。请妥善保管，文件内包含学习记录与作答。导出期间不能切页或再次发起操作，正常关窗会等待导出收尾。取消选择不会写入文件。写入或发布失败时会保留当前数据与已有目标，检查目录权限、磁盘空间后可重试；不能选择当前运行数据目录、数据库别名或带有数据库伴随文件的位置。

点击“选择备份并预览”可检查文件，并查看题目总数、归档数、版本、图片、练习、草稿、收藏、自评和备份时间。损坏、其他应用、过新结构、数据关联或业务对象损坏会被拒绝。结构 1～5 的旧备份在独立副本中验证升级兼容性；旧备份没有时间记录时显示“未知”，不会将文件修改时间当作备份时间。

预览本身保持当前数据与来源文件不变。核对摘要后点击“恢复此备份…”，系统确认框默认取消；选择“创建保护备份并恢复”会替换当前题库、学习记录、练习进度和显示设置，成功后自动重启。恢复使用预览时已检查的副本，预览后原文件被修改或移动不会悄悄改变恢复内容；重新选择/导出或重新加载窗口后，旧预览失效。

恢复前程序沿用正常退出的保存流程，确认待保存草稿和已经发起的显示设置保存，并暂停其他数据操作。在当前数据目录的 `backups/before-restore-<唯一编号>.sqlite3` 创建并校验保护性完整备份；无法保存或无法建立保护备份时停止恢复，原数据保留，窗口可继续操作。失败后重新选择备份预览。没有点击保存的显示选项仍应先保存，避免将未确认选择误认为已经入库。

需要回到恢复前的状态时，可直接在“选择备份并预览”中选择这份保护备份，核对后按相同流程恢复。程序会再建立一份新的保护备份，不覆盖所选的旧保护文件。

替换前关闭全部数据库连接。替换失败会回退原数据并重启；自动回退也失败时退出并保留保护备份与 `restore-transaction` 现场，下次启动先检查未完成恢复，再打开数据库。遇到这类提示请保留全部文件和 `logs/application.log`，不要通过删除数据库或事务目录绕过检查。不要手工覆盖正在使用的数据库，也不要直接复制正在写入的数据库冒充一致性备份。范围和实际检查见[M4 第二批](M4第二批行为与验收.md)。
