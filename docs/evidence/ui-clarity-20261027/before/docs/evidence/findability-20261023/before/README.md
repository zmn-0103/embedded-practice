# 嵌入式刷题本

供个人使用的 Windows 离线刷题程序，内部标识为 `embedded-practice`。题目与参考答案在程序外通过 Markdown 维护，程序负责导入、练习和保存学习记录。

核心流程：导入题库 → 选择专题或筛选条件 → 阅读题目 → 输入答案或自行思考 → 揭晓参考答案 → 自评 → 下一题。

使用 npm 管理依赖，固定版本保存在 `package.json`，依赖解析结果由 `package-lock.json` 锁定。版本变化需要重新检查原生模块与打包兼容性。

## 开发与运行

开发环境为 Windows 11 x64、Node.js 24.19.x 与 npm 11.17.0。安装后的应用自带 Electron 运行时。

```powershell
npm ci
npm run dev
```

| 命令 | 用途 |
|---|---|
| `npm run check` | 主进程与界面类型检查、代码格式检查 |
| `npm test` | 503 项状态、解析、快照、接口、控制器与练习/管理/显示契约检查；仅扫描正式测试目录 |
| `npm run test:desktop` | 构建并测试开发版 Electron 的真实桌面流程 |
| `npm run build` | 类型检查并生成 `out/` 构建产物 |
| `npm start` | 运行已有构建产物 |
| `npm run pack:dir` | 生成 Windows x64 解包产物 |
| `npm run pack:win` | 生成 Windows x64 NSIS 安装包，禁止自动发布 |
| `npm run test:packaged` | 对已有 `release/win-unpacked/` 运行桌面测试 |

默认安装包：`release/embedded-practice-0.1.0-x64-setup.exe`。当前为未签名的 M0 工程验证版本，使用默认 Electron 图标。

`release/win-unpacked/` 已在本次会话筛选快照修复后重新构建，可启动其中的 `embedded-practice.exe` 使用导入、筛选收藏、顺序/随机练习、学习记录、历史与显示设置；实际运行结果见[修复证据](docs/evidence/session-filters-fix/README.md)。当前程序使用结构 6，升级旧库前生成并校验保护性备份。旧结构 5 或更低版本程序不支持新库；NSIS 安装包仍为 M0 历史版本，本次未重新制作或安装，请使用当前整个解包目录。

## 数据与题库

初始真实题库已从用户提供的 78 道 GPIO 自测题建立，原题和原答案完整保留；未自动导入应用。样例和测试夹具不自动加入正式题库。个人题库可在仓库外维护，或放入已忽略的 `question-banks/personal/`。

正式数据默认位于 `%APPDATA%/embedded-practice/`，开发运行默认使用 `%APPDATA%/embedded-practice-dev/`；自动化测试显式使用独立临时目录。数据库、备份、日志和本地练习数据不进入 Git。程序不得修改题库来源文件。
