## 首次失败及修复

初版20261023.2保留整个题库组件，但仅使用hidden，使已展开答案仍位于页面DOM；原M2在新轮开始时检出，开发/解包各1项失败。修正版使用稳定Portal容器，离页时从文档移出，返回时接回，组件状态和内部滚动保留；可见性变化使旧读取失效。对应7个新场景还覆盖52候选上限、模拟中文组合Enter、晚到响应、返回读取失败、跨页收藏变化及快捷条件不替换旧轮。组合事件为模拟，不等于原生微软拼音验收。

初包在 `release/findability-20261023/`，仅保留追溯，不推荐试用。修正版.3位于r2独立目录；后续通过不覆盖首轮340/342。
