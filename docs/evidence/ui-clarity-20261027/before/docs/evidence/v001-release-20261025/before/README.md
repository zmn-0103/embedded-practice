# 嵌入式刷题本

供个人使用的Windows离线刷题程序，内部标识embedded-practice。题目与参考答案在程序外用Markdown维护，程序负责导入、练习、草稿、历史、分类、方案与完整备份恢复。

## 可安装多主题试用版

**V0.0.0 测试版，构建20261025.1-themes，数据库结构10，Windows x64。** 支持多个本地主题包的安装、预览、应用、更新和卸载；保留原四套主题，并新增非官方Claude风格与学习工作区。主题切换保留原题库筛选、练习队列、草稿与学习记录。

打开[新交付目录的开始使用](release/V0.0.0-themes-20261025.1/开始使用.md)，用同目录“安全试用新主题.cmd”进入独立试用数据目录。完整程序、两个示例主题、原13专题419题及格式说明已放在该目录。旧个人程序、快捷方式及学习库不自动替换或迁移；结构10不能交给旧程序使用。

[主题使用与格式](docs/多主题系统行为与格式.md) · [完整主题计划](docs/多主题系统开发计划.md) · [当前交付与兼容边界](docs/当前试用版本交付说明.md) · [本批检查与失败](docs/evidence/themes-20261025/README.md)。应用仍离线运行，主题包只含严格配置，没有在线商店、脚本或外部资源。实际结果以[验收记录](docs/验收记录.md)为准，安装/人工/硬件及VMware原边界保持。

## 2026-10-24个人测试版基线（保留）

**V0.0.0 测试版，构建20261024.4-v000，数据库结构9。** 题库版本独立为bank-20261024.1-full433：8份资料433道原题全部有去向，合并24道重复原题，保留旧10道通用样题，最终13专题419题。GPIO78、UART原30及通用10的身份保留。

打开[交付目录](release/V0.0.0-personal-20261024.4/开始使用.md)，或直接运行[embedded-practice.exe](release/V0.0.0-personal-20261024.4/win-unpacked/embedded-practice.exe)，必须保留整个win-unpacked。同目录集中放有13份可导入题库、来源与433题去向、简短说明和反馈入口。既有数据位置与结构9保持，使用前先导出完整备份。

[使用与反馈](docs/V0.0.0使用与反馈.md)说明启动、导入、分类、继续旧轮与备份。文件夹不会自动建立本机分类；新专题在题库中按表安排归属，已有专题重导入保留原分类。题目难度与个人自评独立。

本版供实际个人试用，题目用户技术审阅和长期体验待完成，具体芯片修订、器件完整后缀、接线及硬件波形按题中条件。真实安装流程仍未验收，VMware及相关排障继续跳过。软件实际结果和首次失败见[验收记录](docs/验收记录.md)及[本批证据](docs/evidence/v000-personal-20261024/README.md)，不以自动化代签用户或硬件验收。
