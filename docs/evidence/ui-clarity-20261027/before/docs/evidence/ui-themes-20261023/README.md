## 问题与原始失败

- `preview-03-local-dark.png`：首轮局部暗色预览把整个表单的 color-scheme 一起改变，白色面板上说明文字对比不足；已把明暗预览限制到缩略图和阅读预览，加入同一页表单颜色保持检查。
- 首轮桌面配色 4 项失败：按钮背景做 120ms 渐变，文字立即换色，产生暂时对比不足。[逐帧原始颜色](contrast-transition-before.json)确认这一时序；只删除跨主题背景颜色过渡，阴影/折叠/复制反馈仍保留，不加等待绕过断言。
- 完整首轮两个失败是同一测试的备份 schema_version 旧预期为 6，实际正确为 7；只同步该字段后两形态完整场景 2/2 通过，不改生产代码或包，也不重复其余 328 个已通过场景。
- 初次类型检查缺旧测试的配色字段、新测试未用类型导入，旧 Schema 导出路径的斜杠表示和 ASAR 静态探针等工具问题见[tooling-notes.json](tooling-notes.json)。原始失败不会被后续结果覆盖。

## 证明范围

所有运行使用显式新建临时数据目录，不连接、覆盖或迁移正式学习库。桌面自动化中系统文件框选择、剪贴板、部分错误/丢响应是明确替身；业务服务、SQLite、真实窗口、新解包 EXE/ASAR 和恢复文件事务按对应场景实际执行。

页面 100%/125%/150% 缩放、900×620 窄窗口不代表重跑 Windows 实际 DPI；旧 M5d 原生系统缩放/输入法/外部能力结果仅证明当时程序。新 UI 的个人阅读偏好、全部原生输入法/DPI 组合仍待实际试用反馈，正式题目技术审阅继续由用户完成。

本轮没有生成新 NSIS、执行安装器、操作 VMware、提交、推送或发布。旧 M5 候选不包含新 UI，旧程序无法打开结构 7。交付入口及具体兼容边界见[当前交付说明](../../当前试用版本交付说明.md)。
