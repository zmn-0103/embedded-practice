# 可填写的专题模板

复制[专题模板](专题模板.md)到自己的题库目录后，替换专题 ID、名称、题目 ID、标签、正文和答案。文件中的占位文字只演示结构，不能作为已完成的题目内容；程序只校验格式，不检查占位文字是否已经替换。

专题和题目 ID 只允许小写字母、数字和连字符。一个文件是一个专题的完整快照；维护原专题时保留 ID 和已有题目，新题使用新的题目 ID。分区内部用四级及更深标题。

图片放在该 Markdown 旁的 `assets` 目录，用 `![说明](assets/文件名.png)` 引用。可以复制[格式示例](../examples/格式示例.md)及其配图试验；示例和模板不自动导入正式题库。
