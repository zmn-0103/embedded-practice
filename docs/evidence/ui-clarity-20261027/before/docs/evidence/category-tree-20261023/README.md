## 性能口径

Windows11 x64 10.0.26200、i5-13500HX、约16GB内存。复用上一批清单指向的5000题/500张128×96小图生成来源，先核对Markdown哈希，再复制新临时来源真实导入；没有读取旧运行库或个人学习数据。生产白名单创建两板块并各归入5专题，实际2500+2500题。

30次在A/B/全部分类间切换，起点为真实click事件，终点为正确题数及首题DOM后两帧；中位21.2ms、95分位25.2ms、最大25.9ms。未把定位与脚本等待计入绘制；样本没有学习历史，此项不冒称本批重测搜索/切题/启动、万条历史、低配机或长期内存。

[1440宽窗口](performance-01/category-1440.png)、[900宽窗口](performance-01/category-900.png)来自实际新解包capturePage。DOM检查无横向溢出，另人工查看图中导航/检索/展开与文字区域；属于窗口截图，不是Windows系统DPI验收。
