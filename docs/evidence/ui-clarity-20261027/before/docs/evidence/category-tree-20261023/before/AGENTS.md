# 项目协作规则

## 适用范围与事实来源

- 本文件适用于整个 `embedded-practice` 仓库；更近的子目录规则可以补充具体约束。
- 默认使用中文交流、编写项目文档和代码注释，沿用已有标识符与工具链风格。
- 需求基线为根目录[计划书.md](计划书.md)。用户后续明确指示优先；发现需求、文档和实现不一致时，说明差异并同步必要文档，不擅自缩减需求。
- 计划书保存用户提供的完整原文。后续修改需求时只调整相关部分并说明原因，保留可恢复版本，避免以摘要替换原文。
- 代码、实际运行日志和验收记录分别证明对应事实；目录存在、计划描述或测试名称均不代表功能已经完成。

## 模块职责

| 位置 | 职责与限制 |
|---|---|
| `src/main/ipc/` | 请求路由、主进程输入校验、调用来源校验和错误转换 |
| `src/main/services/library/` | Markdown 解析协调、导入预览、确认、版本比较、查询与归档 |
| `src/main/services/practice/` | 选题、固定队列、草稿、揭晓、自评、会话导航与恢复 |
| `src/main/services/resources/` | 图片类型与路径校验、资源入库、受控读取 |
| `src/main/services/backup/` | 一致性备份、恢复预览、保护性备份、替换与失败回退 |
| `src/main/database/` | 数据库连接、迁移、事务和持久化；事务边界服务于完整业务操作 |
| `src/main/workers/` | 批量解析、资源处理等后台工作，避免阻塞窗口响应 |
| `src/preload/` | 只暴露白名单桌面能力，不提供任意文件、SQL 或 IPC 入口 |
| `src/renderer/src/` | 展示、输入与交互状态；不直接访问文件系统、数据库或 Node.js |
| `src/shared/contracts/` | 共享 TypeScript 类型、校验契约与错误结构，不引入主进程专用能力 |
| `tests/` | 单元、数据库集成、组件、Electron 流程及独立测试样本 |
| `question-banks/` | 模板、显式示例及其配图；不作为运行数据库位置 |

纯解析、变更比较、队列生成等逻辑尽量与 I/O 分离。沿用现有模块边界，不为填满目录创建空实现或无价值转发层。

## 题库与导入契约

- 题目稳定身份是 `topic_id + question_id`。文件改名、标题或答案修改不改变身份；不使用内容哈希代替稳定 ID。
- 每个专题文件是该专题的完整快照；同批重复专题 ID 必须拒绝，未参与导入的专题不受影响。
- 按 Markdown 语法树识别题目和答案分区并保留原始正文，禁止只用正则按 `##` 切分。兼容 UTF-8 BOM、Windows 和 Unix 换行。
- 严格校验计划书第四章规定的字段、标题层级、唯一 ID、非空分区、难度、图片和大小上限；错误包含文件名、行号与原因，不静默截断。
- 导入必须先预览后确认；确认提交预览时已暂存且校验的快照，不无提示重读可能已变化的源文件。
- 题目、版本和图片在同一批次事务中提交，失败不得留下半批数据；重复导入相同内容应保持幂等。
- 内容版本与收藏、草稿、自评和历史分开存储；缺题归档，恢复相同 ID 时保留历史，不永久删除题目或记录。
- 题干、答案或引用图片变化时标记“内容更新待复习”；仅标签或显示顺序变化不触发该标记。最新掌握状态只采用对应最新内容版本的自评。
- 图片只支持 PNG、JPEG、WebP，必须来自该 Markdown 文件旁的 `assets` 目录；校验规范化后的实际访问路径，防止逃逸到目录外。
- 禁止导入远程图片、绝对图片路径、SVG、原始 HTML 和脚本；缺图或不支持的图片引用必须报错。
- 图片内容复制入库并按哈希去重，历史版本仍引用的图片不得提前清理；导入后不能依赖原始文件路径，也不能修改来源文件。

## 练习、保存与统计契约

- 每轮保存固定、不重复的题目队列与对应内容版本；重启保持队列和位置，导入更新不得中途替换本轮内容。
- 每题首次进入隐藏参考答案，揭晓前答案正文不得挂载到页面正文或无障碍阅读树。新一轮不自动展示上次答案、历史作答或揭晓状态。
- 允许空输入揭晓；搜索默认不展示参考答案片段。
- 自评只在揭晓后可用；揭晓、未评价、跳过、自评及收藏的含义分别处理，不显示未经定义的“系统正确率”。
- 同一轮同一题修改自评更新原记录，不重复累计次数；新一轮产生新历史。自评保存与推进位置必须同一事务完成，处理重复点击和重试。
- 输入停止 500ms 后保存草稿；切题、揭晓、返回首页和正常退出前提交待保存内容。使用递增修订号拒绝过期请求覆盖新内容。
- 明确展示保存中、已保存和保存失败；失败时保留输入，阻止依赖该次保存的切题并允许重试，不宣称未提交按键可在强制结束后恢复。
- 最多保留一个可继续的活动会话；无匹配题目时不创建空会话。收藏与掌握程度独立。

## 数据保护与桌面边界

- 运行数据位于 Electron 用户数据目录，与安装目录分离。题目、图片、学习记录和设置均纳入完整备份。
- 开发运行默认使用 `embedded-practice-dev` 数据目录，安装版默认使用 `embedded-practice`；自动化测试必须显式传入独立临时目录，不依赖这两个默认目录。
- 测试必须使用独立临时数据库和数据目录，禁止连接、覆盖或迁移正式用户数据库。样例与压力数据明确标识，不自动进入正式题库。
- 使用 SQLite 一致性备份能力，禁止直接复制正在写入的数据库冒充完整备份。
- 恢复前检查完整性、应用标识与结构版本，并展示恢复摘要；自动备份当前数据失败时停止恢复。
- 恢复采用暂存、校验、关闭连接、替换与失败回退流程，处理数据库伴随文件；损坏或更新结构版本的备份不得覆盖当前数据，恢复成功后重启应用。
- 数据库迁移前备份；失败保留可恢复数据并提示，禁止自动重建空数据库掩盖失败。历史版本暂不自动清理。
- 开启上下文隔离和渲染进程沙箱，关闭渲染进程 Node.js 集成。桥接接口使用共享类型，主进程仍需重新校验输入与调用来源。
- Markdown 通过受控组件展示，图片仅通过已导入资源 ID 读取；不把题库当作可执行页面。外链只允许明确验证的 HTTP/HTTPS 地址。
- 实现单实例限制；错误向界面返回统一错误码、中文说明及必要定位，堆栈仅进入本地诊断日志。日志默认不记录完整题目、用户答案或敏感信息。
