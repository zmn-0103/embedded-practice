# 参考答案

建议完成前面的题目后，再查看本部分。

## 一、基础概念

1. General-Purpose Input/Output。输入用于读取外部信号，输出用于控制外部电路。
2. GPIO 外设需要相应时钟才能正常工作。
3. APB2。
4. 更新软件变量 `SystemCoreClock`；不能替代 GPIO 时钟使能。
5. 通用输出由软件控制输出数据状态；复用输出由片上外设控制引脚信号。
6. 推挽可以主动驱动高低电平；开漏可主动拉低，输出高电平通常依赖上拉。
7. GPIO 输出驱动速度等级，不是 MCU 主频。
8. 为输入引脚提供默认电平，避免悬空造成不确定状态。
9. 取决于外部电路和按键的有效电平。
10. 复用 GPIO 只是引脚配置，还需要配置对应外设和映射。

## 二、标准外设库

11. `GPIO_Pin`、`GPIO_Mode`、`GPIO_Speed`。
12. 第一个参数指定 GPIO 端口，第二个参数是配置结构体地址。
13. 使能 GPIOA 的 APB2 外设时钟。
14. `SetBits` 将输出数据位置 1；`ResetBits` 将输出数据位清 0。
15. 返回 `uint8_t`；`Bit_SET` 表示高电平，`Bit_RESET` 表示低电平。
16. 前者读取 IDR 输入状态；后者读取 ODR 输出数据状态。
17. 不决定输入采样速度；该成员主要用于输出模式的速度配置。
18. 兼容不支持混合声明的旧式 C 编译模式。

## 三、工作模式与配置字段

19. 模拟输入、浮空输入、输入上拉/下拉。
20. 通用推挽、通用开漏、复用推挽、复用开漏。
21. 通用推挽输出。
22. 通用开漏输出。
23. 复用推挽输出。
24. 4 位。
25. CRL 配置引脚 0～7；CRH 配置引脚 8～15。
26. MODE 决定输入/输出及输出速度等级；CNF 决定具体输入/输出配置类型。
27. MODE=`10`，CNF=`00`。
28. MODE=`10`，CNF=`01`。
29. MODE=`00`，CNF=`10`。
30. CRL/CRH 字段相同；上拉/下拉方向由对应 ODR 位选择。

## 四、寄存器与位掩码

31. IDR：输入；ODR：输出数据状态；BSRR：置位/复位；BRR：复位。
32. IDR 反映输入引脚状态，ODR 保存输出数据状态。
33. BSRR。
34. BRR。
35. 低 16 位置位，高 16 位复位。
36. 它们允许针对指定输出位执行置位/复位，而无需读改写整个 ODR。
37. `0x00000020`。
38. 引脚掩码选择引脚；字段掩码定位配置寄存器中的 4 位字段。
39. Bit 23～Bit 20。
40. `0x0F` 是 `1111`，左移 20 位后覆盖 Bit 23～Bit 20。
41. 清除目标字段，保留其他位。
42. 将新配置左移到目标位置，再写入相应字段。
43. 按位或不能把旧字段中的 1 清除。
44. 会破坏其他引脚的配置。
45. ODR 位用于选择内部上拉或下拉方向。

## 五、寄存器推导题

46. `GPIOA_CRL`，Bit 3～0，字段值 `0010`。
47. `GPIOA_CRL`，Bit 15～12；MODE=`01`，CNF=`00`，字段值 `0001`。
48. `GPIOA_CRL`，Bit 23～20，字段值 `0010`。
49. `GPIOA_CRH`，Bit 3～0，字段值 `0010`。
50. `GPIOA_CRH`，Bit 7～4；MODE=`10`，CNF=`01`，字段值 `0110`。
51. `GPIOC_CRL`，Bit 7～4；MODE=`00`，CNF=`10`，字段值 `1000`；对应 ODR 位还需置 1。
52. `GPIOC_CRL`，Bit 27～24；MODE=`00`，CNF=`01`，字段值 `0100`。
53. `GPIOC_CRH`，Bit 23～20；MODE=`00`，CNF=`10`，字段值 `1000`；对应 ODR 位需清 0。
54. `0x0F << 12`。
55. `0x0F << 0`，即 `0x0F`。
56. 先清除旧字段，才能准确写入新配置。
57. 对应输出数据位置 1。
58. `0x0000`，因为 PC1 对应 IDR 位为 0。

## 六、硬件与程序分析

59. PA8；低电平点亮。
60. PC1；按下时接地，为低电平。
61. 内部上拉使松开状态通常为高电平，按下后电路接地。
62. LED0 点亮。
63. LED0 熄灭。
64. 需要 PC1 已正确配置且按键电路正常；低电平对应按下。
65. GPIO 可能无法按预期工作。
66. 可能无法正确读取按键，甚至造成与外部电路争用的风险。
67. LED0 可能先点亮，随后程序读取松开状态并将其熄灭。
68. 可以避免引脚切换为输出模式时先出现不期望的输出电平。

## 七、软件消抖

69. 机械触点接通、断开时短暂反复变化的现象。
70. 程序可能多次采样到高低电平交替。
71. 第一次采样、延时、第二次采样、比较结果、稳定时再处理。
72. 为机械触点提供稳定时间。
73. 保持 LED 原状态。
74. 不能；稳定高电平代表松开，稳定低电平代表按下。
75. 抖动时间和波形因按键而异，采样策略也有限制。
76. 会阻塞 CPU。
77. 消抖确认电平稳定，事件管理还需要识别按下、保持、松开及避免重复触发。
78. 能减少阻塞，让 CPU 在等待期间继续执行其他任务。
