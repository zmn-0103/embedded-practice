# 嵌入式通用基础：10题小样

2026-10-24。五个专题各2题，题目和参考答案放在同一文件，答案由程序在练习时隐藏。这是一批待用户审阅、用于确认深度与表达的小样，尚未扩为约30题版。

## 导入与试用

在当前[练习方案试用程序](../../release/practice-plans-20261024/win-unpacked/embedded-practice.exe)的“题库 → 导入题库”中，同时选择下列五份文件；不要把本说明或原始资料快照作为题库导入。程序需保留整个 `win-unpacked` 目录，构建为20261024.1-plans、数据结构9。

| 专题文件 | 专题ID | 固定题目ID | 本批考点 |
| --- | --- | --- | --- |
| [GPIO通用基础](GPIO通用基础.md) | `general-gpio` | `gpio-general-001`、`gpio-general-002` | 推挽/开漏与上拉；按键消抖与一次事件 |
| [UART通用基础](UART通用基础.md) | `general-uart` | `uart-general-001`、`uart-general-002` | 帧开销与理论时间；文本消息边界与超长恢复 |
| [SPI通用基础](SPI通用基础.md) | `general-spi` | `spi-general-001`、`spi-general-002` | 极性/相位与采样边沿；全双工读取与供钟 |
| [I2C通用基础](I2C通用基础.md) | `general-i2c` | `i2c-general-001`、`i2c-general-002` | 7位地址与线上字节；重复START与应答方向 |
| [ADC通用基础](ADC通用基础.md) | `general-adc` | `adc-general-001`、`adc-general-002` | 编码数与理想步长；SAR采样建立 |

首次导入这些新身份，预览应为新增10，其余0；原样重复导入应为不变10，其余0。若个人库已导入或修改过同身份内容，预览以实际差异为准，先核对再确认。

导入后可在分类管理中创建“嵌入式通用基础”，再将这五个专题归入该板块。文件夹不会自动建立程序内分类。此操作由使用者明确执行；本次检查只在新建临时库建立分类。

然后在“开始练习”选择该分类、全部专题、全部题数，按顺序练习10题。每题先独立作答或思考，再揭晓、自评；可在中途保存退出并重开继续。深度、答案长度、条件是否清晰，以及技术问题，记录到[样题审阅与试用表](../../docs/通用基础样题与试用.md)。

## 身份、来源和维护

这批题从原始学习资料提取考点并重写，不覆盖旧STM32题的身份与学习记录；每题都有明确题设，不能只换芯片名称。标签表达跨专题考点，初始难度每专题1道基础、1道进阶，不代表用户掌握程度。

来源为用户指定目录下8份自测资料，433道原题已作范围筛选；49道原题合并贡献到这10道小样，其余仅记录候选处理方向。[来源入口](../sources/general/README.md)提供逐字节原文快照、逐题处理清单、样题映射和技术核对范围。官方资料链接放在答案区；静态核对和导入通过均不能替代用户技术审阅或硬件验证。

以后扩充时保留已有专题/题目ID，并给每个专题提供包含旧题和新增题的完整快照。不要只导入同专题新增片段，否则程序会按完整快照规则预览归档缺失题目。格式与版本规则见[Markdown V1契约](../../docs/MarkdownV1题库格式.md)。
