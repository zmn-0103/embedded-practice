## 内容与身份维护

- [原始自测题](sources/STM32F103RCT6-GPIO-原始自测题.txt)保留用户提供的题目、答案及顺序。
- [题答对应清单](sources/STM32F103RCT6-GPIO-题答对应.json)记录原问题、原答案、章节、顺序与固定 ID，方便逐题检查错配和遗漏。
- 正文保留每道原题，参考答案开头保留原答案；必要的补充集中在四级“补充说明”中，没有以改写代替原文。
- 补充覆盖配置结构体成员作用、输出锁存与实际电平的区别、先清字段再写入、复用映射条件，以及阻塞延时与 CPU 忙等待的区别。
- 初始难度是整理时的分类：寄存器推导题标为“进阶”，其余为“基础”，可后续修改；这不是掌握程度评定。
- 后续补充答案、改标题、改文件名时保留已有专题 ID 与题目 ID；新增题目使用新的 ID，不重新编号现有题目。

## 条件与技术依据

LED0 接 PA8、低电平点亮，以及 KEY0 接 PC1、按下接地等接线来自用户给出的实验前提。相关题目已注明范围，不能推广为所有 STM32F103RCT6 开发板的固定接线；本次没有原理图核验或板上验证。

寄存器配置按 STM32F1 的 CRL/CRH、MODE/CNF 体系理解，不能套用其他 STM32 系列的 MODER 配置。参考：[ST RM0008](https://www.st.com/resource/en/reference_manual/cd00171190.pdf)、[Arm CMSIS 系统时钟说明](https://arm-software.github.io/CMSIS_6/main/Core/group__system__init__gr.html)。标准外设库接口细节仍需与实际项目采用的库版本对照。

## 与应用的关系

这是待使用的真实初始题库，不是程序启动时自动写入的数据。当前程序已接通文件格式解析、图片验证、批次快照、预览确认、数据库导入与题库界面。题答清单用于对应核对，不是对全部技术答案、实验现象或程序行为的自动验证。

2026-10-22 另提供[UART 第二层 30 题试用选集](trials/README.md)，来自用户指定笔记的原第19～48题，专题与已有GPIO独立。选集保留原题答及来源映射，已完成生产导入/重复/临时更新/重开与30题流程检查；来源技术审阅和真实学习体验仍待完成。5,000题/500图生成压力样本只在独立临时目录，不作为真实题库交付。

[可填写模板](templates/README.md)和[真实配图格式示例](examples/README.md)已提供；模板的占位文字和演示题不是正式题目，不自动导入。示例配图仅供验证格式，不代表用户开发板或电路。
