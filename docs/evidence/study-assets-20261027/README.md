## 覆盖的用户流程与数据保护

笔记真实保存/UTF-8上限/清空修订/CAS/原命令幂等、未知响应锁定原操作、实际触发器写失败原输入与正常退出保护、跨页同题同步/跨轮重开、题库重导入和归档保留；练习揭晓前笔记零读取，揭晓后仍主动打开。

结束轮20条分页、按成员专题交集、活动轮排除；摘要/队列只读元数据，主动展开才读取单题；无作答排队项也能复盘但不补造历史。跨历史页选两次，确认前零详情读取，不同版本提示，自己的回答并列/窄栏上下，参考答案不挂载；全表快照确认复盘只读。

结构12夹具来自前一.4真实EXE创建的新TEMP，来源见schema-v12-source.json，22个对象/7888字节，SHA256为4a923af302982bb2513ca5a441e45300419bc4c33ffa6fd52e36259d2547c52c。升级前保护备份、仅空笔记表/原轮题单草稿与自定义DDL保持；备份受阻/同名表/外键失败完整回滚；恢复含笔记及清空修订/轮次/题单/活动草稿，坏修订/时间/孤儿/超量/重复拒绝，原备份保持。

三种真实导出内容分别核对默认答案/个人信息隔离、代码/表格、图片字节哈希与来源文件移走；题单当前版无记录不套旧作答，旧轮采用当时版本/本轮作答，答案明确导出不改变揭晓。取消/归档失效/坏图/活动轮/超500题拒绝整批，应用数据/非Markdown目标不写；单元另核对原子替换、清理本次暂存资源、旧文件保护和任务取消。六IPC严格来源、参数、输出、恢复暂停/关闭、悬空对话框取消与迟到不写。
