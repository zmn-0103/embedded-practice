## 本批契约

- 在普通题库列表勾选有效题目，按勾选先后组成临时集合；跨专题、筛选、分页与同次打开内的页面切换保持，重复身份不重复加入。清空仅清空临时勾选。第一版每轮/题单最多500个明确题目，最多100份题单，超限明确拒绝、不静默截断。
- 固定题单保存名称和有序topic_id＋question_id身份，不保存筛选条件、答案或题目版本。与动态练习方案分开。可保存新题单、载入并明确替换勾选、更新/改名和删除定义；删除不删除题目、历史或已建轮。
- 名称沿用去首尾空白、1～60字符、无控制符及SQLite ASCII NOCASE唯一。更新核对原名称/完整身份列表，过期编辑拒绝；响应未知按原操作重试，不重复保存或盲覆盖。列表和预览失败保留错误与输入，关闭等待在途写入。
- 题单重导入后仍按稳定身份关联。预览逐项显示可用、已归档、已失效，缺项保留；用户明确移除不可用项后才能创建较小集合，不自动补题或替换其他题目。
- 勾选和题单练习采用开始前预览的当前有效内容版本。主进程建轮事务再次校验全部身份/版本/归档状态，任一变化拒绝整轮并保留原活动轮；用户重新预览后再确认。创建时保存固定队列及版本，新轮重新隐藏答案。顺序模式按所选顺序，随机仅重排这些题。
- 查看本轮清单只读取题目身份、标题、是否揭晓、自评和曾跳过，禁止读取/返回题干、参考答案或旧作答。按50题分页，定位当前位置；单独显示“尚未揭晓”“已揭晓未自评”“不会/不熟/掌握”及“曾跳过”，不把跳过写为不会。
- 点击清单指定题仍走原草稿/事务/回执守卫：先保存当前输入，失败留在原题；成功只变位置，不揭晓、评价、补题或改队列；未知结果重试原目标/请求。查看清单本身不保存或改变练习，原自动保存计时仍照常。
- 结构12新增题单定义/成员和勾选来源名称；旧库先一致性保护备份再事务迁移，旧轮字段为NULL。完整备份与恢复包含题单、顺序及来源；旧程序不能打开结构12。所有测试与试用用独立目录。
