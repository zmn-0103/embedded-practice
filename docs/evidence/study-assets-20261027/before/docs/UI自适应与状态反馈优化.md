2026-10-27，承接[第一批及用户完整结论](UI可读性与操作层级优化.md)，用户明确要求“继续”。本批完成高缩放/小窗口空间、概览下一步、板块状态、设置与记录反馈；产品0.0.2、结构10，新增独立构建20261027.2-ui-adaptive。原第一批程序、源码快照、所有证据与个人桌面/学习库保持，不自动提交、推送或更换桌面。

## 本批行为

| 方向 | 已采用实现与边界 |
|---|---|
| 小窗口与程序缩放 | 有效CSS视口不高于600px时，压紧底栏间距与工具按钮，阶段补充说明保留可访问文本；原自评、暂不评价、返回、上一题和结束均可见。正文15～22px及输入200px/最小180px保持。输入聚焦时按真实底栏与视口尽量展示完整输入区，超高手动输入框仍保证首行。正常态与失败面板分别检查，不因压缩丢失错误重试。 |
| 概览下一步 | 首次确认空库突出导入，有题无活动轮突出开始新练习，有活动轮突出继续原轮；统计为辅助。开始新练习仅进入原配置页，确认后才创建队列。题库状态未确认时给出读取/重试方向，不显示已经可开始的假象；已知活动轮仍可继续。 |
| 板块状态 | 可练习、规划中、仅有归档、暂无内容分别标识；规划/空分类用较弱表面与虚线、保留文字对比度，有效入口仍受真实题数约束。规划可展开，归档入口独立可达；没有匹配时可清空搜索/拓展/有题展示条件，不写分类或题目。 |
| 设置反馈 | 从本地表单与已保存值派生待应用/已应用/应用未确认等提示，选主题仍只预览，保存并应用后生效。恢复默认沿原即时保存行为，并明确说明其立即生效、学习数据保留。未改变安装主题与应用主题、备份或数据位置接口。 |
| 学习记录 | 统一“有效题目”，范围选择即时生效；新增重置记录范围回到全部分类/专题/有效题目，只改变显示范围，不删除学习记录。下方题目筛选仍不影响上方统计，加载/无范围内容/读取失败各自保留原路径。 |

沿用现有公共组件、主题语义变量、本机字体、字号约定与构建工具，不添加依赖/在线资源。主进程、数据库、IPC、题库与练习控制器保持，不能把设计改进写成用户测试已确认的缺陷。
