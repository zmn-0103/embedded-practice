## 工具与步骤偏差

- 原生文件框首次 `set_value` 定位失败，错误为 `element 171 is not available in cached app state for embedded-practice.exe`。之后工具多次检测到用户输入，停止自动点击，由用户实际完成导入；不伪称自动操作已完成。
- 最初指导误把收藏安排在练习页，已更正为题库详情。首轮实际 ended/未自评与目标关闭/自评不同，记录实际结果并补做目标场景，不据此认定新缺陷。
- 只读探针输出在控制台遇到中文编码显示问题，UTF-8 JSON 文件单独校验；终端显示不作为文件损坏依据。
- 后续只读快照首次 SQL 字符串引号遗漏，停止在查询阶段，改为 `length(draft)>0` 后重读；没有业务写入。工具还出现一次备份按钮位于屏外、一次 geometry 不可用和一次刷新参数 false/false 被拒绝，分别滚动/重新识别/修正参数后继续。原生步骤保留原错误，不将工具错误算成生产缺陷或运行通过。
- 可访问性树和截图曾短暂不同步，保存了初始观察与后续稳定观察，未据此断言计时性能或改应用交互代码。
- 运行环境更新后，原程序和记事本窗口/进程均不在，原因未知；没有把这次消失签成正常关闭或认定崩溃。[独立只读核对](post-runtime-change-check.json)确认数据保持，后续复开与普通 Alt+F4 正常关闭另有证据，不能覆盖这次未知观察。
- 收尾静态核对首次遇到报告链接尚未生成，另一次发现工具返回的 89 张 JPEG 截图被保存成 `.png` 后缀。已在本批证据目录内仅改名为 `.jpg`，逐份 SHA-256 保持，用户提供的 PNG 原名保留；[改名对应表](screenshot-format-correction.json)及[工具核对偏差](tooling-notes.json)独立记录，未转换图片或改写历史证据。

## 仍未验收

20 题原生界面走查不等于用户技术审阅、真实学习或完整主观体验。长答案/大段代码、前导缩进和多类编辑器、真实大图、多系统 DPI、完整中文输入法组合及键盘、真实系统浏览器、完整离线、性能、新 NSIS 与安装升级尚未验收。历史键盘偏移、额外字符及候选中 Alt+F4 一次未关闭仍待定位。

本轮没有修改生产源码，也没有重新运行全部单元测试或桌面测试。M4 第三批旧报告保持原有证明范围，不能当成本轮新执行结果。
