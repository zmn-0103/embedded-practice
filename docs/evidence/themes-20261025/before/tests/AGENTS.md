# 测试目录补充约束

继承[根规则](../AGENTS.md)。运行方式见[开发说明](../docs/开发说明.md#运行与测试前的目标核对)，数据边界见[数据保护契约](../docs/数据保护与桌面边界.md)。

- 桌面检查先明确开发/解包形态；解包形态显式设置 `EMBEDDED_PRACTICE_PACKAGED_EXECUTABLE`，按[交付说明](../docs/当前试用版本交付说明.md)核对 EXE、构建标识和目标结构。旧版本仅用于明确标注的兼容性场景，不能冒充当前程序。
- 每场景使用新建独立临时目录，通过 `EMBEDDED_PRACTICE_TEST_DATA_DIR` 传入，并核对应用实际数据路径；不依赖默认开发库或个人库。
- 旧结构 SQL 夹具保留生成程序、构建/结构和哈希来源。需要新的结构时另建夹具，不重写旧夹具来适配当前结构；迁移检查同时核对保护备份、原业务数据及失败回滚。
- 保留首轮失败、报告及必要现场；修正后另存新轮次。定位器应匹配实际可见交互，不以删除断言、放宽范围/超时、增加重试或操作隐藏控件掩盖问题。
- 报告分别列明场景覆盖、运行形态及替身边界；重复定向不累计成不同场景，不将精确字段或旧业务回归缩减为只检查数量。
