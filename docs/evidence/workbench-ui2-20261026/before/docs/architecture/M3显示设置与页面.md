# M3 显示设置与页面

日期：2026-10-21。范围见[第五批行为](../M3第五批行为与验收.md)，实际运行另见[证据](../evidence/m3e/README.md)。

## 数据与迁移

`appearance_settings` 是 SQLite STRICT 单行表，固定 id=1。主题只允许 system/light/dark，字号为 15～22 的整数；新库与受支持旧库升级时插入 system/17。结构版本为 5，设置与题库、图片、作答同处受控数据目录，不使用 localStorage 或任意文件写入。

v1/v2/v3/v4 都先使用 SQLite 一致性备份，检查完整性、应用标识与旧结构版本，再开始迁移事务。v4 仅追加设置表，不重建会话；已有会话索引/触发器保持。v3 仍沿用会话 CHECK 约束替换，拒绝未知会话索引/触发器，v1/v2 沿用已有升级路径，最后创建设置表、检查外键并设置结构 5。备份失败停止；表名冲突、DDL 或外键失败回滚，不能自动创建空库。旧结构 4 程序及旧 M0 NSIS 不能打开结构 5。

仓储读取固定行并严格校验；缺行、坏行或数据库错误返回失败，不补写默认值掩盖问题。保存是完整 theme/fontSize 目标，在即时事务中 UPDATE RETURNING 并校验后提交；失败回滚。不增加学习记录或计数，提交成功但响应丢失时重试同一目标仍得到相同状态。

## 能力边界

共享契约只提供 `settings.read()`、`settings.save({theme,fontSize})`。预加载仅调用固定通道；主进程仍检查可信主 Frame、严格参数/响应及服务关闭状态，异常转换为中文错误，详细异常写入现有本地诊断。没有路径、SQL、CSS、系统命令、备份恢复或任意 IPC 能力，CSP 与沙箱保持。

## 显示与异步状态

App 层读取和保存设置，使用代次/挂载状态拒绝过期读取，捕获完整目标并用进行中 Promise 防止重复保存。保存成功才更新已确认值与根元素 data-theme/data-font-size；失败保留已确认显示及表单选择，允许重读或重试。初次读取失败不显示伪造默认表单。设置页外有错误入口，练习中不能通过此入口绕过离开前保存。

CSS 通过固定选择器设置字号变量，没有内联样式或动态 CSS。手动主题优先；system 随 prefers-color-scheme 变化。正文、Markdown 代码/表格和练习输入框使用 rem，代码高亮颜色随明暗变化；部分辅助提示与标题沿用既有固定层级，不承诺所有标签同字号。

设置保存时禁用表单和页间导航。正常关闭继续经过练习握手，等待进行中的设置保存；失败返回窗口时复位原关闭状态，防止练习控件永久禁用。该过程不保证强制终止前尚未发送或确认的选择可恢复。

## 四个入口

开始练习、题库、学习记录、设置与数据分别展示对应页面。导航是可访问链接，阻止默认锚点跳转以保持受信任页面的精确 URL；不是新增路由权限。练习工作区始终挂载，以保持控制器、首页条件和关闭监听；非当前页通过 hidden 隐藏。练习中隐藏主导航，原返回首页仍先保存。

导入面板跨页保留，已暂存预览不会因查看记录或设置丢失；题库浏览/记录和设置表单按当前页面挂载，题目/历史/答案保持按需规则。设置页明确完整备份恢复待后续提供，不伪造可用按钮。完整恢复、数据位置操作和发布验收仍属于后续阶段。
