# M1 第二批：源文件、图片与批次快照

日期：2026-10-20。沿用第一批纯解析器，建立导入前的数据准备链路；M1 整阶段继续开发。

## 本次行为

1. 输入用户选择的一个或多个 Markdown 绝对路径，严格按 UTF-8 解码，兼容 BOM 与原有换行。不修改来源文件或数据库。
2. 每个 Markdown 限 20MiB，每张图片限 10MiB；整批 Markdown 与实际读取的图片源文件合计不超过 200MiB，题目合计不超过 10,000 道。同批重复专题 ID 拒绝。
3. 图片只从该 Markdown 旁的真实 `assets` 目录读取。统一词法规则，并在访问前后核对真实路径；目录链接或文件链接不得使访问越出该目录。
4. 根据图片内容识别 PNG/JPEG/WebP，要求与扩展名一致，读取正整数尺寸，计算 SHA-256。文件缺失、读不了、超限或头部无效时返回来源 Markdown 的图片行列。
5. 文件采用只读句柄和有界读取，检查读取期间的长度/时间变化并关闭句柄；无法得到稳定数据时拒绝该次准备，允许重新选择或重试。
6. 成功返回完整的专题、原文、图片字节副本、内容哈希及 URL 到资源哈希的绑定。相同内容图片在批次结果中只保留一份；后续确认必须使用这份快照，不重新读取来源。
7. 任一文件或图片出错则整批失败，不返回部分成功快照。总大小按 Markdown 和不同规范化源路径计数，内容相同但路径不同的图片仍计入来源大小；同一来源重复引用不重复计数。
8. 提供可填写的专题模板和带真实 PNG/JPEG/WebP 的两题格式示例；占位文字和演示题不自动进入正式题库，程序内导出入口后续接入。

## 验收条件

- 真实 PNG/JPEG/WebP、中文/空格文件名、编码 URL、同图多次引用和跨文件内容去重。
- 缺图、目录代替图片、伪后缀、空文件、截断头部、超限、越界路径、嵌套目录 junction 和 `assets` 根目录 junction。
- 严格 UTF-8、重复专题、整批题量与大小上限、混合有效/无效文件完整失败。
- 准备成功后修改或移走来源，返回的题干与图片字节仍为原快照；来源没有被本服务改写。
- 每个代码文件依次完成 Bug 与优化检查，实际运行另存验收证据；回归原有解析与桌面行为。

## 边界

本批不添加数据库表、预览令牌管理、导入界面或练习功能，后台工作线程与界面调度后续接入。图片尺寸工具进行格式头部检查，不代表完整像素解码、所有图片损坏检测或实际显示验收。后续显示链路仍需处理解码失败。

本地真实路径核对用于限制静态链接与常规来源变化，不宣称可以对抗具有同等文件系统权限的进程持续替换目录或挂载点。所有自动化使用明确创建的独立临时目录，不接触正式数据库。
