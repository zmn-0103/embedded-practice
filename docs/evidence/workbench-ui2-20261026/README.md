## Windows文件编号精度补充

[本机诊断](windows-file-id-diagnostic.json)在本轮独立TEMP目录创建48个普通文件，47个ino超过Number安全整数，其中两个不同精确编号172544160723982050和172544160723982063被Number表示成同一值。原备份别名规则比较Number，因而有将独立文件误拒绝为当前库别名的缺陷。

新增用例只替换本轮主进程的文件状态元数据，实际导出、预览和数据库读取仍执行真实路径。旧r4确定失败；修复仅对目标lstat与运行库stat启用bigint，独立精确编号可预览，精确编号相同仍拒绝。原真实符号链接、硬链接、目录、WAL/SHM/journal及恢复保护断言均保留。[最小差异](backup-precision.diff)另存。r4完整回归那次失败未记录当时精确编号，不能把之后证实的同类缺陷当作该次已确认根因。
