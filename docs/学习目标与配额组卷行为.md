# 每日、备考目标与分专题配额组卷

2026-10-29，用户要求继续后续批次，本批按原候选顺序实施目标与配额。产品0.0.2、构建20261029.3-study-goals、结构17；前批源码、完整交付和原始报告保持，逐文件两轮复查，不自动提交推送。

## 目标与日历

- 每日目标按本机日历日期分别保存，自评不同题数/明确完成不同复习待办数各0～500，0表示不设置该项。可明确沿用最近一次目标，不自动给未来补设。
- 活动从本版起在成功业务写入同一事务记录：非空自评、首次练习揭晓、待办pending→done、真实笔记变更；重复回执/同内容重试不重复记。自评目标按稳定题目去重，重复练习保留活动次数；完成后重开/延期不抹去当日已发生事实。同题同日再次完成待办仍只增加一次目标进度。
- 练习揭晓次数、成功笔记保存次数单独展示，不计入自评目标。只浏览题库/答案不计目标，原只读接口不改为写统计。旧版本没有完整活动账本，不补造过去次数；日历仍可按现存开始/结束/揭晓/自评时间回看原有轮次，旧活动可能不完整。
- 点击月历日期可看当天活动元数据与轮次，均20条分页。已结束轮沿原复盘入口，活动轮提示去继续；活动不保存答案/笔记正文。记录日期固定为发生时本机日期，恢复或换时区不回算新账本。
- 备考目标由用户创建名称、若干固定题单和可选截止日，最多20个。范围按所关联题单的当前成员去重，题单编辑后范围随之变化；失效题单/归档/失效题明确显示，不扩大或补题。当前版本练习覆盖与自评掌握分别显示，不声称系统正确率或已经掌握。
- 从目标整体或明确一份题单取身份，进入原组卷确认；整目标超过单轮500题时提示分题单练习，不截断。目标定义修改/删除有修订保护，不删除学习记录。旧轮仍按固定队列，不随目标变动重抽。

## 配额

开始练习提供一套可保存复用的配额设置，每行唯一专题、1～500题、随机/不会与不熟优先/最久未练优先，最多20行、合计最多500题。同一专题不得重复，稳定身份去重，不按文字内容误合并跨专题题。

随机从该专题活动题抽取；薄弱优先先当前不会/不熟，再未自评，最后掌握，组内沿原题库顺序；最久沿现有当前版本未练/揭晓时间/时间未知规则。每次重新预览实际题目和各行需求/可用/缺额；任何专题缺失或不足都不能进入确认，不从其他专题补题。保存设置不会开始练习，编辑后可明确保存并预览；设置与已建轮队列分开。

成功预览后把这些明确身份交原SelectedPractice，再核对当前内容/归档并明确开始，可只打乱这批题。原活动轮、未知回执、草稿保存和版本固定契约保持。历史以实际保存的题目为准，不把后来配额设置套回旧轮。
