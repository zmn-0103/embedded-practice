- 支持安装多个本地 `.ep-theme.json` 主题包，先预览，再确认安装和保存应用；支持版本更新、卸载与恢复默认外观。
- 保留松间绿、晴空蓝、暖沙金、暮山紫，新增非官方Claude风格学习工作区；支持浅色、深色、跟随系统及15～22px字号。
- Claude工作区支持折叠导航和隐藏辅助信息；切换主题保留原题库筛选、当前练习、队列、草稿和学习记录。
- 完整备份纳入已安装主题和外观偏好。严格限制主题配置，不执行CSS、脚本或远程素材。
- 提供“纸页墨色”“电路夜航”两个完整可安装示例，位于新交付目录的“主题示例”。安装示例是用户操作，不自动改变现有外观。

使用与格式见[多主题系统说明](多主题系统行为与格式.md)，原始完整计划见[主题开发计划](多主题系统开发计划.md)。
