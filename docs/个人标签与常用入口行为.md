# 个人标签与常用入口

2026-10-28，分支 `codex/functional-ux-next-20261028`。用户确认本批仅做“个人标签＋方案／题单置顶和最近使用”；其他候选仍待另行开发。沿用工作台、现有主题、受限桥接和原练习确认流程。

## 个人标签

- 在题库“个人标签”管理区创建、改名和删除。名称去首尾空白，1～60字符，拒绝控制符，按 SQLite ASCII NOCASE 唯一；最多100个。Markdown题库标签与个人标签分别保存、分别筛选，允许同名。
- 先在题库明确勾选，再为全部勾选批量添加或移除一个个人标签。作用数量包含其他专题、分页和筛选中的既有勾选；最多500题，不作用于未勾选的搜索结果。重复添加或移除是幂等操作。任一题目失效或写失败整批回滚，原勾选保留。
- 关联使用题目内部稳定身份，对应 `topic_id + question_id`，与题目版本分离。重导入及归档不覆盖个人标签，归档项保留关联；不修改Markdown、个人笔记、收藏或历史作答。
- 标签改名沿同一身份，核对原名称，过期编辑拒绝。删除需要明确确认并核对原名称，仅删除标签及其成员关联；题目、笔记与练习记录保留。
- 题库与练习均可按一个个人标签筛选，与原专题、分类、题库标签、难度、自评、收藏条件取交集；列表、匹配数和建轮使用同一谓词。不限个人标签时兼容旧条件。
- 动态方案保存个人标签身份，改名后条件继续有效。标签删除后旧方案保留原条件，显示失效并禁止填入；原匹配结果为0，不静默清成不限。用户可重新选择条件后更新或另存。
- 管理区使用现有分类管理的有界浮层，收起后继续勾选/阅读。变更前先保存笔记，等待写入及刷新期间笔记只读；保存失败不发送标签变更并保留输入。结果未知按捕获的原操作重试，或明确停止重试后核对。
- 新一轮独立作答期间仍隐藏参考答案和个人笔记；本批不增加个人标签正文搜索或任何答案/笔记提前读取入口。

## 方案与题单的常用入口

- 方案和题单分别支持置顶、取消置顶。列表先置顶，同组按最近成功开始练习的时间降序，再按名称与身份稳定排序。未使用项的时间为NULL。
- 方案显示范围、当前实际匹配题数及最近开始时间；固定题单显示保存题数和最近开始时间。题单仍保存有序题目身份，方案仍保存条件。
- 填入方案、载入题单、改名、更新、置顶和导出不记使用。只有成功创建新练习轮次才更新时间；继续原轮、结果页再练、失败或空匹配不记一次新的使用。
- 方案来源由明确填入时的ID传递；事务内核对实际条件仍等于保存定义。用户改动条件后开始，不把改后的练习归为原方案最近使用。单纯改名或置顶不改变条件身份。
- 题单来源由明确载入且勾选保持原有序成员时传递。确认页移除成员、或保存定义已变化，则不把较小/不同集合计为原题单使用。建轮仍按预览的当前有效版本复核，归档/失效不补题。
- 使用时间与建轮、旧活动轮替换、固定队列及回执写在同一事务。任一步失败全部回滚，原活动轮保留。原请求重试读取原回执，不再次建轮或更新时间。
- 从练习返回题库后刷新题单最近时间与排序；不清除原临时勾选或重置已有筛选。

结构1～13先创建并校验一致性保护备份，再事务升级。结构13只增加本批两表与四列，旧笔记、题目、版本、记录、方案、题单及自定义对象保持；备份受阻或未知同名对象导致停止/回滚，不重建空库。旧版本程序不能打开结构14，不使用原个人库做迁移测试。旧版没有记录方案/题单的使用时间，升级后的最近使用从本版开始记录，不从旧轮推算历史使用时间。

完整备份恢复包含标签、关联、置顶和最近使用；预览检查必要列、名称/身份/容量、重复与孤儿关联、置顶值和时间格式。失效方案标签引用允许保留，不能自动放大范围。源备份只读，旧备份仅在暂存副本迁移。
