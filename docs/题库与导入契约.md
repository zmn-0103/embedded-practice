# 题库与导入契约

本页维护当前有效的题库、导入和版本规则。需求基线见[计划书](../计划书.md)，具体格式见[Markdown V1题库格式](MarkdownV1题库格式.md)；实际进展与结果分别见[开发记录](开发记录.md)和[验收记录](验收记录.md)。原日期增补保留在[历史记录](history/契约增补与模块演进.md#题库与导入原始增补)。

## 身份、完整快照与格式

- 题目稳定身份是 `topic_id + question_id`。文件改名、标题或答案修改不改变身份；不使用内容哈希代替稳定 ID。
- 每个专题文件是该专题的完整快照；同批重复专题 ID 必须拒绝，未参与导入的专题不受影响。
- 按 Markdown 语法树识别题目和答案分区并保留原始正文，禁止只用正则按 `##` 切分。兼容 UTF-8 BOM、Windows 和 Unix 换行。
- 严格校验计划书第四章规定的字段、标题层级、唯一 ID、非空分区、难度、图片和大小上限；错误包含文件名、行号与原因，不静默截断。

## 预览、提交与内容版本

- 导入必须先预览后确认；确认提交预览时已暂存且校验的快照，不无提示重读可能已变化的源文件。
- 题目、版本和图片在同一批次事务中提交，失败不得留下半批数据；重复导入相同内容应保持幂等。
- 内容版本与收藏、草稿、自评和历史分开存储；缺题归档，恢复相同 ID 时保留历史，不永久删除题目或记录。
- 题干、答案或引用图片变化时标记“内容更新待复习”；仅标签或显示顺序变化不触发该标记。最新掌握状态只采用对应最新内容版本的自评。
- 标题、难度、标签、顺序和专题名称属于元数据，修改不新建内容版本；原有未消除的更新标记继续保留。导入不替换旧轮已固定的题目、答案、标题或属性快照。

## 图片与来源文件

- 图片只支持 PNG、JPEG、WebP，必须来自该 Markdown 文件旁的 `assets` 目录；校验规范化后的实际访问路径，防止逃逸到目录外。
- 禁止导入远程图片、绝对图片路径、SVG、原始 HTML 和脚本；缺图或不支持的图片引用必须报错。
- 图片内容复制入库并按哈希去重，历史版本仍引用的图片不得提前清理；导入后不能依赖原始文件路径，也不能修改来源文件。

## 内容差异的只读边界

[内容差异](内容更新差异与集中复习行为.md)读取题库已保存的版本与图片，不回读来源文件。只允许同一道题中更早版本与当前详情目标版本对照；目标已变化则提示刷新。版本元数据不含正文，答案分区需明确查看。查看差异不触发揭晓、自评或“已复习”，不改笔记和旧轮快照。

## 个人资料与知识关联

- 个人标签与 Markdown 题库标签分别保存，按稳定题目身份关联；重导入、版本变化和归档均保留个人关联。标签整理不修改 Markdown、内容版本或原导入预览，详见[个人标签与常用入口](个人标签与常用入口行为.md)。
- 人工知识关联两端按稳定题目身份保存；当前题干版本、元数据、归档或恢复不覆盖说明、方向和修订。检索使用已入库当前题干及个人资料，不回读 Markdown 或网络；关联、搜索与对照不触发揭晓、自评或内容更新已复习。
- 归档项继续可整理、检索；组卷仍须通过当前有效版本预览，失效不补题。详见[积累检索与知识关联](积累检索与知识关联行为.md)。
