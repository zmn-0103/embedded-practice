《嵌入式刷题本 UI 布局改版计划书——方案 E：学习工作台》

> 文档类型：阶段历史。本文保留该批次的原始需求、设计或验收范围；其中“当前”“未实现”和版本号仅指当时，不覆盖[现行文档索引](README.md#当前业务规则)与[当前交付](当前试用版本交付说明.md)。原始失败和待验结论保持。


**一、目标与实施边界**

以当前嵌入式刷题本 V0.0.1 为基础，整合已有四种 UI 方案的优点，形成统一、清晰、适合长时间阅读和自主练习的桌面布局。

本次设计的主要目标：

1. 打开程序后，能够快速继续上次练习或选择新的练习范围。
2. 题库内容较多时，能够通过板块、专题、搜索和筛选快速定位。
3. 练习时能够清楚区分题干、自己的答案、参考答案和自评操作。
4. 导入、分类、主题和备份等管理功能保持完整、易找、可理解。
5. 深色、浅色、字号调整和窄窗口使用同一套交互规则。
6. 改版后保留现有题库、稳定编号、草稿、收藏、自评、历史、练习队列、分类、方案和主题配置。

本计划为设计与后续实施依据。本次只交付参考图与计划，不表示已完成应用改版，也不授权自动覆盖个人程序或正式数据库。

软件继续保持 Windows、个人使用、离线运行、Markdown 在程序外维护的定位。不增加自动判分、AI 追问、代码执行、间隔重复、账号、云同步、在线题库市场或程序内题目编辑。

软件主图标暂不重新设计。参考图中的角标与图标仅表示位置，落地时继续使用现有应用图标，并统一功能图标。

**二、总体布局与导航**

采用“左侧固定导航＋顶部轻工具栏＋任务主区域”。

左侧一级入口按以下顺序排列：

- 学习总览。
- 知识板块。
- 开始练习。
- 题库。
- 学习记录。
- 设置与数据。

其中，“学习总览”为本次提出的新页面；其余入口承接现有功能，不另建重复业务系统。

顶部显示当前页面位置、必要的范围搜索与外观入口。顶部不再重复放一整套一级导航。

搜索行为必须明确：

- 题库页搜索标题、题干和标签，不搜索后直接展示答案片段。
- 知识板块页提供板块与专题检索。
- 其他页面如果保留顶部题目搜索，执行后进入题库并显示搜索范围；不得形成第二套搜索结果。
- 活动练习中不提供可绕过保存流程的跨页搜索。
- 键盘快捷键如后续增加，先确认不与中文输入、现有操作及系统快捷键冲突。

练习中保留明确的“保存并返回”。其他页面入口不得绕过保存守卫。导航折叠只改变显示，不重建练习状态。

全局的新布局能力需要修改应用界面并重新交付程序，不能仅靠现有主题 JSON 实现。保留现有主题格式，不为了这次设计开放任意 CSS、脚本或自由面板结构。

**三、统一视觉规范**

参考图默认采用浅色蓝色工作台风格：

- 页面底色：#F5F7FB。
- 内容卡片：#FFFFFF。
- 主要文字：#17243A。
- 主操作色：#2764E7。
- 辅助强调色：#14A89A。
- 分隔线：#DFE6F0。

以上作为设计起点，实际应用映射到现有主题变量。原有松间绿、晴空蓝、暖沙金、暮山紫、Claude 风格与外部主题继续可用，不强制将用户切换到蓝色。

间距采用 4、8、12、16、24、32px 的统一尺度；卡片圆角建议 12px，普通控件 8px。减少无意义的卡片套卡片和大面积装饰。

正文默认 17px，继续支持 15～22px。代码采用本地等宽字体，正文采用本地中文字体回退，不下载在线字体。

功能图标建议使用统一的 20px 规格和一致线宽。图中同类功能出现不同小图标时，实施阶段统一为一个固定图标。引入第三方图标时保留许可，并优先复用现有资源。

状态必须同时使用文字和视觉提示：

- 不会：红色语义。
- 不熟：琥珀色语义。
- 掌握：青绿色语义。
- 保存失败：错误提示＋重试操作。
- 内容更新待复习：独立提示，不等同于不会。
- 题目难度与个人自评使用不同字段、标签和说明。

主题切换、加载完成和保存状态变化尽量不造成正文跳动。

**四、各页面与功能设计**

**4.1 学习总览——参考图 01**

首页首先显示活动练习。

存在活动练习时，展示专题、当前位置、本轮模式、已揭晓数、已自评数以及“继续本轮”。当前位置与完成数量分别表达，不把“第 8 题”写成“已完成 8 题”。

没有活动练习时，主卡片改为“开始新练习”，进入配置页面。

统计区域仅使用现有可解释数据：范围内有效题目、已揭晓、已自评、收藏等。不得把主观自评包装成系统正确率。

板块入口与“不会”“不熟”“内容更新待复习”快捷入口只导航或填入筛选条件，不自动启动练习。

不增加每日目标、连续打卡、学习时长、到期日历和任务清单。

**4.2 知识板块——参考图 02**

保留全部题库、未分类、本机自定义分类和现有规划板块。

基础板块共 15 个：

C语言、C++语言、数据结构与算法、处理器与ARM架构、MCU与外设原理、MCU平台与SDK、通信协议、计算机网络、RTOS与并发、Linux系统与应用、Linux内核与驱动、硬件与电路基础、存储与文件系统、编译调试与工程实践、项目与面试表达。

拓展板块共 7 个：

无线与物联网、安全与可靠性、信号处理与多媒体、控制与电力电子、汽车电子、机器人与无人机、FPGA与数字设计。

所有数量和导入状态读取本机数据。参考图显示“已导入”不代表当前本机实际存在对应题库。

有题板块进入对应题库范围；无题板块允许查看规划和导入入口，不创建空练习。规划板块不自动写成分类，不自动移动已有专题。

具体芯片相关内容进入对应平台专题；通用协议、语言和原理内容保留通用归属。

**4.3 题库检索——参考图 03**

宽窗口采用三部分：

- 左侧：分类与专题导航。
- 中间：搜索、筛选、题目列表与分页。
- 右侧：选中题目的详情。

筛选保留专题、标签、难度、自评、收藏、内容更新待复习及有效／归档范围等现有能力。具体组合语义沿用当前契约。

列表主要展示标题、难度、自评、收藏及必要状态。题目身份沿用现有稳定 ID，不因排序或布局改变。

详情首先显示题干与属性；参考答案与单题历史由用户主动展开。题库浏览不计作练习揭晓或自评。

“导入题库”“分类管理”保持清晰可达，即使某张示意图未完整显示工具栏，也不能在实现时遗漏。

切换详情和返回列表保留当前筛选、页码与选中位置。

**4.4 开始练习与方案——参考图 04**

左侧配置本轮条件，右侧展示已保存方案。

保留顺序／随机和 10、20、50、全部的题数选项。匹配不足时使用实际匹配题目；无结果时禁用开始操作，并提供清空或调整条件的入口。

随机队列在创建本轮时固定。固定队列是业务规则，不提供关闭开关。

已有活动练习时：

- “继续本轮”读取原固定队列与内容版本。
- “结束本轮并开始新练习”沿用现有明确操作与保存保护。
- 旧练习记录保留。

方案支持保存、填入条件、删除。方案名去首尾空白后为 1～60 字符，遵守现有唯一性规则与数量上限。

选用方案只填入条件，不立即开始。分类或专题失效时明确提示，不静默扩大为全部题目。自评与难度筛选保持现有单项选择语义，不从示例图扩展为联合状态。

本次不增加方案编辑、自动执行、定时复习或同名覆盖。

**4.5 练习未揭晓——参考图 05**

宽窗口左侧为题干和“我的答案”，右侧为参考答案占位区域。

未揭晓时：

- 答案正文、答案摘要和历史作答不得进入正文或无障碍阅读树。
- 不展示可用自评按钮。
- 允许空输入揭晓。
- 不要求输入达到字数或选择选项。
- 题目中的提示只来自原始题干；不自动生成新的“思考方向”。

输入区可收起。收藏与自评相互独立。

保存状态显示保存中、已保存或保存失败。保留现有停止输入 500ms 后保存，以及切题、揭晓、返回和正常退出前提交待保存内容的规则。

保存失败时保留输入，阻止依赖该次保存的推进或离开操作，提供重试，不显示虚假的已保存。

**4.6 揭晓与自评——参考图 06**

揭晓后右侧展示原始 Markdown 参考内容，支持文字、代码、表格、本地图片和资料链接。

不要求每道题都包含“回答要点、常见错误、代码示例”等固定分区；只有题库原文包含时才显示，不拆造新的内容字段。

代码支持高亮、局部横向滚动和复制。图片支持放大查看，资料链接仅在用户点击后交给系统浏览器。

自评按钮为“不会”“不熟”“掌握”，另有“暂不评价，下一题”。

自评保存成功后再进入下一题。保存与推进保持原有事务语义，重复点击或重试不得重复累计。

单题历史主动展开；新一轮不自动显示上次作答或沿用揭晓状态。

**4.7 学习记录与收藏——参考图 07**

上方为所选分类、专题和有效／归档范围的统计。下方为题目列表、收藏筛选和单题历史。

统计保留已揭晓、已自评、各自评数量、收藏、内容更新待复习等独立含义，按题目身份和当前内容版本去重。

图表只表达已有自评分布，不生成正确率、知识点掌握推断或学习时长。

下方筛选不改变上方范围统计时，必须保留清晰说明。

单题历史展示当时内容版本、作答与自评；旧版本记录保留。收藏筛选开启时，列表只能显示当前符合收藏条件的题目，取消收藏后按现有刷新规则更新。

“不会”和“不熟”可以作为复习筛选入口，不另建一套自动判错的错题数据库。

**4.8 导入与归档——参考图 08**

导入流程保持：

选择文件 → 校验与变更预览 → 确认导入 → 展示结果。

预览区分别显示新增、内容更新、信息变更、不变、将归档和恢复数量。

明确说明每个文件是对应专题的完整快照，遗漏题目可能归档。用户确认前不写入最终题库。

校验失败展示可定位的文件、题目或错误位置，保留重新选择入口。失败结果与成功结果分别展示，不同时作为当前状态出现。

归档题继续可查看历史与收藏，不进入新练习。恢复沿用重新导入包含该题的完整专题文件的流程，不新增缺少业务支持的单题恢复或删除按钮。

**4.9 分类与专题管理——参考图 09**

分类采用“分类／板块 → 专题”两层结构，每个专题最多归属一个分类。

支持新建、重命名、移除分类和调整专题归属。不新增任意层级的文件夹系统。

移除分类时明确说明：专题进入未分类，题目、草稿、收藏和学习记录保留；确认框默认取消。

分类调整不得复制题目、改变稳定编号或重建已有练习队列。

**4.10 外观与本地主题——参考图 10**

保留五套内置主题、已安装外部主题、明暗模式、15～22px 字号及现有受控布局偏好。

设置页分为主题选择和局部预览。预览不影响正在使用的主界面；点击“保存并应用”后生效。

保留本地主题安装、版本更新、卸载和恢复默认外观：

- 安装不自动应用。
- 内置主题不可卸载。
- 外部主题安装后完整配置保存在数据库中。
- 删除原下载文件不应导致已安装主题失效。
- 卸载当前主题时按现有事务规则切回默认主题。
- 保存失败保留原外观和待应用选择。
- 主题切换保留草稿、队列、筛选、分页与选中项。

预览区域的按钮、错误条等可以作为组件样式样本，但不能据此改变真实练习状态机。不得出现自动判断答案正确与否的提示。

**4.11 备份、恢复与数据位置——参考图 11**

设置与数据中保留外观主题、备份恢复、数据位置三个清晰分区。

完整备份包含题库、图片、学习记录、分类、方案、主题及相关设置，只备份已保存内容。

恢复必须经过预览和明确确认，显示备份摘要、结构兼容信息与覆盖范围。

恢复前先保存待保存内容，再创建保护性备份；保护失败则停止恢复。恢复成功后按原流程重启，失败按现有机制回退或提示核对。

数据位置为只读信息，可提供现有的打开目录、打开日志和复制路径能力。不因视觉改版新增任意迁移数据目录的功能。

参考图中的路径为示例，实际必须显示当前运行程序真实的数据位置。

**五、深浅主题、窄窗口与内容适配**

参考图 12 展示布局方向，实施时按实际可用内容宽度调整：

- 宽度充足：题库可显示分类、列表、详情；练习可显示题目与参考内容双栏。
- 中等宽度：优先压缩或折叠导航，减少辅助信息占用。
- 窄窗口：练习按题目、我的答案、揭晓入口、参考答案、自评的顺序单列展示；题库详情采用可返回的单独阅读区域或抽屉。

断点建议以 1440、1200、900px 等代表性窗口验证后确定，不照搬图片比例作为最终实现值。

正文不产生整页横向滚动；长代码和宽表格在自己的容器内滚动。图片不撑破窗口。

操作区必须可达，不能覆盖输入首行、最后一行、图片或正文。优先使用文档流；确需吸底时预留对应空间并验证键盘焦点可见。

导航收起、窗口缩放、字号变化和主题切换不得丢失输入或重置活动会话。

**六、空状态、异常与反馈——参考图 13**

必须覆盖以下状态：

1. 首次空库：导入题库、导出模板；不自动混入测试样例。
2. 筛选无结果：显示当前条件，可清空或调整；不创建空会话。
3. 数据加载中：显示局部加载状态，不把上次范围数据冒充当前结果。
4. 读取失败：显示原因及重试，不伪装成零题或空记录。
5. 保存中、已保存、保存失败：同一时刻清晰表达当前真实状态。
6. 本轮结束：展示实际本轮结果，不把提前结束写成已完成全部题目。
7. 图片查看：放大、缩小、适应窗口、拖拽、关闭和焦点返回。
8. 主题不可用：使用现有临时回退规则，保留原选择并提示检查。
9. 导入校验失败、方案失效、恢复保护失败：保持用户可理解的下一步。
10. 操作结果暂未确认：沿用原请求重试，不通过生成新身份重复创建记录。

错误信息就近出现；关键错误不能只依赖短暂消失的提示条。

**七、实施顺序**

第一批：统一界面规范与导航框架。

确定间距、字号、颜色变量、控件状态和功能图标；保留现有主题能力。完成六个入口及轻工具栏，验证导航与练习保存守卫。

第二批：学习总览、知识板块与题库。

复用现有查询和统计能力完成总览；调整板块卡片、分类导航、筛选栏、题目列表和详情。保证全部原有入口可达。

第三批：练习配置与练习工作区。

完成方案区域和双栏布局，重点验证未揭晓答案隔离、输入保存、揭晓、自评、跳过、返回、旧轮继续及窄窗顺序。

第四批：学习记录与管理页面。

完成统计、收藏、历史、导入、归档、分类和主题管理的统一布局；保持原有业务语义。

第五批：备份恢复、异常与桌面交付检查。

完成数据管理页面与关键异常状态；检查长文本、长代码、大图、深浅主题、字号、窗口大小及实际目标程序。

每批只完成当前授权范围。逐文件修改，每个代码文件完成后先做 Bug 检查，再做可维护性检查，按现有规则记录。不要一次性重写全部界面或趁机改造数据库层。

**八、验收条件**

视觉与导航：

- 所有主要功能均有明确入口。
- 页面间保持统一的字体、间距、按钮与状态表达。
- 不同页面按任务采用适当密度。
- 新增总览不产生与原页面冲突的第二套业务状态。
- 窄窗口和最大字号下，正文、操作区与焦点可达。

练习与数据：
