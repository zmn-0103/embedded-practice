# 题库分类与标签规范

本页维护题库内容的组织规则。当前题库及逐专题数量只在[题库入口](../question-banks/releases/v003-20261030/README.md)维护；旧GPIO/UART与小样统计已迁入[实施记录](history/专项功能实施记录.md#题库分类与标签规范)。程序内分类行为见[分类树契约](分类树行为与验收.md#本批契约)。

## 板块、专题与题目身份

板块用于宽范围浏览，专题是完整Markdown快照，标签提供跨专题的知识点入口。采用板块→专题两层，不为目录层级复制题目。稳定身份是 `topic_id + question_id`，不由板块、标题、标签、文件名或路径决定。

板块规划允许包含零题方向和待建设专题，但不生成占位题或空Markdown导入文件。规划见[规划清单](../question-banks/catalog/板块规划.json)，个人库的实际分类与题数由程序读取，不从规划或文件夹推断。

新专题首次导入默认未分类；重导入已有专题保留归属。移动分类或改显示名不重新生成题号、不改变题目内容、不重抽已建轮队列。拆分专题或迁移题目身份需要明确的内容迁移方案。

## 标签词汇与使用方式

标签使用短、完整、可理解的词语，同一概念保持同一写法与缩写大小写。Markdown中用半角逗号分隔；选择一个完整标签筛选，与分类、专题、难度、自评、收藏及个人标签等条件取交集。候选片段检索不代表多标签联合匹配。

可按知识主题、具体芯片/器件、知识点和任务形式选择必要标签。通用原理题不添加无关芯片标签；芯片相关题在题干明确型号和必要前提。当前题库以库无关概念、机制与轻量分析为主，不把HAL/SPL函数或初始化结构体名称当成必背考点。

“第二层”“试用选集”等来源状态放在专题说明和来源记录中；收藏、不会、不熟、掌握、待审阅等个人或审阅状态不混入知识标签。个人标签独立保存，规则见[个人标签与常用入口](个人标签与常用入口行为.md)。

具体标签、筛选命中数以当前完整专题和程序实时查询为准，不把旧试用题量或历史标签数量硬编码到程序或使用说明。

## 板块入口与本机分类

规划的显示名称与程序创建分类的本机ID分离。规划不会自动修改个人分类；同名规划和真实分类如何合并显示见[板块入口](板块入口行为与验收.md)。文件夹也不会自动建立分类。

## 难度、来源与审阅

难度按任务复杂度设置：基础为单概念或直接推导，进阶为多条件、计算或时序，综合为故障定位与设计取舍。Markdown写基础、进阶、综合；界面可显示易、中、难；不重复添加一套难度标签。旧题未分级不自动评为基础。

个人掌握程度由自评独立表示，不改变题目难度。技术资料、格式校验和自动化运行均不代替用户逐题技术审阅；来源和适用芯片条件按题库说明维护，不编造个人经历或硬件结果。

## 维护顺序与后续边界

先核对稳定身份和来源，再调整分类或标签。只改标题、标签、顺序等元数据不应触发内容更新；更正题干、答案或图片时按[导入契约](题库与导入契约.md)生成内容版本，历史练习仍引用原快照。每份导入文件必须是该专题的完整快照，不用局部几题覆盖完整专题。

用户原始学习资料不作为程序内可编辑题库；仓库维护和实际导入分开执行。数据保护及任何清空操作遵守明确授权与[数据保护契约](数据保护与桌面边界.md)。
