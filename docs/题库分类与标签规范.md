## 板块、专题与题目身份

这是仓库文件的对应关系，含原GPIO/UART共108题及新增10道通用小样，不代表个人数据库已导入或用户已审阅。模板、格式示例和生成压力题不计入真实内容。允许先规划C语言、RTOS等空板块及待建设专题名；不生成占位题或空Markdown导入文件。旧GPIO标签尚未按本规范逐题统一，不能把本批写成全部题库已整理完成。

移动分类或改显示名只调整分类关系；不能重新生成题号、改已有专题ID或复制同题冒充新题。若确需拆分专题，应另定身份迁移与历史关联方案。导入仍是每个专题的完整快照，不能用“只选其中几题的文件”覆盖该专题。

## 标签词汇与使用方式

标签保持短、可理解的完整词；同一概念使用同一写法，英文缩写采用约定大小写。使用半角逗号分隔，程序仍按一个完整标签精确筛选；候选中的片段检索不等于标签支持模糊或多个标签联合匹配。

UART 当前使用26种标签：

| 维度 | 规范词 |
| --- | --- |
| 芯片系列、协议 | STM32F103、UART |
| 语言 | C语言 |
| 知识点或操作 | 状态标志、发送、接收、标准外设库、并发与原子性、中断、初始化、DMA、寄存器、地址计算、波特率、帧格式、位运算、GPIO、错误处理、时序 |
| 题型或任务 | 判断题、计算题、读寄存器、概念题、流程题、综合题、故障排查 |

STM32专题每题包含芯片系列与协议，再选相关知识点和任务标签；下方通用小样采用独立约定，不添加芯片标签。只有依赖具体封装/板卡接线的内容才另加更细的芯片或板卡词，并在题目条件中说明。此处的“UART”是知识主题名，具体硬件按题目指定的 STM32F103 USART1 理解；函数标签“标准外设库”不代表 HAL 接口行为。

“第二层”“试用选集”属于来源与交付状态，保留在专题名、来源清单和说明中，不再充当30题相同的检索标签。收藏、不会、不熟、掌握、待审阅属于个人状态或审阅状态，不混入知识标签。

| 找题目的 | 当前可用入口 | UART 本批预期 |
| --- | --- | ---: |
| 练波特率 | UART专题 + 完整标签“波特率” | 4题 |
| 做波特率计算 | UART专题 + 波特率 + 难度进阶 | 2题：029、041 |
| 排查串口问题 | UART专题 + 故障排查 | 6题：043～048 |
| 看中断链路 | UART专题 + 中断 | 2题：026、046 |
| 看基础题 | UART专题 + 难度基础 | 16题 |

上述数量以本批文件为准，已通过生产接口逐项核对26种标签和3档难度，并实际操作“波特率 + 进阶”筛选。未来混入其他题库或更改标签后应重新计算，不能把这些数量硬编码到应用。

## 难度、来源与审阅

当前界面以“易（基础）／中（进阶）／难（综合）”显示原三档，未分级保持独立。筛选与方案继续使用原值，Markdown写法不变，不另加一套易中难知识标签。未分级旧题需要独立内容整理，不能因入口上线而宣称已逐题评级。

基础用于直接辨认概念、函数职责、位状态或简单掩码；进阶用于公式计算、多位字段修改、标志副作用或特定异常分析；综合用于同时连接时钟、引脚、帧格式、中断等多个模块。UART 本批为16基础、10进阶、4综合。这是内容整理时的任务复杂度，不是考试等级、正确率或用户掌握程度。

当前元数据集中记录于[UART题目整理清单](../question-banks/trials/UART题目整理清单.json)，导入文件与清单应同步维护。原始笔记位置、原题号和题答哈希继续以[原始来源映射](../question-banks/trials/题答来源.json)为准；其中旧标题是整理来源时的历史标题，不应改写成当前标题。

技术依据、AI核对范围和待修订项见[UART来源与技术核对](UART30题来源与技术核对.md)；人工结论填写[用户审阅与试用表](M5题目审阅与试用反馈.md)。目前30题均待用户审阅。程序格式检查、哈希相同、AI查阅资料和测试中输入自评，分别只证明对应事实。

## 2026-10-24 通用基础小样约定

通用板块使用“嵌入式通用基础”，下含GPIO、UART、SPI、I2C、ADC五个专题，各2题；是新的考查范围与题答，采用新身份，不把旧STM32题改名覆盖。每题含主题标签，再按考点或任务增加电气接口、时序分析、缓冲区、消息边界、故障排查等标签；不把“待审阅”或“试用”当知识标签，也不要求包含芯片型号。

本批每专题1基础/1进阶，共5基础/5进阶。难度为初始任务复杂度，技术审阅和实际体验另行记录。词汇与身份以[可导入文件](../question-banks/general/README.md)及[样题映射](../question-banks/sources/general/样题来源映射.json)为准，来源与433题筛选见[来源入口](../question-banks/sources/general/README.md)；用户审阅和运行结果见[试用表](通用基础样题与试用.md)。

文件夹不自动建立应用内分类；用户可以创建该板块并将五专题归入。试用小样反馈后再考虑约30题，后续保持完整专题快照与既有新ID；原GPIO78题元数据整理暂不在本批进行。

## 维护顺序与后续边界

维护前备份原文件。先核对稳定ID与来源，再修改元数据；预览应显示信息变更且内容更新为0。若更正题干、答案或图片，则属于真实内容更新，应在独立批次列出差异、资料版本和原因，允许生成新内容版本，保持旧轮和历史仍引用原版本。

分类树本机持久化、每专题单归属/未分类、改名/移除后保留专题、范围交集、按题去重、导入保持归属与原轮分类快照已实现，详见[使用方法](使用说明.md)。例如可在程序中手动创建“STM32”，再把已导入的GPIO和UART专题归入其中；此操作由用户明确选择，仓库108题对应表不代表个人库已经导入或分类。保存练习方案、个人笔记、学习路线与多标签联合筛选仍在本批之外。
