# M2 第三批：长内容切题与异常退出验证

日期：2026-10-20。接续 M2 交互缺陷修复，本批仍在核心顺序练习范围内，不推进 M3。原计划书保持，数据库结构仍为 3，不增加依赖或新的桌面能力。

## 本批目标与输入输出

1. 长题干、长答案下切换题目后，先展示新题题首与进度，并将键盘焦点放到题目标题；上一题和完成/结束结果遵循相同阅读入口。揭晓、草稿保存和图片预览等同题更新不抢滚动位置或焦点。
2. 真实终止本次测试启动的应用进程后，独立进程继续同一队列，恢复已经确认保存的草稿、揭晓、自评和位置。不承诺恢复 500ms 内尚未提交的输入；本批不把强制结束当作正常退出或断电测量。

## 允许修改与失败表现

- 生产改动限定在练习展示组件；复用原保存控制器、预加载、IPC、服务与事务。
- 新增/补充真实 Electron 场景，使用明确标识的生成长题和独立临时数据库；所有终止和写入只作用于本场景创建的进程/目录。
- 切题先按原契约保存；失败保持输入和当前位置，不能提前滚到另一题。标题聚焦只由题目或结果变化触发，不因输入、保存、自评按钮保护或揭晓抢焦点。
- 退出恢复以实际 SQLite 与独立进程页面结果为据，保留未提交尾部与已确认草稿的区别。

## 验收条件

1. 未修源码先运行新增长内容场景，保存问题复现结果；不能只根据代码缺少滚动处理就认定已复现。
2. 真实 Electron 渲染缩放 100%/125%/150% 下，长内容自评推进、返回上一题及末题完成能看见题首/结果标题，键盘焦点匹配当前内容；这是 Electron 页面缩放测试，不替代 Windows 系统 DPI 验收。
3. 同题自动保存保持用户阅读位置和输入焦点；既有图片自动保存、防重复激活及写入失败回归保持。
4. 显式确认草稿保存后，再产生未提交尾部并直接终止该测试进程；重开只恢复已确认内容、队列版本及实际位置/自评，数据库无外键或完整性错误。
5. 单元、类型/格式、完整开发构建与重新生成的 Windows 解包程序分别运行；原 M0 NSIS 不覆盖、不制作新安装包。
6. 每个代码文件先 Bug 检查、再优化复查，实际结果写入验收记录并保留证据；另准备未完成的人工验收清单，不能把自动化或合成输入事件记作真实中文输入法验收。
