## 本次目标与边界

- 首页提供顺序／随机选择，默认顺序，保留 10／20／50／全部数量及现有交集筛选。
- 随机模式从全部匹配题目中随机选取规定数量，不能先截取顺序列表再打乱；本轮稳定身份不重复，不足数量时使用全部匹配题目。
- 实际队列、内容版本和模式一次性保存。继续、切题、重开及导入更新均读取原队列，不再次随机选题。新轮重新选题，但允许不同轮出现相同题目或相同顺序。
- 保留开始请求幂等与结果未知时的原请求重试；无匹配、写入失败或过期替换请求不得结束原轮或留下部分新轮。
- 随机轮同样遵守答案隐藏、500ms 保存、揭晓／自评／切题事务、重复激活保护和正常退出握手。
- 单题历史、更新待复习展示、主题／字号和完整备份恢复不属于本批；不将本批视为 M3 全部完成。

## 数据与兼容

当前结构 3 的会话表只接受顺序模式。本批将结构升级至 4，允许两种模式。v1／v2／v3 升级前都须完成 SQLite 一致性备份并校验，失败停止；v3 只替换会话表约束，逐字段保留旧会话、队列、作答、收藏、版本和幂等回执，外键检查失败则回滚。重开不重复迁移。旧程序不支持结构 4，应使用本批重新生成的整个解包目录。

请求的 mode 可以省略，旧输入保持原 JSON 形状与回执哈希，按顺序模式执行；非法模式在主进程拒绝。响应明确给出实际模式，不由首页选择反推活动轮。

迁移表约束按 [SQLite 官方表结构修改流程](https://www3.sqlite.org/lang_altertable.html)处理：在事务外暂时关闭本连接外键执行，事务内建新表、复制、替换、重建索引及检查外键，结束后恢复外键执行；不使用 writable_schema 修改数据库内部元数据。
