## 选题、答案与本轮状态

首页默认 20 题，可选专题和 10/20/50/全部。无题不能建立空轮；有活动轮时可继续，或点击明确的“结束本轮并开始新练习”。新轮请求以 UUID 和原活动游标保护重复提交；确认建轮后单独读取当前视图，读取失败只重读。结果未明时保留原请求供重试，暂时锁定筛选条件。

进入练习时卸载题库浏览与导入正文，避免题库中已展开的答案留在练习页面。未揭晓题的服务视图没有答案字段，组件也只在 `revealed` 为真时挂载答案区域；不通过 CSS 隐藏答案。首次进入未揭晓题没有自评按钮，允许空输入直接揭晓。上一题保留本轮状态，新轮输入/揭晓/自评重新开始。

自评、暂不评价、跳过和结束复用原事务。完成页分别显示揭晓、自评及三档数量、揭晓未评价和仍未揭晓的跳过数，不计算正确率。返回首页保持活动轮；明确结束或末题推进后保留记录并显示摘要，历史查询页面尚未实现。

题目标题与结果标题可接收程序焦点，但不额外进入 Tab 顺序。会话 ID、位置或状态变化后，在布局阶段回到页面顶部并聚焦标题；长题干/长答案的推进和上一题不会停留在旧题的滚动深处，完成/结束页也有明确入口。Effect 不依赖草稿、保存状态、揭晓或忙碌保护，避免同题编辑/保存和失败时抢滚动位置或输入焦点；请求提交和视图读取成功后才发生实际切题。

输入框通过 Tab 等方式获得焦点时，浏览器的默认滚动只考虑视口，可能把输入文字留在底部 sticky 操作区后面。PracticePane 在 onFocus 中按实际边框、内边距、行高与操作区顶部判断遮挡，必要时将输入框顶部滚入可见区域；已可读的位置不主动移动，草稿/保存更新不触发。浏览器在 Shift+Tab 返回其他元素时仍可正常滚动，不承诺跨不同焦点位置坐标不变。

## 自动保存与重试

每次输入递增草稿修订并重置 500ms 计时；后台保存过程中允许继续输入。较旧保存确认只更新已确认修订，不覆盖新文本。后续保存等待在途请求结束，避免并发草稿覆盖。未修改的已确认草稿无需重复写入；数据库仍独立检查修订、字节上限与当前会话。

切题、揭晓、自评、结束、返回首页先立即刷新最新输入。此期间同步设置操作锁，阻止在途重入和新输入；保存失败保留文本、显示错误，并阻止后续状态操作。普通后台保存失败可继续修改输入或点击“重试保存”；草稿超限不会截断，可以缩短后重试。

2026-10-20 复查修复：仅有在途锁不能阻止快速完成后第二次点击落到新题。PracticePane 对状态操作立即设置同步门闩，操作按钮在激活后至少保护 500ms；请求未完成时继续沿用原忙碌锁。鼠标多击的后续 click 和 Enter/Space 长按重复 keydown 不触发新操作。短暂保护只影响按钮，不延长输入冻结或改变 500ms 草稿保存；结束保护后可明确逐步操作。计时器在组件卸载时清理，正常关闭仍独立刷新草稿，失败重试仍使用原请求。

状态操作先保存草稿，再携带相同草稿进入业务事务。请求结果未明时保存原 UUID、游标和输入，锁定编辑供“重试原操作”；已收到回执但视图读取失败时，缓存回执并只重读。两种情况都不能重新生成请求而再推进一次。控制器不把题目、答案或草稿写入浏览器本地存储。

## 正常退出

1. 主进程阻止立即关窗/退出；重复请求共用一次协调。页面监听已就绪后，发送本次随机 UUID 的关闭事件。
2. 页面等待首页建轮或当前练习操作结束，设置持续的关闭输入锁，刷新最新草稿；有结果未明操作则返回失败，不能跳过核实。
3. 仅接受匹配 UUID 的保存回执。默认 10 秒超时、错误或失败时，主进程显示“返回窗口 / 放弃未保存内容并退出”，默认和取消均返回窗口。迟到失效回执不能关闭窗口，页面解除关闭输入锁。
4. 确认保存成功，或用户明确选择放弃后，才停用接口、关闭练习连接、取消/等待导入工作线程并关闭其他连接，再退出。

页面尚无输入监听或已经被强制销毁时，退出不能证明未提交内容已保存。强制结束、进程崩溃只保证已确认保存的状态；未发送的按键与 500ms 内尚未提交的输入没有恢复承诺。系统强制关机流程未另行实测。

第三批强制结束测试先核对独立测试库已确认的两题草稿、揭晓/自评和位置，再输入尚未提交尾部，直接终止实际 Electron 主进程。Windows 的 Playwright process() 可能是启动外壳，测试通过主进程读取 PID 和 userData 并核对属于本场景后才终止；等待真实关闭，独立进程继续并逐项核对 SQLite、外键及 quick_check。该场景不是正常关闭、真实断电或系统关机验收。

## 长内容与安全展示

代码使用 lowlight 3.3.0 包装 highlight.js 11.11.2，注册常用语言和 ARM/Thumb 语法（`armasm`/`arm`），支持 C、C++。只将 AST 的文本和 `span` 转为 React 节点，CSS 类名受限；不拼接 HTML。没有语言、不支持的语言、超过 32,768 字符或高亮异常时保留完整纯文本。高亮只辅助阅读，不证明代码能编译。原许可和来源见[许可说明](../licenses/README.md)，并随 ASAR 携带。

复制通过限长具名接口写剪贴板，最多 1,048,576 个字符，保留原始代码文本；失败有提示，不读取系统剪贴板。图片继续使用入库版本 ID/哈希，点击后通过 Portal 打开原生 `dialog`，可按 50% 步进在 100%～300% 放大；Escape/关闭/背景点击可退出并恢复焦点。缩放使用图片宽度属性，未放宽 CSP。小图放大不会生成额外细节。

Markdown 自定义组件映射由 useMemo 按图片绑定与版本维护引用，不随草稿、保存状态或本地提示变化重建组件类型，避免打开的图片对话框与缩放状态在自动保存时丢失。资源绑定/版本变化仍刷新映射；切题仍由现有题目位置/版本 key 卸载旧正文。

底部保存/错误和常用操作使用 sticky 定位，长答案与代码不会把操作推到正文末尾；表格和代码横向滚动。明暗颜色继续跟随系统，主题和字号设置仍属后续阶段。

## 验证边界

控制器时序和 IPC 失败使用单元替身；Electron 窗口回归走 React、预加载、IPC、生产服务和 SQLite，在系统对话框/剪贴板边界与故障注入点使用明确替身，该组不覆盖实际系统剪贴板。提交后响应丢失由测试调用真实服务并主动丢弃一次返回产生，不是断电实测。正常关窗场景等待真实应用关闭事件并独立进程重开；其他场景的强制清理不算正常关闭证据。

第四批另用原生 Windows 输入/无障碍树/窗口捕获，实际验证中文及空格路径的文件选择与取消、Microsoft Pinyin 候选/取消/选词/标点/换行、程序复制到系统剪贴板再粘入答案、Tab 输入可见性，以及正常关闭/独立进程继续和 SQLite 核对；该组未替换文件框或剪贴板。原生关闭前已保存，不扩大为未等 500ms 关窗的证明。开发构建和 Windows 解包 EXE 分别验证，详情见[第四批证据](../evidence/m2d/README.md)。

热更新开发模式、组合输入中揭晓/切题/关闭、多种 Windows DPI、外部编辑器双向剪贴板、系统浏览器、大图与完整人工体验、压力性能、正式题库长期体验和新 NSIS 安装尚未验收。当前顺序练习软件闭环具备对应证据，M3 搜索/收藏/随机/历史与 M4 完整备份恢复未开始。
