## 统计与数据链路

`desktop.learning.read({ topicId, archived })` 只接受明确专题或全部专题、活动或归档范围。预加载严格校验响应，既有题库 IPC 校验可信主 Frame、参数与返回，关闭时移除固定 `learning:read` handler；异常沿用中文错误与校验诊断脱敏，不伪造零结果。接口不返回答案、作答、题干或数据库路径。

现有题库服务组合 `createLearningReader`，使用同一受控 SQLite 连接。范围计数与专题目录在一个只读事务中读取，参数绑定，不改变学习状态或数据库结构。

内层每道题一行，当前版本由 `questions.current_version_id` 关联；真实揭晓通过 `EXISTS` 同时核对题目与版本，避免多轮重复累计。外层分别聚合题数、真实揭晓题数、当前版本自评与三种分布、收藏、更新待复习。空库或无匹配范围返回真实零。最新自评与更新口径复用已有 `currentRatingSql` / `practicedSql`，不建立第二套掌握状态。

自评采用题目当前保存且对应最新内容版本的状态，揭晓仅计算真实练习作答。旧数据只有有效当前自评而无实际作答时，允许自评题数大于真实揭晓题数；不据此补造历史。内容更新后旧版不计入当前统计，元数据保持；归档与恢复只改变题目所处范围，收藏/旧版本记录保留。没有定义或显示系统正确率。

## 页面与范围

`App` 在非练习时提供“练习与题库”“学习记录”。练习控制器始终保持挂载，记录页时只隐藏开始区域；正常关闭仍经过原练习保存握手。导入面板切页仅隐藏，保留预览/原令牌；题库详情在切到记录页时卸载，避免把已展开内容保留到另一页。进入或离开实际练习均回到首页状态，练习期间导航隐藏，不绕开离开前保存。

`LearningRecords` 持有专题/归档范围，读取 Effect 只依赖标量范围、导入刷新和重读序号。清理拒绝旧响应，展示摘要前再核对响应范围，切换后不短暂展示旧范围计数；失败显示错误及重试。目录在范围切换时保留供继续选择，统计内容在等待时隐藏。

下方复用 `LibraryBrowser`，父级按范围 key 重建。可选固定范围在挂载时初始化，隐藏重复范围控件，初始只看收藏；其他筛选可独立修改，清空仍保留范围。普通题库不传范围时维持原行为。收藏成功沿用失效通知/当前条件重读及过期响应保护，同时触发总览重读，不用旧收藏响应映射统计；当前范围的列表仍匹配时保留详情/答案状态。历史仍需主动展开。

## 验证与边界

契约/IPC 检查严格范围、计数约束、分布总和、正文拒绝、关闭/来源/故障与脱敏。真实 Electron 和 SQLite 检查空库、真实多轮去重、未评价、版本与元数据、旧状态兼容、归档恢复、收藏/历史及同范围清空，另检查真实 SQL 故障/重试和晚到旧范围响应。页面预览保留与记录页正常关闭后恢复原轮独立验证，未将控件存在视为完成。
