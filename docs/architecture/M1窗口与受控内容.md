窗口选择导入 → 预加载固定方法 → 主进程验证来源与请求 → 系统文件选择框 → 后台准备/私有快照 → 仅返回令牌与摘要 → 确认同一令牌 → 原事务提交 → 刷新分页列表。

## 桥接与状态

`desktop.library` 提供 `previewImport`、`cancelImport`、`commitImport`、`discardImport`、`listQuestions`、`getQuestion`、`getAnswer`、`exportTemplate`、`openReference`，M2 第二批另加限长代码文本的 `copyCode`。没有任意文件、SQL、通道或路径入口；源文件只能来自主进程原生选择框，模板目的地只能来自保存框。共享 Zod Schema 严格拒绝额外字段，主进程再次检查参数、来源与返回值，错误只包含错误码、中文说明及必要的文件/行列。

同一时间只允许一个文件选择/准备/导出操作；同步引用锁阻止窗口重复点击，主进程仍有独立忙碌保护。预览令牌归当前窗口所有，重新选择会释放旧预览，页面主导航/重载、渲染消失、取消或关闭均使其失效。原生对话框的迟到结果不能触发准备；不能取消对话框自身时，也不会阻塞应用等待工作线程收尾。

确认提交使用原私有快照和回执幂等规则。若 IPC 响应失败，界面保留同一令牌供重试，不宣称失败一定未入库；放弃只声明关闭预览。库基线变化、期限或令牌失效按错误重新预览。事务开始后不提供中途取消，最大批次提交耗时仍未测量。

## 读取与展示

每页固定 20 题，只读取元数据。专题选项包含活动/归档数量；请求页码按实际总数收敛。列表读取在只读事务内获得一致的专题/总数/记录。

`getQuestion` 返回当前固定版本题干，结构中没有答案。`getAnswer` 必须给出题目稳定身份和版本 ID，版本须属于该题；因此更新期间也能读取所选旧版本。只有点击展开才调用、挂载答案；切题、刷新和详情重新建立时隐藏。请求代数与清理标记防止旧答案或旧详情覆盖当前选择。内容检查页没有草稿、自评、揭晓记录、固定练习队列或统计。

Markdown 由 react-markdown 与现有 remark-gfm 展示，跳过原始 HTML，不增加可执行 HTML 插件。题外引用定义用标准序列化器补入，置于正文前保留首定义优先。表格对齐映射成预声明 CSS 类，不放开内联样式。M2 第二批已用受控 AST 接入代码高亮/复制与图片模态放大，复用相同内容组件和图片协议。

图片地址形式为 `practice-image://resource/<版本ID>/<SHA-256>`。主进程只接受规范 GET，验证版本与哈希在 `version_images` 有关联，返回数据库 BLOB、固定 MIME、`nosniff` 与 `no-store`；无关联或非法 URL 返回 404，内部错误返回无堆栈的 500。CSP 只给图片增加该协议，不允许网络图片或任意文件路径。

Markdown 会对中文文件名进行 URI 编码，展示端和快照绑定均复用 `parseImagePath` 的单次解码/路径校验结果匹配，不重复解码或读取源路径。真实三种 2×3 小图已在 Electron 解码；头部合法而像素损坏的 PNG 显示失败提示。导入校验仍是签名/头部尺寸/限额，不能宣称能排除全部坏图。

外链只有明确 HTTP/HTTPS、无凭据/控制字符且满足限长才显示为链接；显式点击调用主进程再校验并交给系统浏览器。其余链接保留文字。跨地址导航、新窗口、WebView、权限和生产外部连接限制保持。

## 正常退出与验证边界

M1 第五批退出会等待线程与连接收尾。当前 M2 第二批先增加页面保存握手：确认最新输入已保存，或用户明确选择放弃后，才停用 IPC、关闭练习连接、撤销图片协议、等待导入服务/线程关闭并关闭启动存储。重复退出复用协调与清理，不重新创建服务；初始化和关闭竞态中已打开的连接也会收尾。细节见[M2 关闭保存](M2练习窗口与保存.md)。强制结束不能承诺未提交操作已保存。

开发构建与 Windows 解包 EXE 各 19 项场景通过，其中新增五项走真实预加载/IPC/线程/SQLite/React/图片协议。测试主进程替换系统对话框返回和外部浏览器调用，另观察真实 Worker 的创建/退出 ID；没有生产测试开关。正式题库人工审阅、原生对话框人工交互、真实外部浏览器、新 NSIS 安装和最大批次性能尚未验收。
