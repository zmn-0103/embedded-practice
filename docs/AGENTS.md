# 文档目录补充约束

继承[根规则](../AGENTS.md)，本文件仅补充文档与证据的局部要求。

- 根 README 说明项目用途、当前状态和使用入口；本目录 README 负责导航。进展写入[开发记录](开发记录.md)，实际结果、失败和未验项目写入[验收记录](验收记录.md)，当前程序及兼容边界写入[交付说明](当前试用版本交付说明.md)。
- 业务约定放入对应契约，通过索引引用；分类与方案分别查阅[分类树契约](分类树行为与验收.md#本批契约)和[练习方案契约](练习方案行为与验收.md#最小范围)，涉及迁移或恢复时另读[数据保护契约](数据保护与桌面边界.md)。
- 整理或迁移历史时保留可追溯原文和原始证据，明确“当前”与“当时”的范围；调整位置后同步相对链接与入口。
- `evidence/` 中已封存的报告、失败现场、旧规则副本、来源与清单保持原样；新检查使用独立批次或新轮次，不覆盖既有报告，也不更新旧哈希来掩盖文件变化。
- 用户题目技术审阅、主观学习体验、硬件或安装验收只能记录已有明确结论；待填写项保持待验，不代签，不将自动化或文档检查当成人工通过。
