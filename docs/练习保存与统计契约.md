# 练习、保存与统计契约

本页维护当前有效的练习、保存和统计规则。需求基线见[计划书](../计划书.md)；分类范围、专题归属及分类快照见[分类树契约](分类树行为与验收.md#本批契约)，动态方案见[当前方案规则](练习方案行为与验收.md#当前行为)，迁移、备份与恢复见[数据保护契约](数据保护与桌面边界.md)。原日期增补见[历史记录](history/契约增补与模块演进.md#练习保存与统计原始增补)，实际检查、失败与未验项见[验收记录](验收记录.md)。

## 固定队列、内容版本与答案隔离

- 每轮保存固定、不重复的题目队列与对应内容版本；重启保持队列和位置，导入更新不得中途替换本轮内容。最多保留一个可继续的活动会话，无匹配题目时不创建空会话。
- 每题首次进入隐藏参考答案；揭晓前答案正文不得挂载到页面正文或无障碍阅读树。新一轮不自动展示上次答案、历史作答或揭晓状态，同轮返回仍保持本轮已保存状态。
- 练习中的单题历史入口只在揭晓后挂载，仍需主动展开读取；揭晓前不能主动回看旧作答。此规则自 2026-10-25 工作台起替代早期历史设计，依据见[工作台揭晓边界](UI学习工作台行为与验收.md#与既有实现的差异)。题库浏览历史独立主动展开，不计练习揭晓。
- 允许空输入揭晓；搜索默认不展示参考答案片段。自评只在揭晓后可用；揭晓、未评价、跳过、自评及收藏分别处理，收藏与掌握程度独立，不显示未经定义的系统正确率。

## 草稿、自评与未知结果

- 输入停止 500ms 后保存草稿；切题、揭晓、返回首页和正常退出前提交待保存内容。递增修订号拒绝过期请求覆盖新内容。
- 明确展示保存中、已保存和保存失败；失败保留输入，阻止依赖本次保存的切题并允许重试。不承诺未提交按键在强制结束后恢复。
- 同一轮同一题修改自评更新原记录，不重复累计次数；新一轮产生新历史。自评保存与推进位置必须同事务，处理重复点击和重试。
- 学习写入结果未知时保留捕获的原命令、目标与输入，不以新请求重复推进；正常关闭经过统一保存守卫。建轮、旧活动轮替换、固定队列及回执同事务提交，失败保留原活动轮；原请求重试读取原回执。
- 方案/题单最近使用只随符合原保存定义的成功建轮同事务更新，失败不结束原轮，回执重试不重复更新时间；详细来源核对见[常用入口](个人标签与常用入口行为.md#方案与题单的常用入口)。

## 联合筛选与本轮再练

- “不会＋不熟”是当前内容版本的最近自评联合，与其他选题范围取交集，不纳入旧版本自评，不表示系统正确率。个人标签也加入公共交集；列表、匹配数、保存方案与新轮选题共用 SQL 谓词，旧队列保持。
- 结果页可明确选择本轮不会、本轮不会＋不熟、仍未揭晓的跳过题、已揭晓未自评题或全部原题。已揭晓且曾跳过的题按当前本轮揭晓/自评处理；未进入且未跳过的题不冒充跳过或未自评。
- 再练必须来自明确已结束/已完成轮次，只从其固定队列及本轮记录取题；与整个题库的最近自评筛选分开，不补入来源外题目。
- 再练沿用来源轮题目、答案、标题及属性快照，包括其后更新或归档项；开始前说明政策、范围和实际题数。新轮可按原顺序或重新随机，创建后固定。
- 新轮使用新身份，草稿、揭晓、自评和跳过重新开始；原轮全部记录保留。来源身份与范围持久化并纳入完整备份，继续练习仍说明来源快照。
- 再练沿原建轮事务、回执及活动轮替换守卫；来源错误、0 题或写失败不得结束原活动轮。响应未知时锁定选择并重试原请求，不重复建轮。
- 旧版本作答只影响对应历史；已有当前版本自评时，旧版再练不能覆盖为过期状态，也不凭旧内容再练解除新版更新标记。

## 明确选题、题单与本轮清单

- 跨专题勾选组卷和固定题单见[完整规则](固定题单与练习清单行为.md)。固定题单保存有序 `topic_id + question_id`；开始前预览当前有效内容，事务核对全部身份、版本及归档状态，任一变化拒绝整轮并保留原活动轮。
- 新轮固定队列与版本，重新隐藏答案。明确选题采用预览当前版本，结果页再练采用来源快照，开始前分别说明。
- 本轮清单以 50 题分页只读标题、身份、揭晓、自评和曾跳过，不返回题干、答案或草稿。查看不改队列或揭晓；跳题先保存输入，失败留原位，响应未知只重试原请求/目标。曾跳过与当前揭晓、自评分列，不影响长期收藏。
- 勾选更新题的集中复习见[专项规则](内容更新差异与集中复习行为.md)。预览和建轮同时核对当前有效版本及内容更新待复习，任一变化拒绝整轮；结果未知沿原回执重试。建轮后仍固定队列/版本，揭晓消除当前更新标记不会移出本轮。
- 内容差异及两版答案查看只读，不揭晓、不评价、不改笔记或解除更新标记；更新状态不加入条件方案或会话 filters。

## 个人笔记、复盘与材料导出

- [个人笔记](个人积累与复盘导出行为.md)按稳定题目身份保存，独立于作答/版本；导入不覆盖。练习揭晓前不挂载或读取，揭晓后仍主动打开。切题、返回及正常关闭等待保存，失败保留输入和原位置。
- 收藏或标签整理前先保存笔记；等待写入及后续刷新/详情移除期间笔记只读，保存失败不发送变更。只看收藏取消成功时只读保持到详情实际卸载；普通列表成功或变更失败后恢复编辑，详见[笔记与收藏保护](个人积累与复盘导出行为.md#个人笔记)。
- 按轮复盘只读结束轮固定内容，未揭晓项不返回参考答案，未作答项不补造单题历史。同题两次记录对照只展示原作答与自评变化，版本不同明确提示，不生成客观正确率。
- 导出不改变揭晓、复习标记或队列；默认只题目，参考答案只在明确选择答案模式后导出，个人内容也需明确选择。题单采用当前有效版本，轮次采用当时固定版本；图片随材料保留，详见[复盘与导出](个人积累与复盘导出行为.md)。

## 复习待办与最近揭晓

- 待办与收藏、自评、笔记分别保存；揭晓、自评、结束本轮或浏览不自动完成待办，必须显式完成。完成/重开有独立修订和完成时间，旧轮中编辑当前安排不改历史快照。
- 日期/原因编辑 500ms 自动保存，切题、导航及关闭沿统一守卫，失败保持输入，未知结果重试原命令。揭晓前不读旧原因。
- 最近练习按当前内容版本所有练习项最大 `revealed_at` 计算；旧版本、题库浏览、笔记及待办不计。7/30 天为请求前 168/720 小时，等于边界算窗口内已练；未练题可入选，已自评却无揭晓时间的旧数据保持未知，不推断日期。
- 最久优先先未练，再按有时间的从早到晚，未知时间已练最后；随机时先按数量取优先集合再打乱，已建轮不重抽或重排。原题再练及明确勾选不能叠加最近条件/最久排序，详见[专项契约](复习待办与最近练习行为.md)。

## 积累检索与知识关联

- 我的积累不在独立作答界面挂载；旧关联说明只在揭晓后主动展开读取，双题对照也需主动操作。搜索不返回参考答案或旧作答；当前题干/笔记对照不改旧轮快照或计为练习。
- 关联编辑明确保存，尚未保存/未知结果加入统一守卫，切题/关闭先确认，不自动创建关系；冲突保留说明并提供明确放弃重读。
- 题库与我的积累把当前题及明确勾选关联身份交原组卷确认，最多 500 个唯一身份，之后固定队列/版本，见[专项规则](积累检索与知识关联行为.md)。

## 目标活动、当前覆盖与配额

- 每日目标采用成功业务同事务活动：非空自评、首次练习揭晓、pending→done、真实笔记变更。自评不同题和完成不同待办按发生日、稳定题去重，尝试次数单列；重开待办、归档、版本变化不抹去当天事实。
- 现有练习覆盖与自评掌握仍只指当前活动题版本，不被目标账本替换。旧版缺少完整事件，不回填或承诺旧日统计完整；日历旧轮只按现存时间关联，原队列/快照保持。
- 配额先在各指定专题挑选并明确预览，缺额或失效阻止确认，不补其他范围。之后以明确身份进入原 SelectedPractice，再核对当前版本、归档及替换原轮；保存成功仍固定队列。备考目标的题单编辑不改已建轮，见[专项契约](学习目标与配额组卷行为.md)。

## 可选口述计时

- 计时仅为当前窗口临时提醒，每轮默认关闭，每题默认 2 分钟且手动开始；切题、揭晓、结束或返回前先暂停，再执行原保存。草稿保存失败不会建立切题命令，重试保存后仍须明确切题；结果未知仍重试原练习请求，计时保留原位余时，不假定操作已完成。
- 正常自动保存不中断计时；失焦、最小化、隐藏和关闭准备暂停，不自动恢复。到时只提醒，不揭晓、评价、推进或完成待办，也不写 learning_activities 或增加目标、覆盖、掌握。
- 关闭/重载清空计时，原练习持久化与备份规则保持；不能称为学习时长或历史作答用时，见[计时专项](口述计时行为.md)。
