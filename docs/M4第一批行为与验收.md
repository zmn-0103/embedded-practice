# M4 第一批：完整备份导出与恢复预览

> 文档类型：阶段历史。本文保留该批次的原始需求、设计或验收范围；其中“当前”“未实现”和版本号仅指当时，不覆盖[现行文档索引](README.md#当前业务规则)与[当前交付](当前试用版本交付说明.md)。原始失败和待验结论保持。


日期：2026-10-22。依据本轮用户认可的复查结论开展开发。

## 范围

先补查 M3 关键输入、保存、退出与长内容键盘场景；原生自动化、Electron 自动化与人工签署分别记录。可复现核心缺陷先限定修复；历史未知原因不因复测通过而改写。

本批实现设置与数据中的完整备份导出和恢复预览：使用 SQLite 一致性备份，覆盖数据库内全部题库、版本、图片、作答、自评、收藏、队列、条件快照、回执和设置。用户选择备份后仅在独立暂存副本检查应用标识、结构兼容性、完整性、外键和摘要，显示题数及时间。预览不关闭业务连接、不替换当前数据库、不执行恢复。恢复执行、保护性备份、替换回退与成功重启按第二批开展；不提前推进 M5。

数据库正式结构保持 6，依赖与锁文件保持。完整备份为独立 SQLite 文件，时间元数据仅写入导出副本；历史数据库备份没有该时间时明确未知，不用文件修改时间冒充备份时间。过新结构、其他应用、损坏及不完整结构必须明确拒绝；旧结构的兼容校验仅针对暂存副本，沿用既有迁移。

## 验收目标

- 导出前先完成显示设置等已发起的保存；练习仍沿用原返回前保存握手。备份只承诺已确认写入数据库的状态。
- 目标先写暂存文件并校验，成功后发布；失败保留旧目标和当前数据，不能写入当前运行数据目录或其别名。
- 原生文件选择只接受主进程选定路径；窗口接口不接收任意路径或 SQL。取消和重复操作有明确反馈，退出需等待在途备份收尾。
- 备份选择后复制出独立快照；验证不修改来源，摘要不泄露题干或用户作答。损坏、过新、错误应用标识、缺表、外键错误与失败路径有实际检查。
- 真实数据库比较全部业务表及资源字节，证明导出一致性；验证中文/空格路径、取消、导出失败、重复操作、关闭等待及预览后原库仍可使用。
- 保持原 503 单元及开发/解包各 101 场景，分别记录新增测试与原始失败，不把合成输入或系统能力替身当成人工验收。
