# 数据保护与桌面边界

2026-10-28第四批：内容差异为只读，更新复习沿原固定队列/版本/来源和回执模型，结构保持13，没有新增迁移或存储表。完整备份仍含原版本/图片/作答/题单/笔记。使用独立安全入口和每场景新TEMP，不访问原个人库；第三批结构13旧程序的兼容读取仅在新建完整备份副本上检查，结构12及更早程序不能打开结构13。行为见[第四批契约](内容更新差异与集中复习行为.md)，执行结果见验收记录。

本页从原AGENTS.md同名章节迁入，保留既有数据与桌面安全约定。备份与恢复实现另见[完整备份与恢复预览](architecture/M4完整备份与恢复预览.md)、[恢复执行与回退](architecture/M4恢复执行与回退.md)；实际检查与未验项查阅[验收记录](验收记录.md)。

- 运行数据位于 Electron 用户数据目录，与安装目录分离。题目、图片、学习记录和设置均纳入完整备份。
- 开发运行默认使用 `embedded-practice-dev` 数据目录，安装版默认使用 `embedded-practice`；自动化测试必须显式传入独立临时目录，不依赖这两个默认目录。
- 测试必须使用独立临时数据库和数据目录，禁止连接、覆盖或迁移正式用户数据库。样例与压力数据明确标识，不自动进入正式题库。
- 使用 SQLite 一致性备份能力，禁止直接复制正在写入的数据库冒充完整备份。
- 恢复前检查完整性、应用标识与结构版本，并展示恢复摘要；自动备份当前数据失败时停止恢复。
- 恢复采用暂存、校验、关闭连接、替换与失败回退流程，处理数据库伴随文件；损坏或更新结构版本的备份不得覆盖当前数据，恢复成功后重启应用。
- 数据库迁移前备份；失败保留可恢复数据并提示，禁止自动重建空数据库掩盖失败。历史版本暂不自动清理。
- 开启上下文隔离和渲染进程沙箱，关闭渲染进程 Node.js 集成。桥接接口使用共享类型，主进程仍需重新校验输入与调用来源。
- Markdown 通过受控组件展示，图片仅通过已导入资源 ID 读取；不把题库当作可执行页面。外链只允许明确验证的 HTTP/HTTPS 地址。
- 实现单实例限制；错误向界面返回统一错误码、中文说明及必要定位，堆栈仅进入本地诊断日志。日志默认不记录完整题目、用户答案或敏感信息。

## 结构11与独立试用（2026-10-27）

构建20261027.3-practice-flow新增再练来源与联合自评条件，使用结构11；v1～v10先创建并校验一致性保护备份，再事务升级。结构10到11仅新增会话来源身份/范围，旧轮对应列为NULL，保留旧队列、版本、草稿、方案及自定义对象。备份受阻、未知同名列或外键失败停止/回滚，禁止重建空库。旧备份只在暂存副本升级、原备份字节保持。

结构11不能由旧结构10程序打开或直接回退。试用入口显式指定独立数据目录，不替换个人桌面或自动迁移正式学习库；退出试用后可继续使用原程序和原数据。如需带入进度，用户先在原程序导出完整备份，再在试用程序预览并确认恢复；这不会把原库升级。新再练来源及编辑后方案纳入完整备份，损坏来源拒绝恢复。


## 结构12与固定题单（2026-10-27）

## 结构13、个人笔记和材料导出（2026-10-27）

20261027.5-study-assets增加personal_notes，题目内部稳定身份外键、文本、修订和保存时间独立于题库版本/练习轮。1～12先一致性保护备份后事务迁移；12升13仅新增空笔记表，既有表/索引/触发器和自定义对象保持，失败完整回滚。完整备份验证正整数修订、UTF-8字节上限、时间、唯一题目和有效关联；源备份只读，旧库只在暂存副本升级。结构13不能交给旧程序打开。

study六接口沿原来源/严格参数/输出校验和恢复暂停/关闭保护。笔记保存采用期望修订和原内容幂等重试；未知结果阻止丢失本地文字的切换和正常退出，明确重新读取前确认放弃本地修改。恢复等待笔记保存，恢复自身忙态继续独立处理。

Markdown材料仅接收题单/轮次身份及内容模式，保存位置来自系统对话框。图片从所属版本入库资源核对哈希后复制，不读源文件或网络；写入随机资源目录和暂存文件，最后替换Markdown，失败只清理本次创建目标。拒绝应用数据目录内的材料目标。完整备份解决恢复，Markdown解决阅读，不能用Markdown恢复数据库。详见[本批契约](个人积累与复盘导出行为.md)。
