# 数据保护与桌面边界

本页维护当前有效的数据保护、备份恢复和桌面能力边界；当前结构为 17。运行对象、构建标识与兼容入口以[交付说明](当前试用版本交付说明.md)为准，实际检查、失败和未验项见[验收记录](验收记录.md)。原结构增补、各批独立 EXE/试用目录及当时执行描述迁入[历史记录](history/契约增补与模块演进.md#数据保护原始结构演进)。[M4 备份设计](architecture/M4完整备份与恢复预览.md)及[恢复执行设计](architecture/M4恢复执行与回退.md)是阶段历史，不能将其中结构 6 或旧保存范围当作当前全貌。

## 数据位置与独立验证

- 运行数据位于 Electron 用户数据目录，与安装目录分离。题目、图片、学习记录和设置均纳入完整备份。
- 开发运行默认使用 `embedded-practice-dev`，安装版默认使用 `embedded-practice`；自动化必须显式传入独立临时目录，不依赖这两个默认目录。
- 测试只使用独立临时数据库和数据目录，禁止连接、覆盖或迁移正式用户库。样例与压力数据明确标识，不自动进入正式题库；运行前明确本轮开发入口或 EXE、构建标识、结构版本和新 TEMP。
- 独立试用显式指定独立数据目录，不自动升级正式学习库或替换个人桌面；旧程序与数据按原交付保留。带入进度须先从原程序导出完整备份，再在试用副本预览并明确恢复，不把原库升级。

## 一致性备份、恢复与失败回退

- 使用 SQLite 一致性备份能力，禁止直接复制正在写入的数据库冒充完整备份。完整备份保留全部业务数据及用户自定义对象，不重新拼装或重算学习记录。
- 恢复前检查完整性、应用标识、受支持结构、外键及实际业务内容，并展示摘要。未知、损坏或更新结构版本备份不得覆盖当前数据；不凭产品版本号推断兼容。
- 旧备份仅在暂存副本升级，源备份只读且字节保持；不能修补或清空损坏来源来使其通过。合法失效引用按业务定义保留供用户处理，不静默扩成不限。
- 恢复等待原练习、笔记、待办和其他学习数据保存，结果未知或保存失败不能绕过；恢复自身忙态与其保存检查分开处理。随后暂停新业务请求、排空在途操作，自动创建并校验当前数据的保护备份；保护失败停止恢复。
- 恢复采用暂存、校验、关闭全部连接、替换及失败回退，处理数据库伴随文件；未确认关闭禁止替换。恢复成功后重启应用，回退或启动恢复失败保留现场，不继续使用部分关闭服务，也不自动建空库。

## 结构迁移与兼容性

- 支持的结构 1～16 先创建并校验 SQLite 一致性保护备份，再事务升级到 17；DDL、版本更新及外键校验形成完整迁移，失败保留原结构、原数据和可恢复备份。备份受阻、未知同名对象/列或外键错误导致停止/回滚，禁止重建空库掩盖失败。
- 原题目、内容版本、固定队列、草稿、收藏、自评、定义、笔记及自定义对象按相应迁移保护规则保持；历史版本暂不自动清理。新来源字段对旧轮为 NULL，不伪造来源或旧使用时间。
- 当前结构 17 不能交给只支持旧结构的程序打开或直接回退；各版独立试用数据不与旧程序混用。产品版本与数据库结构分别判断。

## 学习数据写入、IPC 与生命周期

- 开启上下文隔离和渲染进程沙箱，关闭渲染进程 Node.js 集成。桥接接口使用共享类型，主进程仍重新校验输入、输出及调用来源；不提供任意 SQL、路径或通道。
- 固定 study 六接口、review 的 read/save/list、knowledge 五通道及 planning 固定能力沿原连接、恢复暂停、关闭注销和服务释放；不因新增业务另开通用能力入口。笔记、待办原因及关联说明按纯文本，检索片段有界。
- 笔记/待办保存采用期望修订及捕获原内容幂等重试；冲突、失败或结果未知保留本地输入，阻止丢失文字的切换及正常退出。明确重新读取前确认放弃本地修改；关闭未确认仍提供返回窗口。学习写响应未知按原操作重试，或由用户明确停止重试后核对。
- Markdown 通过受控组件展示，图片仅按已导入资源 ID 读取；不把题库当可执行页面。外链只允许明确验证的 HTTP/HTTPS 地址，由用户点击后交系统浏览器。
- 实现单实例限制；错误向界面返回统一错误码、中文说明及必要定位，堆栈仅进本地诊断日志。日志默认不记录完整题目、用户答案或敏感信息。

## 只读差异与 Markdown 材料

- 内容差异只读已入库版本/图片，更新题复习沿原固定队列、版本、来源和回执模型；不会另建迁移或改变备份所需的原版本、图片、作答、题单和笔记。
- Markdown 材料只接收题单/轮次身份及内容模式，保存位置来自系统对话框。图片从所属版本入库资源核对哈希后复制，不读来源文件或网络；写入随机资源目录及暂存文件，最后替换 Markdown，失败只清理本次创建目标，保留原目标。
- 拒绝应用数据目录内的材料目标。完整备份用于恢复，Markdown 用于阅读，不能据 Markdown 恢复数据库，见[材料导出规则](个人积累与复盘导出行为.md)。

## 临时口述计时

- 计时无表、迁移或持久化设置，只在当前窗口内存；正常关闭/重载重置，不纳入完整备份，不影响题目、草稿、轮次、笔记和活动账本。
- 原生窗口 blur/minimize/hide 只发固定无参数 `practice:timer-pause` 通知；preload 只允许订阅/解绑，不暴露原生窗口控制或业务写入。关闭注销监听，发送失败不改变保存握手，见[计时规则](口述计时行为.md)。
