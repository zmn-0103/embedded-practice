- 运行数据位于 Electron 用户数据目录，与安装目录分离。题目、图片、学习记录和设置均纳入完整备份。
- 开发运行默认使用 `embedded-practice-dev` 数据目录，安装版默认使用 `embedded-practice`；自动化测试必须显式传入独立临时目录，不依赖这两个默认目录。
- 测试必须使用独立临时数据库和数据目录，禁止连接、覆盖或迁移正式用户数据库。样例与压力数据明确标识，不自动进入正式题库。
- 使用 SQLite 一致性备份能力，禁止直接复制正在写入的数据库冒充完整备份。
- 恢复前检查完整性、应用标识与结构版本，并展示恢复摘要；自动备份当前数据失败时停止恢复。
- 恢复采用暂存、校验、关闭连接、替换与失败回退流程，处理数据库伴随文件；损坏或更新结构版本的备份不得覆盖当前数据，恢复成功后重启应用。
- 数据库迁移前备份；失败保留可恢复数据并提示，禁止自动重建空数据库掩盖失败。历史版本暂不自动清理。
- 开启上下文隔离和渲染进程沙箱，关闭渲染进程 Node.js 集成。桥接接口使用共享类型，主进程仍需重新校验输入与调用来源。
- Markdown 通过受控组件展示，图片仅通过已导入资源 ID 读取；不把题库当作可执行页面。外链只允许明确验证的 HTTP/HTTPS 地址。
- 实现单实例限制；错误向界面返回统一错误码、中文说明及必要定位，堆栈仅进入本地诊断日志。日志默认不记录完整题目、用户答案或敏感信息。
