# 我的积累检索与知识关联

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

## 检索

学习记录增加“我的积累”。普通关键词按字面子串查询当前题目标题/题干、已保存个人笔记、个人标签和关联说明，区分命中来源并显示有界纯文本片段；不搜索或返回参考答案、历史作答。支持有效/归档/全部题目、来源分类、仅有笔记及笔记最近修改优先，20题分页，单题多处命中合并展示。

空关键词可浏览，默认只看个人笔记；快捷入口提供有笔记、最近修改、归档笔记。最近10个非空搜索关键词在明确搜索成功后记录，可复用/清空；分页和返回不刷新使用时间。题目详情返回保留原搜索条件、页码、结果和滚动位置，另有明确刷新操作；笔记编辑仍沿原保存守卫。

## 人工关联

每条关联包含两个稳定题目身份、类型、对比说明、修订和修改时间。类型为容易混淆、前置知识、同一项目场景；前置知识明确“目标题是来源题的前置”，反向列表显示后续知识。其他两类两端含义相同。同一无序题目对与同一类型只能有一条关联，不能自关联，改类型/编辑/删除按原修订核对，不静默合并或覆盖。

题库详情、揭晓后练习和轮次复盘主动展开后读取关联，任一端都能找到同一条记录。重新导入/归档保持；归档端明确显示。关联列表20条分页，说明最多2000个UTF-16单位，纯文本保存；创建/修改明确保存，未保存输入或未知结果会阻止离开，可原命令重试或明确放弃。

主动对照读取两题当前题干，并提供各自的当前个人笔记，不改变旧轮内容/揭晓/自评。前置方向和当前版本明确展示。题库和我的积累可勾选关联题，与当前题一起进入原明确题目组卷确认，最多500个唯一身份；归档/失效不补题，开始后队列固定。练习中与旧轮复盘先提供整理/对照，组卷从题库或我的积累进入。

## 数据与隐藏边界

独立作答揭晓前不挂载或读取旧关联说明/检索结果/笔记。检索与对照均不把浏览当练习，不读取来源Markdown或网络；保存关联不修改题库版本、历史、待办或自评。

完整备份恢复包含关联、说明和最近查询，拒绝无效身份、重复题目对、修订/类型/文字/日期越界及孤儿。关联和检索不引入网络、语义搜索或自动生成的知识关系。迁移失败回滚，遵守数据保护契约。
