# 项目模块职责

本页按当前职责说明应用模块，覆盖结构 17 的既有功能及临时口述计时，不记录各批构建或测试过程。代码路径相对仓库根目录；修改前仍需回查实际源码和调用关系。业务规则分别见[题库与导入](题库与导入契约.md)、[练习保存与统计](练习保存与统计契约.md)、[方案](练习方案行为与验收.md#当前行为)及[数据保护](数据保护与桌面边界.md)；原按批次追加的设计说明见[模块演进历史](history/契约增补与模块演进.md#模块原始批次演进)，实际结果见[验收记录](验收记录.md)。

## 进程与基础模块

| 位置 | 当前职责与边界 |
| --- | --- |
| `src/main/index.ts`、`src/main/window.ts` | 启动、受信任页面、单实例、连接/服务生命周期、诊断及正常关闭协调。 |
| `src/main/ipc/` | 固定请求路由、主进程输入/输出和调用来源校验、错误转换；恢复暂停、任务排空及关闭注销。 |
| `src/main/database/` | 连接、结构 17 初始化、受保护迁移、事务及持久化；事务边界服务完整业务操作。 |
| `src/main/workers/` | 批量解析与资源准备等后台工作，避免同步处理大批来源阻塞窗口。 |
| `src/preload/` | 只暴露白名单桌面方法及受限事件订阅，不提供任意文件、SQL、路径或 IPC。 |
| `src/shared/contracts/` | 共享 TypeScript 类型、严格请求/响应校验和错误结构，不引入主进程专用能力。 |
| `src/renderer/src/` | 展示、输入、临时选择及交互状态，不直接访问文件系统、数据库或 Node.js。 |
| `tests/` | 单元、数据库集成、组件、Electron 流程及独立样本；不同验证层分别提供证据。 |
| `question-banks/` | 题库来源、原始题答/逐题映射、模板、显式示例及配图；保持稳定 ID 和审阅状态，不自动导入，也不是运行数据库目录。 |

纯解析、变更比较及队列生成尽量与 I/O 分离。沿现有边界工作，不为填满目录创建空实现、第二套状态机或无价值转发层。

| [content-update-reader.ts](../src/main/database/repositories/content-update-reader.ts)、[content-updates.ts](../src/shared/contracts/content-updates.ts) | 只读当前详情目标版本及同题更早版本；元数据无正文，题干/答案分开显式读取，沿原 library IPC/生命周期。 |

方案/题单仓库管理置顶、最近时间和列表摘要；`practice-repository` 在原建轮/回执事务内核对来源定义再更新时间，失败整批回滚，不让“填入”或重复回执冒充新使用。

## 练习、保存与工作台

[App.tsx](../src/renderer/src/App.tsx)组合六入口、侧栏和轻工具栏，协调跨页保存、关闭及数据操作；[LearningOverview.tsx](../src/renderer/src/components/LearningOverview.tsx)复用原 PracticeWorkspace 活动轮上下文与 learning.read，只展示真实摘要、填入条件或调用原继续方法，不维护另一份会话。[LibraryBrowser.tsx](../src/renderer/src/components/LibraryBrowser.tsx)管理宽窗三栏/窄窗切换、请求代次、范围/分页和阅读节点；分类管理复用全宽表单。

| 模块 | 当前职责与边界 |
| --- | --- |
| `src/main/services/practice/`、[practice-repository.ts](../src/main/database/repositories/practice-repository.ts) | 独立连接与受控服务，公共选题、固定队列/版本、草稿修订、揭晓、自评、导航、来源、回执及活动轮替换事务。再练仅复制指定结束轮原队列/版本/属性；明确组卷重新核对当前版本/归档；更新复习额外核对临时更新状态。 |
| `PracticeWorkspace`、`practice-controller` | 原 start/run、保存后操作、未知结果重试、活动轮与正常关闭协调；所有再练/题单/待办/配额入口复用这条链路。 |
| [PracticePane.tsx](../src/renderer/src/components/PracticePane.tsx)、[PracticeFavorite.tsx](../src/renderer/src/components/PracticeFavorite.tsx) | 布局和原收藏入口，参与保存/关闭守卫；实际保存和推进仍由原控制器负责。参考答案及练习历史在揭晓后才挂载。 |
| [PracticeRepeat.tsx](../src/renderer/src/components/PracticeRepeat.tsx) | 仅显示结果页再练范围、题数和来源版本政策，交原工作区明确建轮。 |

## 个人积累、复盘与导出

- `study.ts` 定义六个受限接口；`note-schema`/`note-repository` 保存稳定身份笔记、期望修订及原命令幂等。`note-controller` 管理 500ms 保存、冲突和未知结果；`PersonalNote` 复用于题库、揭晓后练习及轮次详情，揭晓前不挂载。
- `round-reader` 只读结束轮摘要、分页元数据和明确单题快照；`RoundReview`/`RoundDetail` 提供查询，`AnswerComparison` 在主动选两条确认后才加载，不改旧轮快照。
- `material-reader` 在同一读取事务准备明确题单/轮次材料；`export-markdown` 只转换受控内容/图片绑定，`write-material` 只将准备内容原子发布至系统所选位置。`MaterialExport` 复用同一入口；渲染层不能传路径、SQL 或材料正文，见[个人积累与导出规则](个人积累与复盘导出行为.md)。

## 待办、检索与知识关联

- `review-todos.ts` 定义严格 read/save/list 及本地日期快捷规则，`review-schema` 只定义单题当前安排；`review-repository` 负责修订 CAS、同内容重试、显式完成时间和分页，不自动安排/完成。`validate-backup` 校验关联、修订、日期和状态。
- `review-controller` 管理 500ms 保存、冲突和原命令；`ReviewTodoEditor` 复用题库、揭晓后练习及旧轮复盘，`ReviewTodos` 只显示当前安排/保留勾选，交原 SelectedPractice 确认。`question-selection` 统一当前版本 MAX 揭晓时间、滚动 7/30 天与最久优先；先取优先集合再沿原洗牌，固定队列不重排。
- `knowledge.ts` 定义五个固定接口，`knowledge-schema` 定义关联/最近搜索；`knowledge-repository` 负责 CAS、无序对去重、双向列表及最近 10 词，`knowledge-reader` 只检索当前题干、已存笔记、个人标签和关联说明，在 SQL 截取有界片段，不读答案/历史。
- `KnowledgeExplorer` 在 LearningRecords 的我的积累入口保持检索快照/返回位置，复用公开 QuestionView。`QuestionRelations` 显式编辑/删除/选择，`relation-controller` 沿学习保存守卫保护输入/未知原命令；`QuestionComparison` 主动读取两端当前题干并复用 PersonalNote。题库/积累将明确身份交原组卷确认，不复制会话管理，见[关联规则](积累检索与知识关联行为.md)。

## 目标、配额与临时计时

- `planning.ts` 约束八个固定能力和目标/活动/范围，`planning-schema` 定义四表；`activity-writer` 在原练习/笔记/待办事务写元数据事实。`planning-repository` 负责 CAS 定义、题单范围去重/失效和配额只读候选；`planning-reader` 提供每日去重进度、日历及当前版本备考覆盖，备份逐条校验。
- `StudyPlanner`/`StudyGoals`/`LearningCalendar` 复用总览和 RoundDetail；`QuotaComposer` 保存一套结构并预览，沿原 SelectedPractice 确认。`planning-controller` 通过原保存协调器处理显式保存、未知命令、冲突和放弃，队列仍由原仓库建立，见[目标与配额规则](学习目标与配额组卷行为.md)。
- `oral-timer-controller` 纯同步处理单调截止时间、分题余时、暂停/重置及新轮清空；`useOralTimer` 安排校准轮询，按工作区、页面和原生暂停事件管理生命周期。`OralTimer` 单独订阅时钟，只在主动展开/聚焦时避开固定栏，到时不滚动或抢焦点。
- PracticePane 操作前先暂停计时再沿原笔记 flush/练习协议，Workspace 保存同窗口本轮计时。`practice-desktop`/preload 只提供固定无参数 onTimerPause；原 practice IPC 在窗口 blur/minimize/hide 通知并清理监听，无计时业务写入或数据库能力，发送失败只诊断。计时不持久化、不扩统计或结构，见[计时规则](口述计时行为.md)。
