# 可选口述计时

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

- 每轮默认关闭；启用后每个未揭晓题默认2分钟，可为本题选1/2/3/5分钟，须明确开始。修改时长/重置只清空本题计时，不清作答。新题默认2分钟，不自动开始；再次回到本题保留当前窗口内暂停的余时和时长。
- 使用单调时钟计算剩余时间，不依赖轮询次数或系统日期。允许开始/暂停/继续/重置；后台延迟后按实际经过时间核对，到时停在00:00，只作界面提醒，不发系统通知、不抢焦点、不播放声音。
- 切题、揭晓、结束、返回前先暂停；练习操作中、关闭准备、窗口失去焦点或隐藏也暂停，不自动恢复。保存失败/未知回执仍留原题、原计时余时，重试不重置计时。普通草稿自动保存不暂停。
- 计时仅用于未揭晓独立作答阶段；到时仍可继续思考/输入，揭晓、自评、推进与待办完成保持原有明确操作。计时不产生学习活动、掌握、正确率或学习时长统计，不读取答案/旧作答/笔记/疑问。
- 同一窗口内保存返回、其他页面再继续，保留本轮各题计时。新轮默认关闭并清除旧轮计时；正常关闭、重启、重载后计时重置。原队列、草稿和历史照常持久化，计时不属于完整备份的持久化设置或学习记录，界面明确提示关闭程序后重置。
- 新组件复用现有主题和按钮；关闭计时时保持紧凑，启用后时钟/状态/操作可用键盘到达。倒数不逐秒播报，只在到时显示一次状态提醒。窄窗、缩放、明暗主题实际操作/原生窗口取图与系统DPI/IME人工验收分开。

计时仅存于当前窗口内存，通过固定的原生暂停通知处理窗口失焦、最小化或隐藏；不增加持久化设置、数据库迁移或网络请求。
