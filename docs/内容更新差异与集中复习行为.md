# 内容更新差异与集中复习

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

## 差异查看

题库详情主动打开内容版本与差异后，读取该题旧版本元数据（每页20条），默认与上一个内容版本对照，也可明确改选更早版本。目标为当前题库详情版本；目标已变化时停止读取并提示刷新，不混入另一道题或新的内容。单版本题目明确说明没有更早内容版本。

题干变化默认可查看；参考答案的两份正文只在用户明确点击“查看参考答案变化”后读取、挂载。改变旧版本或题目后重新隐藏答案差异，旧响应不得覆盖新选择。文字差异按行标注新增/删除/未变，长内容超出有界计算预算时完整显示原片段和新片段，不截断或伪装精确差异。

两份内容预览使用各自入库版本与图片；题干文字相同时仍说明图片、引用或答案可能变化，允许查看预览，不把纯文字相同宣称为内容完全相同。不读取题库来源文件或网络，不把题库Markdown作为可执行页面。查看版本、差异、参考答案差异均只读，不揭晓练习、不自评、不消除待复习标记，不改变笔记/历史。

## 更新题集中复习

沿用既有“内容更新待复习”：当前内容sequence>1，且该当前版本没有练习揭晓或对应自评。标签/排序等纯元数据变化不产生内容版本。新题未练习与内容更新分开；题库查看答案/差异、旧版再练不解除当前版本标记。

可筛出更新题后跨专题/页勾选，再用明确的“复习勾选中的更新题”进入组卷确认。临时勾选可能含其他题，预览逐项显示归档/失效/不再待复习，不自动删项或补题；用户可明确从本轮移出不可用项，原勾选和保存题单保持。

开始前核对每项当前有效版本及待复习状态；任一版本/归档/待复习状态变化则整轮拒绝，原活动轮不结束。请求结果未知时按原请求/题目/条件重试，不重新筛选或重复建轮。可原顺序或仅这些题随机，新轮身份独立，队列/内容/顺序一旦建立即固定；揭晓后不因标记消失而删题，更新/归档也不替换本轮内容。来源名称说明这是更新题复习，题单仍只存身份，条件方案保持原语义。

明确题目组卷中，更新状态限定只在预览和建轮校验，不写进条件方案或会话filters。持久数据仅使用原固定队列/版本/来源名称/回执，故无需结构升级。完整备份和旧轮复盘继续保存原版本/答案/作答，个人笔记不变。
