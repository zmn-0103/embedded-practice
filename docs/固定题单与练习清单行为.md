# 固定题单、勾选组卷与本轮清单

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

[个人标签与常用入口](个人标签与常用入口行为.md)增加题单置顶、最近成功开始排序及时间展示，载入/编辑不计使用；勾选批量个人标签沿原稳定身份和500题边界。题单仍存有序身份，确认页不补题，最近使用与建轮同事务；本轮清单/草稿/揭晓规则保持。

[更新题集中复习](内容更新差异与集中复习行为.md)复用现有勾选/题单入口，增加明确“复习勾选中的更新题”。该确认额外显示不属于更新待复习的项并阻止开始，显式移除只影响本次确认，不改原勾选或保存题单。普通组卷规则保持；固定题单仍只存身份，不存更新筛选，开始后队列仍固定。

## 当前行为

- 在普通题库列表勾选有效题目，按勾选先后组成临时集合；跨专题、筛选、分页与同次打开内的页面切换保持，重复身份不重复加入。清空仅清空临时勾选。每轮/题单最多500个明确题目，最多100份题单，超限明确拒绝、不静默截断。
- 固定题单保存名称和有序topic_id＋question_id身份，不保存筛选条件、答案或题目版本。与动态练习方案分开。可保存新题单、载入并明确替换勾选、更新/改名和删除定义；删除不删除题目、历史或已建轮。
- 名称沿用去首尾空白、1～60字符、无控制符及SQLite ASCII NOCASE唯一。更新核对原名称/完整身份列表，过期编辑拒绝；响应未知按原操作重试，不重复保存或盲覆盖。列表和预览失败保留错误与输入，关闭等待在途写入。
- 题单重导入后仍按稳定身份关联。预览逐项显示可用、已归档、已失效，缺项保留；用户明确移除不可用项后才能创建较小集合，不自动补题或替换其他题目。
- 勾选和题单练习采用开始前预览的当前有效内容版本。主进程建轮事务再次校验全部身份/版本/归档状态，任一变化拒绝整轮并保留原活动轮；用户重新预览后再确认。创建时保存固定队列及版本，新轮重新隐藏答案。顺序模式按所选顺序，随机仅重排这些题。
- 查看本轮清单只读取题目身份、标题、是否揭晓、自评和曾跳过，禁止读取/返回题干、参考答案或旧作答。按50题分页，定位当前位置；单独显示“尚未揭晓”“已揭晓未自评”“不会/不熟/掌握”及“曾跳过”，不把跳过写为不会。
- 点击清单指定题仍走原草稿/事务/回执守卫：先保存当前输入，失败留在原题；成功只变位置，不揭晓、评价、补题或改队列；未知结果重试原目标/请求。查看清单本身不保存或改变练习，原自动保存计时仍照常。
- 完整备份与恢复包含题单定义、成员顺序及勾选来源；引入题单前的旧轮来源字段保持NULL，不补造来源。旧库先一致性保护备份再事务迁移，旧程序不能打开高于其支持范围的数据库。所有测试与试用用独立目录。

## 备考目标引用题单

备考目标保存题单身份，当前成员按稳定题去重。题单删除后目标保留失效引用并明确提示，整目标不可假称完整；可明确选择仍存在的一份题单进入原确认。目标整范围超过500题不截断，按题单分别练。题单/目标修改不影响已经建立的固定队列。[目标与配额契约](学习目标与配额组卷行为.md)。
