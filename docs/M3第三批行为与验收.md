# M3 第三批：单题历史与内容更新待复习

> 文档类型：阶段历史。本文保留该批次的原始需求、设计或验收范围；其中“当前”“未实现”和版本号仅指当时，不覆盖[现行文档索引](README.md#当前业务规则)与[当前交付](当前试用版本交付说明.md)。原始失败和待验结论保持。


日期：2026-10-21。接续随机练习与结构 4，原有 430 项单元及两种形态各 68 项属于上批证据，本批须重新验证。

## 本次范围

1. 题库详情和练习页提供主动展开的单题历史。按稳定身份查询，不因同名题、不同专题相同题号、文件改名、归档或恢复混入其他题目。默认不请求历史、挂载旧作答或旧参考答案。
2. 内容更新待复习标记出现在题库列表/详情。结构、依赖与锁文件保持，主题/字号、学习记录总览、完整恢复及 M4/M5 不在本批内。

## 历史行为

- 只有已保存编辑（包括清空后的修订）、已揭晓或已跳过的实际作答行计入历史；仅排队且没有任何操作的行不计入。练习页排除本轮，题库可查看当前活动轮已保存记录。
- 同轮修改自评更新同一条历史，新轮产生新条目。只保留旧版自评但没有真实作答行的数据不补造历史。
- 列表每页 20 条，按会话开始时间倒序及稳定次序排列，展示当时标题/专题、内容版本序号、是否当前内容版本、顺序/随机、会话状态、揭晓/跳过/自评与时间。列表不返回完整作答、题干或答案。
- 点开单条记录才读取已保存草稿、当时题干、资源绑定及已揭晓参考答案；从未揭晓的记录不返回/挂载参考答案。用户作答按纯文本显示，不作为 Markdown 或 HTML 执行。
- 历史查询不保存当前输入、不改变揭晓/自评/位置/收藏或练习统计。读取失败提供重试；切题、翻页、关闭或卸载后旧响应不能展示到另一题。
- 历史版本图片使用当时版本 ID 和资源绑定；导入来源移动、图片替换及归档后仍能读取已入库的旧资源。

## 内容更新状态

最新内容版本序号大于 1，且该版本尚无实际练习揭晓或有效当前版本自评时，显示“内容更新待复习”。首次导入不标记；只改标题/难度/标签/顺序不新增内容版本。内容更新但从未练习的题也需标记。

练习揭晓最新版（允许空输入、未自评）后标记消除；仅排队/跳过、查看题库参考答案或历史不消除。旧活动轮继续揭晓旧版本不能消除新版标记；新一轮使用最新版。旧自评仍通过历史查看，不用于新版掌握状态。已有旧状态只有对应最新版本的有效自评时兼容认定为已练习，不伪造缺失的历史作答。

## 修改与验证

- 共享契约、只读历史仓储、既有题库服务/可信 IPC 与受限预加载、展示组件及局部样式；不开放 SQL/路径或新增通用查询入口。
- 契约/IPC 单元检查，真实 SQLite 的历史资格/分页/跨专题/归档恢复/版本/标记与读取失败，真实 Electron 的默认隐藏/主动展开/重试/乱序/旧图片/保存阅读保持。
- 完整单元、类型/格式、构建、开发与重新生成的 Windows 解包 EXE 回归，原各 68 项保持。截图目视与系统 DPI/完整人工验收分别认定。
- 逐文件先 Bug 再可维护性复查；实际结果、失败、环境与证据写入验收记录。改前副本位置见 `docs/evidence/m3c/environment.json`，测试仅用显式独立临时目录。
