# V0.0.3 使用说明

适用于当前 **V0.0.3 / 构建 `20261030.1-v003-bank` / 数据库结构 17**。本机程序位置与兼容边界见[当前交付说明](当前试用版本交付说明.md)，项目能力与限制见[项目首页](../README.md)。

本机桌面已按 2026-10-30 的明确要求重置为 23 专题 382 题、归档 0、全部未练习，个人使用记录为空；这是一次交付操作，程序不会在日常启动或导入时自动重置记录。源码首次启动使用独立空库，需要主动导入题库。

## 进入程序与选择入口

使用已有桌面“嵌入式刷题本 V0.0.3”，或保留完整 `win-unpacked` 后运行其中的 EXE。源码启动见首页的 `npm ci`、`npm run dev`。正式数据默认在 `%APPDATA%/embedded-practice/`，开发默认在 `%APPDATA%/embedded-practice-dev/`，程序不会自动把仓库题库或测试样本导入个人数据。

程序提供六个入口：

| 入口 | 用途 |
| --- | --- |
| 学习总览 | 查看当前版本学习情况、继续活动轮、每日/备考目标与活动日历 |
| 知识板块 | 按板块找题，查看已有题数和待补充方向 |
| 开始练习 | 填写条件、使用或编辑练习方案、设置分专题配额 |
| 题库 | 搜索筛选、查看内容、勾选题目、固定题单、标签与复习待办、导入和分类 |
| 学习记录 | 当前版本统计、按轮次复盘、我的积累检索 |
| 设置与数据 | 外观与本地主题、完整备份与恢复、数据位置和日志 |

练习期间使用“保存并返回”离开，之后通过“继续练习”回到已保存位置。

## 导入或更新题库

当前完整题库为[23 专题 382 题](../question-banks/releases/v003-20261030/README.md)。新建空库时，在“题库”点击“导入题库”，一次选择 `question-banks/releases/v003-20261030/topics/` 下全部 23 份 `.md`；不要把 README、来源映射或编辑记录作为题库导入。已有本机桌面数据已导入，无须为了开始练习再次导入。

1. 选择一个或多个专题 Markdown 文件，等待检查；准备期间可取消。错误会指出文件、行列与原因，请在程序外修正后重试。
2. 核对预览中的新增、内容更新、信息变更、不变、归档和恢复数量。每份文件是一个专题的**完整快照**；原有题目未出现在这次快照中会被归档，不要用局部题目文件覆盖完整专题。
3. 确认后等待“导入完成”，或放弃本次预览。预览默认保留 15 分钟；来源修改后需要重新预览，不能直接提交旧预览来导入新内容。
4. 确认结果尚未核实时按原请求重试。相同内容重导入不会重复增加题目，不能仅凭一次响应失败认定没有入库。

自建题库可先“导出题库模板”，在程序外补全并审阅。每题稳定身份是 `topic_id + question_id`，更新时保持 ID。图片放在 Markdown 同级 `assets/`，支持 PNG/JPEG/WebP；原始 HTML、远程图片、绝对图片路径、SVG 与脚本会被拒绝。格式见[Markdown V1](MarkdownV1题库格式.md)、[模板](../question-banks/templates/README.md)和[配图示例](../question-banks/examples/README.md)。程序只校验格式与关联，技术内容仍需人工核对。

题干、答案或图片变化会生成新内容版本；仅改标题、难度、标签或顺序属于信息变更。归档保留已有历史，原 ID 再出现可恢复；重导入不覆盖个人笔记。旧轮沿原队列和版本，下一轮才采用新内容。入库图片不再依赖原文件位置，参考外链仅在主动点击后交给系统浏览器。

## 按板块、专题和条件找题

“知识板块”显示本机分类的实际题数；空板块可查看规划，不能开始空练习。点击有题板块会进入相应题库范围，并清除旧的附加筛选；普通导航返回题库则保留同次打开内的条件和阅读位置。规划目录不会自动导入题目或建立分类。

题库导航按“板块 → 专题”展开。“全部分类”取消分类限制，“未分类”只看尚未归属的专题；查找专题只收窄导航，点击范围后才改变题目结果。新专题默认未分类，可展开“管理分类”创建或改名板块、保存专题归属。每个专题至多归属一个板块；删除板块只把专题改为未分类，不删除题目或记录，再导入同一专题保留原归属。

关键词搜索当前标题、题干与题库标签，不查参考答案。分类、专题、题库标签、个人标签、难度、自评、收藏和最近练习条件可组合使用，结果取交集。修改条件后按界面按钮应用，区分“已填写”与“已应用”的条件。难度的易（基础）/中（进阶）/难（综合）是题目复杂度，个人掌握程度由自评单独表示。

“未练习”指当前版本尚无揭晓或有效自评，排入队列与跳过不算练过；已揭晓未自评单独显示。可联合选择“不会”和“不熟”。最近练习按当前版本最近一次练习揭晓时间判断，可选从未练、最近 7 天未练、最近 30 天未练；浏览答案、修改笔记或待办不会刷新该时间。

题目内容更新后，当前版本尚未练习会显示“内容更新待复习”。查看差异、题库答案或旧历史不会消除标记；在练习中揭晓当前新版本才会消除。可查看题干差异与各版图片，参考答案差异需要另外主动展开。筛选后可勾选并点击“复习勾选中的更新题…”，核对状态与版本后开始。

## 保存方案、勾选题目与固定题单

| 方式 | 保存什么 | 适合场景 |
| --- | --- | --- |
| 练习方案 | 分类、专题、筛选、模式、题数等动态条件 | 经常使用同一选题规则，每次按当前题库重新取题 |
| 固定题单 | 题目的稳定身份与顺序 | 反复练同一组明确题目，或关联备考目标 |
| 临时勾选 | 同次打开内选中的题目 | 先挑一组题立即练习，尚不需要保存定义 |

在“开始练习”填写条件后，可保存当前条件为方案。选用方案只填表，明确开始才创建新轮；已有方案可改名、用当前条件更新或另存。引用的分类、专题或个人标签失效时会提示，先修正条件再更新或另存，不会扩大成全部题目。方案支持置顶，同组按最近成功开始练习排序；查看、编辑或填入条件不计使用。

在题库跨专题、筛选与分页勾选题目，按勾选先后组成临时集合，可进入组卷确认，或命名保存固定题单。载入题单会明确替换当前勾选；可更新题单内容、改名、删除定义与置顶。每轮/题单最多 500 个唯一身份，最多 100 份题单；删除定义不删除题目或已有记录。

开始前预览会列出可用、归档与失效项，需要明确移除不可用项后再确认，不自动补其他题目。按顺序练习使用所选顺序，随机只打乱这批题；开始时再次校验内容版本，随后队列固定。固定题单保存身份，不保存当时题目版本；结果页的“再练本轮”则使用原轮版本。

## 开始、继续与结束练习

1. 在“开始练习”设置范围、顺序/随机、题数与筛选，核对匹配题数；没有匹配时不能开始。匹配不足时使用实际匹配数量。最久未练优先先取够本轮题目，随机模式再只打乱这一批。
2. 明确开始后建立固定队列与内容版本。已有活动轮时，继续原轮与结束原轮后开始新轮是两个明确操作；无匹配不会结束旧轮。
3. 在“我的答案”输入文字或代码，也可只在脑中思考，再点击查看参考答案。独立作答揭晓前不展示旧作答、个人笔记、旧待办原因或关联说明。
4. 揭晓后选择“不会 / 不熟 / 掌握”，或暂不评价后前进；未揭晓可跳过。跳过与揭晓未评价都不会自动记成“不会”。
5. 展开本轮清单可看位置和真实状态，点击指定题会先保存当前输入，再跳转；查看清单不会揭晓或评价。上一题、自评修改和收藏不会重新抽题。
6. 完成或结束后看本轮摘要，可再练不会、不会＋不熟、跳过、已揭晓未自评或全部原题。再练另建新轮，沿来源轮内容版本，答案与输入重新隐藏/清空，旧记录保留。

“保存并返回”保留活动轮，“结束本轮”保存后结束。关闭并重开可继续已保存队列，随机顺序不会再次洗牌；题库更新、收藏变化和为下一轮修改条件不会改写原轮。

输入停止 500ms 后自动保存。切题、揭晓、自评、结束、返回与正常关闭前立即提交最新输入，保存失败保留文字并阻止离开；按提示“重试保存”或“重试原操作”核实同一次请求。草稿上限为 1MiB UTF-8，超限需缩短，不会静默截断。

无法确认保存时，关窗提示默认返回窗口；只有明确选择放弃未保存内容并退出才放弃。强制结束进程只能保留已确认保存状态，不保证最后尚未提交的按键可恢复。

## 可选口述计时

题目标题下可手动启用倒计时，每题默认 2 分钟，可选 1/2/3/5 分钟。手动开始、暂停、继续或重置；切题、揭晓、返回、失去焦点或最小化会暂停，不自动继续。到时仅显示提醒，仍由自己决定何时揭晓、自评或推进。

同一窗口内返回后继续，保留各题余时；新轮默认关闭，关闭程序、重载或重启后计时重置。计时不属于学习时长统计，不写目标进度，也不进入完整备份。

## 收藏、个人标签、笔记和复习待办

收藏独立于自评；取消收藏不改变掌握程度、历史或已建轮队列。收藏操作前会先保存笔记，操作与列表刷新期间编辑器暂时只读；保存失败保留输入并停止收藏操作。

个人标签与 Markdown 题库标签分开管理。可创建、改名、删除个人标签，对勾选题目批量添加或移除，并用于筛选与保存方案。重导入或归档保留标签关联；删除标签不删除题目或记录。

每题可主动打开个人笔记，保存纯文本或粘贴代码；笔记跨轮、内容版本与归档保留，不被题库导入覆盖。停止输入 500ms 自动保存，离开前等待确认；失败保留输入，旧修订冲突不会覆盖新内容。练习中须揭晓后再主动打开，新题和新轮默认折叠。

复习待办可设待复习/已完成、可选日期和原因，也可延期、取消日期或重新加入。题库详情、揭晓后练习及轮次复盘均可操作。**完成待办必须明确点击，打开题目、揭晓、自评或结束一轮都不会自动完成。** 日期/原因停止输入后自动保存；待办列表支持状态、到期/逾期/无日期筛选与跨页勾选，勾选后仍要进入组卷确认。

## 学习记录、复盘与材料导出

“学习记录”的当前版本统计按题去重，分别显示已揭晓、已自评、收藏、内容更新待复习及自评分布，不给系统正确率。旧版本记录继续保留，但不会算作新版已掌握；元数据变化不重置统计。

主动打开“查看本题历史”，再展开某条记录，可查看当时版本、作答、自评与已揭晓的参考答案。未揭晓记录仍不展示参考答案。可跨页选两条记录，点击“对照这两次作答”，对照自己的回答、自评、时间与内容版本；查看历史不改变当前练习状态。

“按轮次复盘”列出已结束/已完成轮，查看当时范围、顺序和各题状态；展开单题才读取当时内容与作答。没有文字作答或尚未揭晓会按实际标记，不据此推断学习效果。

固定题单与已结束轮可导出 Markdown 复习材料。默认仅题目，可明确选择加参考答案，或自己的作答与当前个人笔记。题单采用当前有效版本，轮次采用当时固定版本；笔记始终是导出时已保存的当前笔记。题单中有归档或失效项时先处理再导出，不自动补题。Markdown 与同目录新建资源文件夹须一起保留；材料用于阅读，不可用来恢复数据库。

## 我的积累与人工知识关联

在“学习记录 → 我的积累”按关键词检索当前题目、已保存笔记、个人标签和关联说明，可选来源、仅有笔记、活动/归档范围与最近修改优先。结果标记命中片段，支持笔记快捷入口和最近 10 个关键词；进入题目再返回时保留搜索条件与位置。检索不查参考答案或历史作答。

题目可人工建立“容易混淆”“前置知识”“同一项目场景”关联，填写说明后明确保存。前置关系要核对方向，另一端也能找到同一关联。主动对照展示两题当前题干与笔记，不改旧轮版本和自评；从题库或我的积累可勾选相关题，进入原组卷确认后再开始。

## 每日目标、备考目标、日历与配额

在“学习总览”设置今日自评不同题数与明确完成不同复习待办数，0 表示不设置该项；可明确沿用最近目标，不会自动给未来设目标。同一天重复练同一道题仍只计一个不同题目标进度。揭晓与笔记活动单独记录，查看题库答案不计目标；旧版缺少的活动不会补造。

备考目标关联一份或多份固定题单，可设置截止日。范围按题单当前成员去重，题单编辑后范围随之变化；失效引用会提示，需要明确处理。当前版本覆盖和自评掌握分别显示。从目标或其中某份题单进入练习仍需预览确认，单轮超过 500 题时分题单练，不截断。

点击活动日历日期可查看当天活动与轮次，已结束轮可复盘，活动轮则回到继续练习。活动日期按发生时本机日期记录，不因恢复后换时区重新计算。

在“开始练习”的配额组卷中，按专题设置题数和随机/不会与不熟优先/最久未练优先，可保存一套复用设置。最多 20 行、合计 500 题，专题不能重复。预览显示需求、可用与缺额；有缺额或专题失效时不能进入确认，也不会从其他专题补题。修改配额不改变已建轮。

## 外观、数据位置与完整备份

“设置与数据”按页面分区管理外观、本地主题、备份和数据位置。选择主题、明暗与字号后先预览，再明确保存/应用；本地主题可安装、预览、更新与卸载，缺失或损坏会提示。尚未应用的选择不等于已保存设置。

题干、答案和笔记中的代码可复制，图片可打开预览并放大，代码块与表格可横向滚动。语法高亮不代表代码经过编译或验证。

“数据位置”显示本次实际数据、保护备份与日志位置，可打开对应文件夹。诊断日志为 `logs/application.log`，发生诊断后才写入；仅打开目录不表示已有日志。遇到数据库错误请保留数据与日志，不通过删除数据库或事务目录绕过检查。

导出完整备份时，先确认草稿、笔记和设置已保存，再在“设置与数据”选择运行数据目录以外的位置。`.sqlite3` 备份包含题库、版本、图片、练习、作答、自评、分类、方案、题单、笔记、标签、待办、关联、目标、活动与已保存外观；口述计时不包含在内。取消选择不写文件，导出期间等待完成。

恢复时先“选择备份并预览”，核对题数、归档、版本、个人记录与结构。损坏、其他应用、过新结构或关联错误会被拒绝；旧备份只在暂存副本中验证兼容性，来源文件保持。确认“恢复此备份…”后会替换当前全部数据并重启，不是追加导入。程序先保存当前输入并创建、校验保护备份；失败则停止恢复。需要回到恢复前状态，可再选择该保护备份并按同样流程恢复。

不要手工覆盖正在使用的数据库，也不要直接复制正在写入的文件冒充完整备份。结构 17 不能交给旧程序；实际恢复、失败回退与运行检查边界见[数据保护契约](数据保护与桌面边界.md)和[验收记录](验收记录.md)。

源码新增的故障恢复入口适用于本地数据库打不开的情况：在错误页选择健康备份、核对预览并确认恢复。程序先在 `backups/before-recovery-*` 保留坏库及伴随文件的原始副本，保护失败即停止；此目录用于排查，不是健康备份，不能按普通备份直接恢复。无法判断的旧恢复事务仍须人工检查，程序不绕过。此能力尚未替换[当前桌面程序](当前试用版本交付说明.md)。

遇到问题时记录产品版本、构建标识、步骤、实际现象与预期；题目问题另附题库版本及 `topic_id + question_id`。参考[项目首页的反馈说明](../README.md#文档与反馈)，保留必要错误信息，不公开个人数据库。
