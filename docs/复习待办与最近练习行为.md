# 复习待办与最近练习

本页维护当前功能行为；版本、运行对象与兼容要求统一见[当前交付说明](当前试用版本交付说明.md)，数据保护遵守[数据保护契约](数据保护与桌面边界.md)。

## 复习待办

- 每道题按稳定身份保存一条当前安排：待复习/已完成、可选本地日期、简短原因及修订。日期可以为空；明天按本地日历加一天，本周末在工作日取本周六，周六/周日取当天，也可手动指定日期。
- 在题库详情、揭晓后的练习和轮次复盘中编辑安排。尚未揭晓的独立作答不挂载或读取旧原因。原因按纯文本处理，不自动读取笔记或参考答案。
- 原因/日期编辑后500ms自动保存，离题、切页、正常退出前沿统一学习数据保存守卫提交。写失败/冲突保留输入，不能靠返回或关窗丢弃；未知结果重试捕获的原内容。明确重新读取前提示放弃本地修改。
- 完成待办必须显式操作；打开题目、查看答案、自评或练完一轮均不自动完成。允许保留、延期、取消日期或重新加入待复习；完成时间与最近修改时间分开保存。
- 题库提供待办入口，支持待复习/已完成/全部、到期及逾期/无日期/全部日期、分页。到期比较本地日期，未设日期不冒充逾期。归档项保留安排并明确标记。
- 勾选待办可跨页/筛选保持，最多500个唯一身份，清空只改临时勾选。勾选后进入原明确题目确认流程，采用开始前预览的当前版本；归档/失效不补题，原活动轮保护保持。
- 待办变更按原修订核对，同内容重试幂等，过期不同内容拒绝。重新导入、归档、收藏、自评及标签变更不覆盖安排。

## 最近练习条件

- “最近练习”指当前内容版本最近一次揭晓时间；浏览题库、看笔记、编辑待办及续看同一条已揭晓记录不增加该时间。旧版本揭晓不计为新版本已练。
- 可选择不限、当前版本从未练习、最近7天未练、最近30天未练；后两者按请求时刻前168/720小时计算，边界时刻算已在窗口内练过。未练题纳入7/30天未练；旧记录只有自评却没有揭晓时间时显示时间未记录，不猜测其最近日期，也不自动归入7/30天未练。
- 最近条件与分类/专题/标签/个人标签/难度/自评/收藏取交集，列表、匹配数、动态方案和新轮使用同一谓词。旧条件缺字段时行为保持不限。
- 最久未练优先：先当前版本未练题，再按已记录揭晓时间从早到晚，已练但时间未知排在已记录项后，最终沿原题库顺序稳定排序。默认顺序保持。
- 选择最久优先并用随机模式时，先按优先级选足本轮数量，再只打乱这批题；不限优先级时沿原随机抽题。开始后固定队列/版本，后续历史变化不重抽或重排。
- 原题再练与明确勾选不能叠加最近条件或最久排序；结果页再练仍沿来源快照。

## 数据保护

完整备份恢复包含安排及完成状态，校验修订、日期、原因、状态与完成时间的对应及有效题目关联。升级按数据保护契约创建一致性保护备份并执行事务；失败回滚，不改写旧笔记、标签、方案、题单或记录。
