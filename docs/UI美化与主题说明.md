## 设计方向

面向离线阅读、思考、输入和复习的桌面学习工作台。主要内容左对齐，宽窗口侧栏呈现四个已有入口，小窗口恢复横向导航；练习中保持专注布局及原返回保存流程。首页以一幅原创电路走线图呼应嵌入式题库，其他页面采用克制的分隔、间距与层级，避免装饰挤占长代码阅读宽度。

使用本机微软雅黑作为中文界面字体、Segoe UI 作为西文补充，代码使用 Consolas/Cascadia Code。标题 24～32px，界面说明 13～15px，阅读正文保留原 15～22px 设置。四种配色各提供明暗成对的背景、表面、文字、操作、选中和边界颜色，不通过滤镜给图片改色。

默认松间绿的明色基础色：背景 `#f5f6f4`、表面 `#fcfdfb`、正文 `#20332d`、次要文字 `#5d7067`、主色 `#216b52`、浅主色 `#e7f1ec`。其余为晴空蓝、暖沙金、暮山紫，明暗模式独立选择。设置页提供有名称、描述和可键盘选择的配色卡，以及反映未保存选择的局部预览；点击“保存显示设置”后应用到整个软件。

用户随后补充了“大厂客户端质感”建议，本轮采用主面板去边框/微色阶分层、输入双环阴影焦点、暗色字重请求降低 40、等宽数字、正文 pretty 换行、已有筛选的 Grid 折叠及复制对勾 2.5s 自熄。动态效果遵从系统减少动态效果偏好；Windows 非可变中文字体未必提供精确的中间字重，不将 CSS 数值视为已测得字形变细比例。软件没有流式生成或拖拽交互，不因参考资料新增这些功能。

设计复核：最初考虑统一圆角卡片拼接，但对学习软件会造成重复层级；改为导航、页面标题、阅读面板、嵌入式说明各承担明确职责，仅首页电路图作为主要视觉记忆点。不增加虚构统计、排行榜、在线字体、动画背景或运行时网络请求。

## 技术范围与验证目标

- 配色与明暗、字号一起存入 SQLite，结构 6 升至 7；旧数据先一致性备份后追加配色，保留旧明暗、字号和全部业务数据。旧版程序不能打开结构 7。
- 四种配色严格白名单；读取坏行、保存失败、提交后响应丢失均沿用明确错误与原目标重试，不静默重置。
- 完整备份包含配色；旧备份仅在副本迁移，新备份拒绝损坏的配色。恢复仍需预览、确认及保护性备份。
- 检查四种配色的明暗显示、跟随系统、字号边界、键盘操作、普通/窄窗口、跨页面、长代码/大图、保存重开及备份恢复。桌面流程使用独立临时数据目录。
- 已跳过的 VMware/安装验收继续保留“未验收”。旧候选 NSIS 与旧解包程序封存，不用它们代表本轮新界面。

## 实际结果与试用

- 单元 566/566（28 文件），类型/格式与构建、独立解包通过。完整首轮 328/330，旧版本测试预期修正后两种形态该场景 2/2 通过，合并为开发/新解包各 165 个不同场景通过；不等同单轮 330/330。原 300 场景已核对保留，原失败不覆盖。
- 四配色×明暗×两运行形态的正文/说明/主按钮实际颜色对比度最低 5.129:1；局部预览隔离、保存/重开、真实写失败/丢响应/坏行、键盘、系统明暗、窄窗、复制反馈及备份恢复均有结果。
- 新解包程序另检查 183 行长代码原文、60 段答案及三个正常尺寸大图、预览跨自动保存、正常关闭和独立重开，共 11 项通过。没有重新做本轮新 UI 的全部 Windows 实际 DPI/原生输入法组合或大题库性能计时。
- 生产改动限定为显示契约/设置仓储与结构增量/备份校验、显示应用、外壳、设置、样式和复制反馈 10 个文件；原草稿控制器、业务题库/练习 SQL、依赖/锁文件和构建配置保持。

使用 新 UI 程序（历史制品已移除，原路径：`../release/ui-20261023/win-unpacked/embedded-practice.exe`），保留完整目录；版本 0.1.0、结构 7、未签名。旧 M5 完整程序和 NSIS 只支持结构 6，不包含本轮主题。完整步骤与数据保护见[当前试用版本交付说明](当前试用版本交付说明.md)。
