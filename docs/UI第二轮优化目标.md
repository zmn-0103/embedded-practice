1. 重做题库工作区的滚动关系，解决“点了题却看不到详情”。

当前宽窗题库使用三栏布局，但列表和详情仍跟随整个文档滚动。实测点击第 20 条题目后，详情整体处于视口外。这是本轮第一优先项。

执行要求：
- 宽窗下将题库正文组织为稳定的三栏工作区：分类树、题目列表、题目详情。
- 顶部搜索、主要筛选及结果数量保持在工作区顶部；列表和详情分别拥有可控的纵向滚动区域。
- 点击列表项时，只更新对应详情，并将详情内部定位到题目标题；保留列表当前位置。
- 不允许通过每次点击都将整个页面滚回顶部来修复，否则会破坏连续浏览。
- 详情过长时在详情区阅读；代码块的横向滚动继续限制在代码块内部。
- 中窄窗口继续使用现有“列表 → 详情 → 返回列表”的方式，保留筛选、页码、选中项和列表滚动位置。
- 将题目列表项整理为标题、元信息、状态三层。普通条目建议控制在约 64～88px，长标题允许自然增高。
- 将题目行样式限定到实际题目按钮，避免 .question-list button 同时影响分页按钮。
- 分页固定为水平布局：“上一页｜第几页 / 总页数｜下一页”，不能每个按钮占一整行。
验收要求：在第 1 页依次点击第 1、10、20 条题目，详情标题都必须出现在当前视口；列表不跳回顶部。翻页、返回、切换主题及字号后继续保持上述行为。

2. 将练习页调整为“精简题头＋阅读区＋稳定操作区”。

执行要求：

- 将当前位置、已揭晓、已自评放入紧凑的进度区，三者保持各自含义。

- 宽窗保留左右两栏：左侧题干与我的答案，右侧参考答案。
- 输入区默认高度建议在 180～240px 内，允许用户展开或调整；不要为了左右等高而制造大块空白。
- 窄窗保留“题干 → 我的答案 → 揭晓 → 参考答案”的顺序，但缩短题头、说明和占位区。
