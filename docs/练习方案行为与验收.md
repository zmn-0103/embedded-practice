# 练习方案行为与验收

本页集中维护当前有效的动态练习方案规则；方案保存条件，固定题单保存明确身份，两者职责不同。需求基线见[计划书](../计划书.md)，原首版范围、结构演进和当批检查原文见[历史记录](history/契约增补与模块演进.md#练习方案原始批次记录)。实际检查、失败和未验项见[验收记录](验收记录.md)，当前程序见[交付说明](当前试用版本交付说明.md)。

## 当前行为

### 保存内容与明确开始

- 每份具名方案保存分类范围、专题 ID、顺序/随机、10/20/50/全部题数和完整筛选：关键词、题库标签、难度、自评（含“不会＋不熟”）、仅收藏、可选个人标签、最近练习条件及最久未练优先。
- 方案不保存题目队列、作答、揭晓或自评记录。选用只填写条件，用户点击开始才按当前题库创建新轮；继续旧轮仍读其固定队列。填入、匹配数刷新与开始前读取使用当前范围，不将保存时匹配题数当作固定题数。
- 列表、匹配数、保存/填入与建轮共用原选题语义，分类、专题和各筛选取交集。“不会＋不熟”只采用当前内容版本最近自评。内容更新待复习的临时组卷状态不加入方案或会话 filters。
- 最近练习可保存 `practiceRecency`（all/never/7d/30d）及 `practiceOrder`（default/oldest）；旧 JSON 缺字段保持不限/默认。最近时间以当前版本最近揭晓为准，7/30 天、未知时间及优先排序口径见[最近练习规则](复习待办与最近练习行为.md#最近练习条件)。最久优先与随机组合时先取优先范围，再只打乱该范围；建轮后固定队列。

### 名称、身份与容量

- 名称去首尾空白后为 1～60 字符，禁止控制符；按 SQLite ASCII NOCASE 唯一，最多 100 份。满额仍可更新已有方案。
- 保存时捕获明确 UUID、名称和完整条件；响应丢失按原 ID/原条件重试，不新增副本、不自动覆盖同名方案。另存当前条件使用新身份及独立名称。
- 方案与导入文件分开、本机持久化。写入不递增题库内容修订号，不使原导入预览无故失效；不修改活动轮、题库内容或作答记录。

### 编辑、删除与失效引用

- 可重命名所选方案，或用上方当前条件更新所选方案；更新前确认名称与目标条件。更新携带捕获的原名称及完整原条件，在 immediate 事务内核对；已删除或原条件已变化时明确报错。目标与当前已相同的原操作重试可幂等成功，JSON 键序/空白不构成条件变化。
- 只改名可以保留已失效分类/专题的原条件；改成不同条件时重新验证范围。分类改名仍按原 ID 定位；分类或专题失效时保留方案并提示重新选择，禁止静默变成全部题目。
- 个人标签按身份保存，改名仍有效；删除标签后方案保留原条件并标记失效，匹配为 0、禁止填入，不静默清成不限。用户明确重新选择后可更新或另存，详见[个人标签规则](个人标签与常用入口行为.md#个人标签)。
- 删除需要确认，默认取消；失效方案也可明确删除。只删除方案，不删除题目、练习记录或活动轮。

### 置顶、列表和最近使用

- 支持置顶、取消置顶；列表先置顶，同组按最近成功开始时间降序，再按名称和身份稳定排序。展示当前匹配数及最近开始时间，未使用时间为 NULL。
- 填入、改名、更新、置顶均不计使用；继续原轮、结果页再练、空匹配或建轮失败也不新增使用时间。只有确实沿该方案保存定义成功建轮才更新时间。
- 来源方案由明确填入时的 ID 传递，事务内核对实际条件与保存定义一致。用户改动条件后开始，不把改后的练习归为原方案使用；单纯改名/置顶不改变条件身份。缺省值与明确默认值归一化，不因字段顺序或旧 JSON 缺字段漏记使用。
- 最近使用、建轮、原活动轮替换、固定队列及回执同事务提交；失败全部回滚并保留原活动轮。原请求重试读原回执，不再次建轮或更新时间。旧版未记录的使用时间不从旧轮推算，详见[常用入口规则](个人标签与常用入口行为.md#方案与题单的常用入口)。

### 失败、未知结果与关闭

- 名称和条件在发起时捕获。保存失败保留名称及捕获条件；确定未执行的输入/目标错误允许修改后重新保存。
- 结果未知或可重试数据库错误时锁定表单及依赖操作，重试原身份、目标与 expected 条件；也可明确停止重试后核对列表。停止重试不会删除已经提交的方案。
- 正常关闭等待在途保存，不绕过原练习/学习数据保存守卫。方案组件负责表单和交互状态，仓库负责持久化，主进程校验来源与固定命令，不新增另一套会话管理。

### 完整备份与兼容性

- 完整备份包含编辑后定义、个人标签条件、置顶和最近使用元数据；旧库没有方案时为明确空集合，不推造最近方案或历史使用时间。
- 损坏定义拒绝恢复，合法失效引用按原定义保留供用户处理。旧库在一致性保护备份后事务升级，旧备份仅在暂存副本升级；备份失败、未知同名对象或外键失败停止/回滚，不重建空库。各结构的字段保护与校验见[数据保护契约](数据保护与桌面边界.md)。
