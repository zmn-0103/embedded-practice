# 项目概况

本页只记录技术定位。产品用途、功能和使用入口见[根 README](../README.md)；当前程序和兼容边界见[交付说明](当前试用版本交付说明.md)，实际进展与检查分别见[开发记录](开发记录.md)和[验收记录](验收记录.md)。

- 目标为 Windows 离线、单用户桌面应用，内部标识 `embedded-practice`，发布验证平台为 Windows 11 x64。
- 技术栈为 Electron、React、TypeScript、electron-vite 和 SQLite/better-sqlite3；现有检查使用 Vitest 与 Playwright，打包使用 electron-builder。依赖及实际版本以 [package.json](../package.json) 和 [package-lock.json](../package-lock.json) 为准，不在本页重复版本快照。
- “嵌入式”描述题库领域，本程序本身不使用 MCU、RTOS 或固件构建流程。题库涉及的芯片、库版本和实验条件另按内容来源核实。
- Markdown 是题库维护来源，SQLite 保存导入副本及本机学习资料；渲染层通过受限桥接调用桌面能力。职责和边界见[项目模块职责](项目模块职责.md)、[题库契约](题库与导入契约.md)和[数据保护契约](数据保护与桌面边界.md)。
