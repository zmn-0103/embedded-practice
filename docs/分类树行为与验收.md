# 分类树行为与验收

本页维护分类树的当前行为。当前程序和兼容要求见[交付说明](当前试用版本交付说明.md)，板块内容组织见[分类与标签规范](题库分类与标签规范.md)。

## 本批契约

分类采用板块→专题两层；每专题至多归属一个板块，未归属时列为未分类。分类只改变导航与选题范围，不复制题目，不改变专题/题目稳定ID、题答、内容版本或既有记录。支持创建/改名/移除板块、调整专题归属与专题检索；移除板块默认取消确认，确认后专题保留为未分类。板块名称去首尾空白、1～60字符、禁止控制字符，名称不区分ASCII大小写且唯一。

分类在本机数据库独立维护。新导入专题默认未分类，重导入已有专题保留原归属；不从文件名或标签推测分类，不修改现有Markdown格式。完整备份包含分类与归属，恢复校验包含这些数据。

题库、开始练习和学习记录支持全部分类、未分类或指定板块，再与专题/归档/既有条件取交集；标签候选覆盖当前分类及专题/归档范围，不被其他条件或分页缩窄。树中计数按专题归属及题目身份去重，学习统计仍只使用当前内容版本。检索专题只收窄导航，不自行应用题目筛选。

新轮在同一建轮事务中按分类选题并保存当时分类ID/名称快照，再保存固定队列及原筛选条件。分类移动、改名、移除、导入更新或重启不会重抽既有队列；重试先读取原回执。旧会话原filters_json保持，新增分类快照统一表示此前没有分类限制；原filters为null仍保持未知，不推造原筛选条件。当前选择的分类或专题不再匹配时显示明确空范围，不自动扩大到全部题目。

分类、专题归属及会话分类快照纳入完整备份与恢复。迁移遵守[数据保护契约](数据保护与桌面边界.md)，未知对象、备份失败或外键错误停止并保持原库；恢复不推造旧轮未知条件。

沿用受限预加载白名单、双端严格校验、可信来源和恢复暂停/关闭边界。分类写入使用明确目标及事务，重复提交同名创建或相同目标不重复新增，失败不留部分归属；不增加任意文件、SQL或网络能力。
